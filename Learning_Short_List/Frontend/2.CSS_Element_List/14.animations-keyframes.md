# 14. CSS ANIMATIONS & @KEYFRAMES

| Property / Rule | Values | Description |
| --- | --- | --- |
| `@keyframes` | `@keyframes name { from {...} to {...} }` | Defines the keyframe timeline steps of an animation |
| `animation-name` | `<identifier>` | `none` | Name of `@keyframes` to play |
| `animation-duration` | `<time>` (e.g. `1s`, `800ms`) | Time to complete one cycle |
| `animation-timing-function` | `ease` | `linear` | `cubic-bezier()` | `steps(n)` | Speed curve of animation |
| `animation-delay` | `<time>` (e.g. `0.5s`) | Time before animation starts |
| `animation-iteration-count` | `<number>` | `infinite` | Number of times animation repeats |
| `animation-direction` | `normal` | `reverse` | `alternate` | `alternate-reverse` | Direction flow of playback |
| `animation-fill-mode` | `none` | `forwards` | `backwards` | `both` | Applies styles before/after animation executes |
| `animation-play-state` | `running` | `paused` | Pauses or resumes animation play |
| `animation` | Shorthand syntax | `name duration timing delay count direction fill-mode` |

**Example:**
```css
/* 1. Pulse / Glow Keyframes */
@keyframes pulseGlow {
  0% {
    transform: scale(1);
    box-shadow: 0 0 0 0 rgba(59, 130, 246, 0.6);
  }
  70% {
    transform: scale(1.05);
    box-shadow: 0 0 0 15px rgba(59, 130, 246, 0);
  }
  100% {
    transform: scale(1);
    box-shadow: 0 0 0 0 rgba(59, 130, 246, 0);
  }
}

.live-indicator {
  width: 12px;
  height: 12px;
  background-color: #3b82f6;
  border-radius: 50%;
  animation: pulseGlow 2s infinite ease-in-out;
}

/* 2. Slide-In Fade-In on Page Load */
@keyframes slideFadeIn {
  from {
    opacity: 0;
    transform: translateY(20px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

.hero-content {
  animation: slideFadeIn 0.8s cubic-bezier(0.16, 1, 0.3, 1) forwards;
}

/* 3. Infinite Loading Spinner */
@keyframes spin {
  to { transform: rotate(360deg); }
}

.spinner {
  width: 32px;
  height: 32px;
  border: 3px solid #e2e8f0;
  border-top-color: #3b82f6;
  border-radius: 50%;
  animation: spin 0.8s linear infinite;
}
```
