# 9. DISPLAY, VISIBILITY & OVERFLOW

| Property | Values | Description |
| --- | --- | --- |
| `display: block` | Display Mode | Starts on new line, takes full available width |
| `display: inline` | Display Mode | Flows within text, ignores top/bottom margin & height/width |
| `display: inline-block` | Display Mode | Flows inline but respects width, height, margin, padding |
| `display: none` | Display Mode | Removes element completely from layout flow and screen readers |
| `display: contents` | Display Mode | Hides container element itself; children become direct items of parent |
| `visibility: visible` / `hidden` | Visibility | `hidden` hides visually but preserves its layout space |
| `visibility: collapse` | Visibility | Collapses table rows/columns or acts like `hidden` |
| `opacity` | `0.0` to `1.0` | Controls visual transparency of element and its children |
| `overflow` | `visible` | `hidden` | `scroll` | `auto` | `clip` | Controls behavior when content overflows container bounds |
| `overflow-x` / `overflow-y` | `visible` | `hidden` | `scroll` | `auto` | Overflow control specifically on X or Y axis |
| `text-overflow` | `clip` | `ellipsis` | Renders ellipsis (`...`) for overflowing text content |

**Example:**
```css
/* Horizontal Scrollable Container */
.scroll-row {
  display: flex;
  gap: 16px;
  overflow-x: auto;
  overflow-y: hidden;
  padding: 12px;
  /* Smooth touch scrolling on mobile */
  -webkit-overflow-scrolling: touch;
}

/* Hide element visually while keeping DOM accessible for screen readers */
.visually-hidden {
  position: absolute;
  width: 1px;
  height: 1px;
  padding: 0;
  margin: -1px;
  overflow: hidden;
  clip: rect(0, 0, 0, 0);
  white-space: nowrap;
  border-width: 0;
}

/* Modal animation state using opacity & visibility */
.modal {
  visibility: hidden;
  opacity: 0;
  transition: opacity 0.3s ease, visibility 0.3s ease;
}

.modal.active {
  visibility: visible;
  opacity: 1;
}
```
