# 20. CLIP PATH & MASKING

| Property / Function | Values | Description |
| --- | --- | --- |
| `clip-path: circle()` | `circle(50% at center)` | Clips element into a circular shape |
| `clip-path: ellipse()` | `ellipse(50% 25% at 50% 50%)` | Clips element into an ellipse |
| `clip-path: polygon()` | `polygon(0 0, 100% 0, 100% 85%, 0 100%)` | Clips element into custom geometric polygon |
| `clip-path: path()` | `path('M ... Z')` | Clips using SVG path data string |
| `mask-image` | `linear-gradient(...)` | `url(...)` | Hides portions of element based on mask transparency |
| `mask-size` / `mask-repeat` | `cover` | `no-repeat` | Sizing and repeating of image mask |

**Example:**
```css
/* Diagonal Cut Header Banner */
.angled-hero {
  background: linear-gradient(135deg, #3b82f6, #1d4ed8);
  color: white;
  padding: 80px 24px 120px;
  /* Cut bottom at an angle */
  clip-path: polygon(0 0, 100% 0, 100% 85%, 0 100%);
}

/* Hexagon Shape Image */
.hexagon-avatar {
  width: 120px;
  height: 120px;
  object-fit: cover;
  clip-path: polygon(50% 0%, 100% 25%, 100% 75%, 50% 100%, 0% 75%, 0% 25%);
}

/* Smooth Fade-out Mask on Scroll Area */
.fade-scroll-list {
  max-height: 250px;
  overflow-y: auto;
  /* Masks bottom edge so text smoothly fades away */
  mask-image: linear-gradient(to bottom, black 80%, transparent 100%);
  -webkit-mask-image: linear-gradient(to bottom, black 80%, transparent 100%);
}
```
