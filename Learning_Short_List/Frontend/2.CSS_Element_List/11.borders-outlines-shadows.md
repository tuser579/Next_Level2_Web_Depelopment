# 11. BORDERS, OUTLINES & SHADOWS

| Property | Values | Description |
| --- | --- | --- |
| `border` | `<width> <style> <color>` | Shorthand for all border sides |
| `border-style` | `solid` | `dashed` | `dotted` | `double` | `none` | Border style pattern |
| `border-radius` | `<length>` | `<percentage>` (1-4 values) | Creates rounded corners or circular avatars (`50%`) |
| `border-image` | `url(...) slice / width` | Uses an image as the element border |
| `outline` | `<width> <style> <color>` | Border outside box model (does not alter element size) |
| `outline-offset` | `<length>` | Distance space between outline and border |
| `box-shadow` | `offset-x offset-y blur-radius spread-radius color (inset)` | Drops one or more shadows from the element frame |
| `drop-shadow()` | Filter function | Casts shadow hugging transparent SVG / PNG contours |

**Example:**
```css
/* Premium Card with Layered Shadow */
.elevated-card {
  background: #ffffff;
  border: 1px solid rgba(226, 232, 240, 0.8);
  border-radius: 16px;
  
  /* Multi-layered smooth box shadow */
  box-shadow: 
    0 1px 3px 0 rgba(0, 0, 0, 0.05),
    0 10px 15px -3px rgba(0, 0, 0, 0.08),
    0 4px 6px -2px rgba(0, 0, 0, 0.03);
  
  transition: transform 0.2s ease, box-shadow 0.2s ease;
}

.elevated-card:hover {
  transform: translateY(-4px);
  box-shadow: 
    0 20px 25px -5px rgba(0, 0, 0, 0.1),
    0 10px 10px -5px rgba(0, 0, 0, 0.04);
}

/* Accessible focus ring using outline-offset */
.custom-btn:focus-visible {
  outline: 2px solid #3b82f6;
  outline-offset: 3px;
}

/* Circular avatar */
.avatar {
  width: 48px;
  height: 48px;
  border-radius: 50%;
  border: 2px solid #3b82f6;
}
```
