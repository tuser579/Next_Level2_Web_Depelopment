# 1. SYNTAX & SELECTORS

| Selector / Syntax | Name | Description |
| --- | --- | --- |
| `*` | Universal Selector | Matches all elements |
| `element` (e.g. `p`, `h1`) | Type / Element Selector | Matches elements by tag name |
| `.class` | Class Selector | Matches elements with specific class name |
| `#id` | ID Selector | Matches element with unique ID attribute |
| `elem.class` | Compound Selector | Matches element having specified class |
| `elem, elem` | Selector List (Grouping) | Applies styles to multiple selectors |
| `parent > child` | Direct Child Combinator | Matches immediate direct children |
| `ancestor descendant` | Descendant Combinator | Matches any nested descendant |
| `prev + next` | Adjacent Sibling | Matches element immediately following sibling |
| `prev ~ next` | General Sibling | Matches all matching siblings following element |
| `[attr]` / `[attr=val]` | Attribute Selector | Matches elements with attribute (or specific value) |
| `[attr^=val]` / `[attr$=val]` | Prefix / Suffix Attribute | Starts with (`^=`) or ends with (`$=`) string |
| `[attr*=val]` | Substring Attribute | Contains substring value |
| `:hover`, `:focus`, `:active` | User Action Pseudo-classes | State on hover, focus, or click |
| `:first-child`, `:last-child` | Child Pseudo-classes | First or last child of parent |
| `:nth-child(n)` | Nth Child Pseudo-class | Matches by formula (e.g. `2n`, `odd`, `3n+1`) |
| `:not(selector)` | Negation Pseudo-class | Matches elements not matching selector |
| `:is(s1, s2)`, `:where(s1, s2)` | Matches Any Pseudo-class | Matches any list item (`:where` has 0 specificity) |
| `:has(selector)` | Parent / Relational Selector | Selects parent based on contained child/sibling |
| `::before`, `::after` | Pseudo-elements | Inserts generated content before/after element |
| `::placeholder`, `::selection` | Component Pseudo-elements | Styles input placeholder or user text selection |

**Example:**
```css
/* Element and Class Selectors */
h1 {
  color: #1e293b;
  font-family: sans-serif;
}

.btn-primary {
  background-color: #3b82f6;
  color: #ffffff;
  padding: 8px 16px;
  border-radius: 6px;
}

/* Combinators & Attribute Selectors */
nav > ul > li {
  display: inline-block;
}

input[type="text"]:focus {
  border-color: #2563eb;
  outline: 2px solid #93c5fd;
}

/* Pseudo-classes & Pseudo-elements */
li:nth-child(even) {
  background-color: #f8fafc;
}

a:hover {
  text-decoration: underline;
}

.quote::before {
  content: "“";
  font-size: 2rem;
  color: #64748b;
}

/* Modern :has() Relational Selector */
.card:has(img) {
  padding-top: 0; /* Adjust card layout if it contains an image */
}
```
