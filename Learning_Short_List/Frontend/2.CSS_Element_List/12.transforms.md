# 12. TRANSFORMS (2D & 3D)

| Function / Property | Values | Description |
| --- | --- | --- |
| `transform: translate(x, y)` | `translate(50px, -20px)` | Moves element along X and Y axes |
| `transform: translateX() / translateY()` | `<length>` | `<percentage>` | Moves along specific single axis |
| `transform: scale(x, y)` | `scale(1.1)` | `scaleX(2)` | Resizes element larger or smaller |
| `transform: rotate()` | `rotate(45deg)` | `rotate(0.5turn)` | Rotates element around origin point |
| `transform: skew(x, y)` | `skewX(15deg)` | `skewY(10deg)` | Skews / slants element along axes |
| `transform-origin` | `center` | `top left` | `x% y%` | Sets the anchor point for transformation |
| `transform-style` | `flat` | `preserve-3d` | Preserves 3D spatial positioning for child elements |
| `perspective` | `<length>` (e.g. `1000px`) | Defines 3D viewing perspective distance for user |
| `backface-visibility` | `visible` | `hidden` | Hides backside of element during 3D rotation flip |
| Individual transform properties | `scale: 1.1; rotate: 45deg; translate: 10px 20px;` | Modern independent CSS transform properties |

**Example:**
```css
/* 3D Card Flip Effect */
.flip-card-container {
  perspective: 1000px;
  width: 300px;
  height: 200px;
}

.flip-card-inner {
  position: relative;
  width: 100%;
  height: 100%;
  text-align: center;
  transition: transform 0.6s cubic-bezier(0.4, 0, 0.2, 1);
  transform-style: preserve-3d;
}

.flip-card-container:hover .flip-card-inner {
  transform: rotateY(180deg);
}

.flip-card-front, .flip-card-back {
  position: absolute;
  inset: 0;
  backface-visibility: hidden;
  border-radius: 12px;
  padding: 20px;
}

.flip-card-front {
  background-color: #3b82f6;
  color: white;
}

.flip-card-back {
  background-color: #1e293b;
  color: white;
  transform: rotateY(180deg);
}

/* Modern individual transform properties */
.interactive-icon {
  translate: 0 0;
  scale: 1;
  rotate: 0deg;
  transition: scale 0.2s, rotate 0.2s;
}

.interactive-icon:hover {
  scale: 1.25;
  rotate: 15deg;
}
```
