# 3. BOX MODEL

| Property | Values | Description |
| --- | --- | --- |
| `box-sizing` | `content-box` | `border-box` | Includes padding & border inside total width/height (`border-box`) |
| `width` / `height` | `auto` | `<length>` | `<percentage>` | Content dimension sizing |
| `min-width` / `max-width` | `<length>` | `<percentage>` | `none` | Minimum and maximum width constraints |
| `min-height` / `max-height` | `<length>` | `<percentage>` | `none` | Minimum and maximum height constraints |
| `margin` | `<length>` | `auto` (1-4 values) | Outer spacing around elements |
| `margin-inline` / `margin-block` | `<length>` | `auto` | Logical outer margin (horizontal / vertical) |
| `padding` | `<length>` (1-4 values) | Inner spacing between border and content |
| `padding-inline` / `padding-block` | `<length>` | Logical inner padding |
| `border` | `<width> <style> <color>` | Shorthand for border on all 4 sides |
| `border-radius` | `<length>` | `<percentage>` | Rounded corners on borders |
| `outline` | `<width> <style> <color>` | Drawn outside border edge (does not take layout space) |
| `outline-offset` | `<length>` | Distance between outline and border edge |

**Example:**
```css
/* Universal Border-Box Reset (Recommended) */
*, *::before, *::after {
  box-sizing: border-box;
}

/* Centered container with Box Model properties */
.card-container {
  width: 100%;
  max-width: 480px;
  min-height: 200px;
  
  /* Margins: Top/Bottom: 24px, Left/Right: auto (centers) */
  margin: 24px auto;
  
  /* Padding: 20px all around */
  padding: 20px;
  
  /* Border & Rounded Corners */
  border: 1px solid #e2e8f0;
  border-radius: 12px;
  
  /* Outline with offset */
  outline: 2px solid transparent;
  outline-offset: 4px;
}

.card-container:focus-within {
  outline-color: #3b82f6;
}
```
