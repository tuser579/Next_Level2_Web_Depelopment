# 16. CONTAINER QUERIES

| Property / Rule | Values | Description |
| --- | --- | --- |
| `container-type` | `inline-size` | `size` | `normal` | Enables element as a query container (usually `inline-size`) |
| `container-name` | `<identifier>` | Names container for specific query targeting |
| `container` | `<name> / <type>` | Shorthand for container name and type |
| `@container (min-width: 400px)` | Rule | Applies styles based on parent container width (not viewport!) |
| `cqw` / `cqh` | Unit | 1% of container width / height |
| `cqi` / `cqb` | Unit | 1% of container inline / block size |

**Example:**
```css
/* 1. Define Container Parent */
.card-wrapper {
  container-type: inline-size;
  container-name: cardContainer;
}

/* 2. Default Card Layout (Stacked for narrow containers) */
.user-card {
  display: flex;
  flex-direction: column;
  gap: 12px;
  padding: 16px;
  background-color: #ffffff;
  border-radius: 8px;
}

.user-card img {
  width: 100%;
  aspect-ratio: 16 / 9;
  object-fit: cover;
  border-radius: 6px;
}

/* 3. When Container width is at least 450px, switch to horizontal row! */
@container cardContainer (min-width: 450px) {
  .user-card {
    flex-direction: row;
    align-items: center;
    gap: 20px;
  }

  .user-card img {
    width: 120px;
    aspect-ratio: 1 / 1;
  }

  .user-card h3 {
    font-size: 1.5rem;
  }
}
```
