# 5. TYPOGRAPHY & FONTS

| Property | Values | Description |
| --- | --- | --- |
| `font-family` | `'Inter', system-ui, sans-serif` | Font family stack with fallback options |
| `@font-face` | Rule block with `src: url(...)` | Imports and defines custom web fonts |
| `font-size` | `<length>` | `<percentage>` | `clamp()` | Size of the font |
| `font-weight` | `100`-`900` | `normal` | `bold` | `bolder` | Font stroke thickness |
| `font-style` | `normal` | `italic` | `oblique` | Font posture / italics |
| `line-height` | `1.5` | `<length>` | `<percentage>` | Height of text line box (unitless recommended) |
| `letter-spacing` | `<length>` | `normal` | Spacing between characters |
| `word-spacing` | `<length>` | `normal` | Spacing between words |
| `text-align` | `left` | `right` | `center` | `justify` | Horizontal text alignment |
| `text-decoration` | `underline` | `line-through` | `none` | Text decoration line, style, and color |
| `text-transform` | `uppercase` | `lowercase` | `capitalize` | `none` | Case transformation of text |
| `text-overflow` | `clip` | `ellipsis` | Rendering for overflow text (requires `nowrap`) |
| `white-space` | `normal` | `nowrap` | `pre` | `pre-wrap` | `pre-line` | Handling of whitespace and line wrapping |
| `word-break` / `overflow-wrap` | `normal` | `break-all` | `break-word` | `anywhere` | Word break rules for long words/URLs |
| `font-display` | `auto` | `block` | `swap` | `fallback` | `optional` | Font loading strategy inside `@font-face` |

**Example:**
```css
/* Custom Web Font Loading */
@font-face {
  font-family: 'CustomSans';
  src: url('/fonts/custom-sans.woff2') format('woff2');
  font-weight: 400 700;
  font-style: normal;
  font-display: swap; /* Fast rendering with swap fallback */
}

body {
  font-family: 'CustomSans', 'Inter', system-ui, -apple-system, sans-serif;
  font-size: 1rem;
  line-height: 1.6;
  color: #1e293b;
  -webkit-font-smoothing: antialiased;
}

/* Fluid responsive typography with clamp() */
h1 {
  font-size: clamp(2rem, 5vw + 1rem, 3.5rem);
  font-weight: 800;
  letter-spacing: -0.025em;
  line-height: 1.2;
}

/* Single line text truncation with ellipsis */
.truncate {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
  max-width: 300px;
}
```
