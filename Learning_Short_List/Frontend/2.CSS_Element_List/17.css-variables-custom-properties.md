# 17. CSS VARIABLES (CUSTOM PROPERTIES)

| Feature / Rule | Syntax | Description |
| --- | --- | --- |
| Variable Declaration | `--variable-name: value;` | Defines custom property (case-sensitive) |
| Variable Usage | `var(--variable-name, fallback)` | Reads property value with optional fallback |
| Global Scope | `:root { ... }` | Defines global variables accessible everywhere |
| Local Scope | `.component { --local: 10px; }` | Overrides or creates scoped variable inside selector subtree |
| `@property` | `@property --name { syntax: '<color>'; inherits: true; initial-value: red; }` | Registers variable with type checking for smooth transitions/gradients |

**Example:**
```css
/* Global Theme Variables */
:root {
  --font-main: 'Inter', system-ui, sans-serif;
  --bg-primary: #ffffff;
  --text-primary: #0f172a;
  --color-primary: #3b82f6;
  --radius-md: 8px;
  --shadow-sm: 0 1px 2px rgba(0, 0, 0, 0.05);
}

/* Dark Theme Toggle Class */
[data-theme="dark"] {
  --bg-primary: #0f172a;
  --text-primary: #f8fafc;
  --color-primary: #60a5fa;
  --shadow-sm: 0 1px 2px rgba(0, 0, 0, 0.5);
}

/* Components dynamically adapt to variables */
body {
  font-family: var(--font-main);
  background-color: var(--bg-primary);
  color: var(--text-primary);
  transition: background-color 0.3s, color 0.3s;
}

.btn {
  background-color: var(--color-primary);
  border-radius: var(--radius-md);
  box-shadow: var(--shadow-sm);
  color: #ffffff;
}

/* Register typed property for animatable gradient */
@property --gradient-angle {
  syntax: '<angle>';
  initial-value: 0deg;
  inherits: false;
}
```
