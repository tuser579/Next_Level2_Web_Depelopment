# 15. MEDIA QUERIES & RESPONSIVE DESIGN

| Feature / Syntax | Type | Description |
| --- | --- | --- |
| `@media (min-width: 768px)` | Viewport Width | Applies styles on screens 768px and wider (Mobile-First) |
| `@media (max-width: 767px)` | Viewport Width | Applies styles on screens up to 767px wide |
| `@media (width >= 768px)` | Modern Range Syntax | Clean mathematical comparison syntax for queries |
| `@media (orientation: landscape)` | Orientation | Detects landscape or portrait device orientation |
| `@media (prefers-color-scheme: dark)` | User Preference | Detects user OS dark mode setting |
| `@media (prefers-reduced-motion: reduce)` | Accessibility | Disables/reduces animations for motion sensitivity |
| `@media (hover: hover)` | Pointer Capability | Targets devices with true hover support (mice vs touchscreens) |
| `@media (pointer: coarse)` | Pointer Precision | Targets touchscreen devices for larger tap targets |
| `aspect-ratio` | CSS Property | Maintains aspect ratio (e.g. `16 / 9`, `1 / 1`) without padding hacks |

**Example:**
```css
/* Mobile-First Base Styles */
.container {
  width: 100%;
  padding-inline: 16px;
}

.grid-cols {
  display: grid;
  grid-template-columns: 1fr;
  gap: 16px;
}

/* Tablet Breakpoint (>= 768px) */
@media (min-width: 768px) {
  .container {
    max-width: 720px;
    margin-inline: auto;
  }
  .grid-cols {
    grid-template-columns: repeat(2, 1fr);
  }
}

/* Desktop Breakpoint (>= 1024px) */
@media (min-width: 1024px) {
  .container {
    max-width: 960px;
  }
  .grid-cols {
    grid-template-columns: repeat(4, 1fr);
  }
}

/* Dark Mode Preference */
@media (prefers-color-scheme: dark) {
  body {
    background-color: #0f172a;
    color: #f8fafc;
  }
  .card {
    background-color: #1e293b;
    border-color: #334155;
  }
}

/* Accessibility: Respect Reduced Motion */
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```
