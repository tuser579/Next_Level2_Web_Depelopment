# 8. POSITIONING & Z-INDEX

| Property / Value | Type | Description |
| --- | --- | --- |
| `position: static` | Default | Default document flow positioning |
| `position: relative` | Relative | Positioned relative to its normal position; creates positioning context |
| `position: absolute` | Absolute | Positioned relative to nearest positioned ancestor (non-static) |
| `position: fixed` | Fixed | Positioned relative to viewport; stays fixed during scroll |
| `position: sticky` | Sticky | Toggles between relative and fixed based on scroll position |
| `top`, `right`, `bottom`, `left` | Offsets | Distance from specified edge of containing block |
| `inset` | Shorthand | Shorthand for `top right bottom left` (e.g. `inset: 0`) |
| `z-index` | `auto` | `<integer>` | Stacking order along the Z-axis (requires positioned element) |
| Stacking Context | Concept | Formed by `opacity < 1`, `transform`, `z-index`, `filter`, `isolation: isolate` |
| `isolation: isolate` | Property | Creates a new stacking context without altering visual styles |

**Example:**
```css
/* Sticky Navigation Header */
.header {
  position: sticky;
  top: 0;
  z-index: 100;
  background-color: rgba(255, 255, 255, 0.95);
  backdrop-filter: blur(8px);
}

/* Card with Floating Badge using Absolute Position */
.card {
  position: relative; /* Containing context for absolute child */
  padding: 24px;
  border-radius: 12px;
  background-color: #ffffff;
  border: 1px solid #e2e8f0;
}

.badge {
  position: absolute;
  top: 12px;
  right: 12px;
  background-color: #ef4444;
  color: #ffffff;
  padding: 4px 8px;
  border-radius: 9999px;
  font-size: 0.75rem;
}

/* Fullscreen Modal Backdrop */
.modal-overlay {
  position: fixed;
  inset: 0; /* top: 0; right: 0; bottom: 0; left: 0; */
  background-color: rgba(0, 0, 0, 0.5);
  z-index: 999;
  display: flex;
  justify-content: center;
  align-items: center;
}
```
