# 23. CURSOR & USER INTERACTION

| Property | Values | Description |
| --- | --- | --- |
| `cursor` | `pointer` | `default` | `grab` | `grabbing` | `not-allowed` | `text` | Mouse cursor icon on hover |
| `user-select` | `none` | `auto` | `text` | `all` | Controls whether user can select text |
| `pointer-events` | `auto` | `none` | `none` ignores clicks/touches passing them to element underneath |
| `touch-action` | `auto` | `none` | `pan-x` | `pan-y` | `manipulation` | Controls touch gesture behavior (e.g. pan / pinch-zoom) |
| `accent-color` | `<color>` | Tints native form controls (checkboxes, radio, range sliders) |
| `caret-color` | `<color>` | Color of the blinking text insertion cursor |
| `resize` | `none` | `both` | `horizontal` | `vertical` | Enables user resizing on elements (e.g. textarea) |

**Example:**
```css
/* Form Controls & Interaction */
:root {
  accent-color: #3b82f6; /* Colors native checkboxes & radio buttons */
}

input[type="text"], textarea {
  caret-color: #3b82f6; /* Custom blinking cursor color */
}

/* Prevent text selection on UI buttons */
.btn, .badge, .tab {
  user-select: none;
  cursor: pointer;
}

.btn:disabled {
  cursor: not-allowed;
  opacity: 0.6;
}

/* Click-through decorative background icon */
.decorative-icon {
  pointer-events: none; /* Mouse clicks pass right through */
}

/* Mobile Touch Optimization: Disable double-tap-to-zoom delay */
.touch-btn {
  touch-action: manipulation;
}
```
