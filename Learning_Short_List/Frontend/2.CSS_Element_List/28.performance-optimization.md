# 28. CSS PERFORMANCE OPTIMIZATION

| Property / Concept | Values | Description |
| --- | --- | --- |
| `content-visibility` | `auto` | `visible` | `hidden` | Skips rendering off-screen elements until scrolled into view (Huge performance boost!) |
| `contain-intrinsic-size` | `<length>` (e.g. `0 500px`) | Provides placeholder height for `content-visibility: auto` to prevent scroll jumps |
| `will-change` | `transform` | `opacity` | `scroll-position` | Hints browser GPU to create dedicated compositor layer |
| `contain` | `layout` | `paint` | `size` | `strict` | Isolates subtree rendering from the rest of the document |
| GPU Accelerated Properties | `transform`, `opacity` | Animate transform/opacity instead of top/left/width/height to avoid layout reflows |

**Example:**
```css
/* 1. content-visibility for ultra-fast rendering on long pages */
.blog-post-card {
  content-visibility: auto;
  contain-intrinsic-size: 0 350px; /* Estimated height */
}

/* 2. GPU Hardware Acceleration for smooth 60fps animations */
.animated-drawer {
  /* Fast compositor-only property */
  transform: translateX(-100%);
  will-change: transform;
}

/* ❌ Slow: triggers CPU layout recalculations */
/* .bad-animation { left: -300px; } */

/* ✅ Fast: runs on GPU compositor */
/* .good-animation { transform: translateX(-300px); } */
```
