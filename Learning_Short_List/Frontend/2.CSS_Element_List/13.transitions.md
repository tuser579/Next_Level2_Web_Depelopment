# 13. CSS TRANSITIONS

| Property | Values | Description |
| --- | --- | --- |
| `transition-property` | `all` | `opacity, transform` | `none` | Names CSS properties to animate on change |
| `transition-duration` | `<time>` (e.g. `0.3s`, `300ms`) | Duration of transition animation |
| `transition-timing-function` | `ease` | `linear` | `ease-in` | `ease-out` | `ease-in-out` | `cubic-bezier()` | Pacing curve acceleration function |
| `transition-delay` | `<time>` (e.g. `0.1s`) | Wait time before transition starts |
| `transition` | `property duration timing-function delay` | Shorthand for all transition parameters |
| `transition-behavior` | `normal` | `allow-discrete` | Enables transitions on discrete properties like `display` and `overlay` |

**Example:**
```css
/* Smooth Button Hover and Active Transitions */
.btn {
  background-color: #3b82f6;
  color: #ffffff;
  padding: 12px 24px;
  border: none;
  border-radius: 8px;
  cursor: pointer;
  
  /* Transition specific properties for 60fps GPU performance */
  transition: background-color 0.25s ease, transform 0.15s ease, box-shadow 0.25s ease;
  box-shadow: 0 2px 4px rgba(59, 130, 246, 0.2);
}

.btn:hover {
  background-color: #2563eb;
  transform: translateY(-2px);
  box-shadow: 0 6px 12px rgba(59, 130, 246, 0.35);
}

.btn:active {
  transform: translateY(0);
  box-shadow: 0 2px 4px rgba(59, 130, 246, 0.2);
}

/* Custom spring / bouncy cubic-bezier */
.drawer {
  transform: translateX(-100%);
  transition: transform 0.4s cubic-bezier(0.34, 1.56, 0.64, 1);
}

.drawer.open {
  transform: translateX(0);
}
```
