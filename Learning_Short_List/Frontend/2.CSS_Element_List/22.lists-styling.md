# 22. LISTS & CSS COUNTERS

| Property / Function | Values | Description |
| --- | --- | --- |
| `list-style-type` | `disc` | `circle` | `square` | `decimal` | `none` | Marker bullet / number style |
| `list-style-position` | `inside` | `outside` | Placement of list marker relative to content block |
| `list-style-image` | `url('icon.svg')` | Custom image as bullet point marker |
| `list-style` | `type position image` | Shorthand for list style properties |
| `counter-reset` | `<name> <initial-val>` | Initializes or resets a CSS counter variable |
| `counter-increment` | `<name> <step>` | Increments counter value on matching element |
| `counter()` / `counters()` | `counter(name)` | Outputs counter value in `content:` property |

**Example:**
```css
/* 1. Reset standard list styles */
.clean-list {
  list-style: none;
  padding: 0;
  margin: 0;
}

/* 2. Custom Step Numbering with CSS Counters */
.step-list {
  list-style: none;
  counter-reset: step-counter; /* Reset counter to 0 */
  padding: 0;
}

.step-list li {
  counter-increment: step-counter; /* Increment by 1 */
  position: relative;
  padding-left: 48px;
  margin-bottom: 24px;
}

.step-list li::before {
  content: counter(step-counter);
  position: absolute;
  left: 0;
  top: 0;
  width: 32px;
  height: 32px;
  border-radius: 50%;
  background-color: #3b82f6;
  color: #ffffff;
  font-weight: 700;
  display: flex;
  align-items: center;
  justify-content: center;
}
```
