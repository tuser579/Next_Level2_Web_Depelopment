# 18. MODERN CSS NESTING

| Syntax / Feature | Example | Description |
| --- | --- | --- |
| Direct Child Nesting | `.card { & > h2 {...} }` | Nests child selectors directly inside parent rule block |
| Pseudo-class Nesting | `.btn { &:hover {...} }` | Nests state pseudo-classes cleanly with `&` |
| Descendant Nesting | `.nav { a {...} }` | Nests descendants without repeating `.nav a` |
| Parent Modifier | `.card { &.featured {...} }` | Targets parent modifier classes |
| Nested Media Queries | `.hero { @media (min-width: 768px) {...} }` | Keeps component responsive rules collocated |

**Example:**
```css
/* Native CSS Nesting (Supported in all modern browsers) */
.card {
  background: #ffffff;
  border-radius: 12px;
  padding: 24px;
  border: 1px solid #e2e8f0;

  /* Nested descendant */
  h2 {
    font-size: 1.5rem;
    color: #1e293b;
    margin-bottom: 8px;
  }

  p {
    color: #64748b;
    line-height: 1.5;
  }

  /* Nested pseudo-class */
  &:hover {
    box-shadow: 0 10px 20px rgba(0, 0, 0, 0.08);
  }

  /* Nested modifier class */
  &.featured {
    border-color: #3b82f6;
    background: #f0fdf4;
  }

  /* Nested Media Query */
  @media (max-width: 640px) {
    padding: 16px;
    
    h2 {
      font-size: 1.25rem;
    }
  }
}
```
