# 10. SIZING & UNITS

| Unit / Function | Type | Description |
| --- | --- | --- |
| `px` | Absolute | Screen pixels (1px = 1/96th of an inch) |
| `rem` | Relative to Root | Relative to root `<html>` font size (default `16px`) |
| `em` | Relative to Parent | Relative to current / parent element font size |
| `%` | Percentage | Percentage of containing parent element's dimension |
| `vw` / `vh` | Viewport | 1% of viewport width / height |
| `dvh` / `svh` / `lvh` | Dynamic Viewport | Dynamic, Small, and Large viewport height (mobile browser address bar aware) |
| `ch` | Character Unit | Width of the `0` character (ideal for line length readability: 60-75ch) |
| `fr` | Grid Unit | Fractional unit representing fraction of available free space in CSS Grid |
| `calc()` | Function | Performs mathematical calculations (e.g. `calc(100% - 32px)`) |
| `min()` | Function | Picks smallest value from comma-separated arguments |
| `max()` | Function | Picks largest value from comma-separated arguments |
| `clamp()` | Function | Clamps value between min, preferred, and max (`clamp(min, val, max)`) |

**Example:**
```css
/* Responsive Typography and Layout using Modern Units */
html {
  font-size: 16px; /* 1rem = 16px */
}

/* Optimal reading container */
.article-body {
  /* Restrict line length to 65 characters for readability */
  max-width: 65ch;
  margin-inline: auto;
  font-size: 1.125rem; /* 18px */
  line-height: 1.7;
}

/* Full height mobile screen with dvh */
.hero-section {
  min-height: 100dvh; /* Accounts for dynamic mobile navigation bar */
  width: 100%;
  padding: clamp(1rem, 4vw, 3rem);
}

/* Responsive dynamic width */
.sidebar {
  width: min(320px, 90vw);
}

.banner {
  /* At least 200px, preferred 30vw, max 400px */
  height: clamp(200px, 30vw, 400px);
}
```
