# 29. CSS ARCHITECTURE & METHODOLOGIES (BEM & RESET)

| Methodology / Concept | Format | Description |
| --- | --- | --- |
| BEM - Block | `.card` | Standalone standalone entity with semantic meaning |
| BEM - Element | `.card__title`, `.card__button` | Part of a block that has no standalone meaning (`__`) |
| BEM - Modifier | `.card--featured`, `.btn--primary` | Flag on a block or element to change appearance (`--`) |
| Modern CSS Reset | Base reset stylesheet | Standardizes default browser styling inconsistencies |

**Example:**
```css
/* Modern Production CSS Reset */
*, *::before, *::after {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}

body {
  line-height: 1.5;
  -webkit-font-smoothing: antialiased;
}

img, picture, video, canvas, svg {
  display: block;
  max-width: 100%;
}

input, button, textarea, select {
  font: inherit;
}

/* BEM (Block Element Modifier) Architecture Example */
/* Block */
.card {
  background: #ffffff;
  border-radius: 8px;
  padding: 20px;
}

/* Element */
.card__header {
  margin-bottom: 12px;
}

.card__title {
  font-size: 1.25rem;
  font-weight: 700;
}

.card__body {
  color: #64748b;
}

.card__button {
  margin-top: 16px;
}

/* Modifier */
.card--highlighted {
  border: 2px solid #3b82f6;
}

.card--dark {
  background: #1e293b;
  color: #ffffff;
}
```
