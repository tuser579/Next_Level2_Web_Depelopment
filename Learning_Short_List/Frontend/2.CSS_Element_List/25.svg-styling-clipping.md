# 25. SVG STYLING IN CSS

| Property | Values | Description |
| --- | --- | --- |
| `fill` | `<color>` | `none` | `url(#grad)` | Interior fill color of SVG vector shapes |
| `stroke` | `<color>` | `none` | Outline border color of SVG paths |
| `stroke-width` | `<length>` | `<number>` | Width thickness of vector stroke |
| `stroke-dasharray` | `<number>, <number>` | Creates dashed vector strokes or animation segments |
| `stroke-dashoffset` | `<number>` | Offsets dash pattern (used for SVG draw animations) |
| `stroke-linecap` | `butt` | `round` | `square` | End shape of stroke lines |
| `vector-effect` | `non-scaling-stroke` | Keeps stroke width constant when SVG is scaled |

**Example:**
```css
/* Dynamic Interactive SVG Icons */
.icon {
  width: 24px;
  height: 24px;
  fill: currentColor; /* Inherits text color of parent */
  transition: transform 0.2s ease, fill 0.2s ease;
}

.btn:hover .icon {
  transform: scale(1.15);
  fill: #3b82f6;
}

/* SVG Line Drawing Path Animation */
@keyframes drawPath {
  to {
    stroke-dashoffset: 0;
  }
}

.animated-check-icon path {
  stroke: #10b981;
  stroke-width: 2;
  stroke-dasharray: 100;
  stroke-dashoffset: 100;
  animation: drawPath 1.2s ease forwards;
}
```
