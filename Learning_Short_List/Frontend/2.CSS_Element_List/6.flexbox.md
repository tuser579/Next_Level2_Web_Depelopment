# 6. FLEXBOX LAYOUT

| Property | Values | Description |
| --- | --- | --- |
| `display: flex` / `inline-flex` | Container | Initializes flexbox context on element |
| `flex-direction` | `row` | `row-reverse` | `column` | `column-reverse` | Sets main axis direction |
| `flex-wrap` | `nowrap` | `wrap` | `wrap-reverse` | Controls whether items wrap onto multiple lines |
| `flex-flow` | `<direction> <wrap>` | Shorthand for `flex-direction` and `flex-wrap` |
| `justify-content` | `flex-start` | `center` | `flex-end` | `space-between` | `space-around` | `space-evenly` | Aligns items along the main axis |
| `align-items` | `stretch` | `center` | `flex-start` | `flex-end` | `baseline` | Aligns items along cross axis |
| `align-content` | `stretch` | `center` | `space-between` | `space-around` | Aligns multi-line wrapped content |
| `gap` / `row-gap` / `column-gap` | `<length>` | Spacing between flex items |
| `flex-grow` | `<number>` (default: 0) | Ability of item to grow if extra space exists |
| `flex-shrink` | `<number>` (default: 1) | Ability of item to shrink if space is insufficient |
| `flex-basis` | `auto` | `<length>` | Default size before space distribution |
| `flex` | `<grow> <shrink> <basis>` | Shorthand (e.g. `flex: 1`, `flex: 0 0 250px`) |
| `align-self` | `auto` | `flex-start` | `center` | `flex-end` | `stretch` | Overrides `align-items` for specific item |
| `order` | `<integer>` (default: 0) | Changes display order of items without altering DOM |

**Example:**
```css
/* Centered Navbar with Flexbox */
.navbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 16px;
  padding: 12px 24px;
  background-color: #ffffff;
  border-bottom: 1px solid #e2e8f0;
}

.nav-links {
  display: flex;
  align-items: center;
  gap: 20px;
  list-style: none;
}

/* Responsive Card Grid with Flex Wrap */
.card-list {
  display: flex;
  flex-wrap: wrap;
  gap: 24px;
  justify-content: center;
}

.card-item {
  /* grow: 1, shrink: 1, basis: 280px */
  flex: 1 1 280px;
  max-width: 380px;
  padding: 20px;
  background-color: #f8fafc;
  border-radius: 8px;
}

/* Align one item differently */
.card-item.featured {
  align-self: flex-start;
  order: -1; /* Place at the beginning */
}
```
