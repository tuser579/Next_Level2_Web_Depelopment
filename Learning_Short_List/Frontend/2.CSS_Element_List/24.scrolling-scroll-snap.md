# 24. SCROLLING & SCROLL SNAP

| Property | Values | Description |
| --- | --- | --- |
| `scroll-behavior` | `auto` | `smooth` | Smooth page scrolling on anchor clicks |
| `scroll-snap-type` | `x mandatory` | `y proximity` | Enables snap points on scroll container |
| `scroll-snap-align` | `start` | `center` | `end` | `none` | Snap alignment position of child slides |
| `scroll-snap-stop` | `normal` | `always` | Forces stopping at each slide without skipping |
| `scroll-padding` | `<length>` | Offset padding on container for fixed headers |
| `overscroll-behavior` | `auto` | `contain` | `none` | Prevents pull-to-refresh or outer page scroll chaining |
| `scrollbar-width` / `scrollbar-color` | `thin` / `<thumb-color> <track-color>` | Standard modern scrollbar styling |

**Example:**
```css
/* Smooth Document Scroll with Fixed Header Offset */
html {
  scroll-behavior: smooth;
  scroll-padding-top: 80px; /* Offset so anchor targets aren't covered by fixed nav */
}

/* Touch-friendly Carousel / Slider with Scroll Snap */
.slider-container {
  display: flex;
  gap: 16px;
  overflow-x: auto;
  scroll-snap-type: x mandatory;
  padding: 16px;
  overscroll-behavior-x: contain;
  
  /* Modern Standard Scrollbar Styling */
  scrollbar-width: thin;
  scrollbar-color: #94a3b8 #f1f5f9;
}

.slider-slide {
  flex: 0 0 85%;
  max-width: 400px;
  scroll-snap-align: center;
  scroll-snap-stop: always;
  border-radius: 12px;
  background: #ffffff;
  padding: 24px;
}
```
