# 26. PRINT MEDIA STYLING

| Rule / Property | Values | Description |
| --- | --- | --- |
| `@media print` | Media query | Styles applied exclusively when user prints page |
| `@page` | Rule with `margin: 2cm` | Page dimensions, margins, and orientation for physical paper |
| `break-inside` | `auto` | `avoid` | Prevents page break inside an element (e.g. cards/tables) |
| `break-before` / `break-after` | `page` | `avoid` | `always` | Forces page break before or after element |
| Print URL Expansion | `a[href]::after { content: ' (' attr(href) ')'; }` | Prints full destination URL next to links |

**Example:**
```css
/* Print Stylesheet Optimization */
@media print {
  /* Set Paper Page Margins */
  @page {
    margin: 1.5cm;
    size: A4 portrait;
  }

  /* Hide interactive / non-printable elements */
  nav, footer, .sidebar, .btn, .no-print {
    display: none !important;
  }

  body {
    font-size: 12pt;
    line-height: 1.4;
    color: #000000;
    background: #ffffff !important;
  }

  /* Prevent awkward page break splitting a card or table */
  .receipt-card, tr, figure {
    break-inside: avoid;
  }

  /* Print destination URLs next to links */
  a[href^="http"]::after {
    content: " (" attr(href) ")";
    font-size: 9pt;
    color: #555555;
  }
}
```
