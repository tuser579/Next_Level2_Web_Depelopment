# 7. CSS GRID LAYOUT

| Property | Values | Description |
| --- | --- | --- |
| `display: grid` / `inline-grid` | Container | Establishes a CSS grid formatting context |
| `grid-template-columns` | `1fr 1fr` | `repeat(3, 1fr)` | `repeat(auto-fit, minmax(200px, 1fr))` | Defines track sizes for columns |
| `grid-template-rows` | `auto` | `100px 1fr` | `<length>` | Defines track sizes for rows |
| `grid-template-areas` | `"header header" "sidebar main"` | Defines named grid area template layout |
| `gap` / `row-gap` / `column-gap` | `<length>` | Sets gutters between grid rows and columns |
| `grid-column` / `grid-row` | `<start> / <end>` | `span 2` | Specifies item placement across columns/rows |
| `grid-area` | `<name>` | `row-start / col-start / row-end / col-end` | Assigns item to named grid area or coordinates |
| `justify-items` / `align-items` | `start` | `center` | `end` | `stretch` | Aligns items inside grid cells |
| `justify-content` / `align-content` | `start` | `center` | `space-between` | `space-around` | Aligns entire grid within container |
| `auto-fit` vs `auto-fill` | Inside `repeat()` | `auto-fit` stretches tracks to fill; `auto-fill` keeps empty slots |
| `minmax()` | `minmax(min, max)` | Defines flexible track size range |
| `subgrid` | `grid-template-columns: subgrid` | Inherits parent grid tracks for nested items |

**Example:**
```css
/* 1. Ultra-responsive Card Grid (No media queries needed!) */
.auto-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(260px, 1fr));
  gap: 20px;
}

/* 2. Full Page Layout with Named Grid Areas */
.app-layout {
  display: grid;
  grid-template-columns: 240px 1fr;
  grid-template-rows: 60px 1fr 50px;
  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
  min-height: 100vh;
}

.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main; }
.footer  { grid-area: footer; }

/* Item spanning multiple columns */
.featured-card {
  grid-column: span 2;
}

@media (max-width: 768px) {
  .app-layout {
    grid-template-columns: 1fr;
    grid-template-areas:
      "header"
      "main"
      "sidebar"
      "footer";
  }
}
```
