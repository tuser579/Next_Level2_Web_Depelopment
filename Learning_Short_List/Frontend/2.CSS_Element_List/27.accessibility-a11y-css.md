# 27. ACCESSIBILITY (A11Y) IN CSS

| Technique / Selector | Type | Description |
| --- | --- | --- |
| `:focus-visible` | Pseudo-class | Shows focus ring ONLY on keyboard navigation (not mouse clicks) |
| .sr-only (Screen Reader Only) | Utility Class | Hides text visually while keeping it readable by screen readers |
| `@media (prefers-reduced-motion)` | Preference Query | Disables triggering animations for vestibular disorders |
| `@media (forced-colors: active)` | High Contrast | Adapts styles for Windows High Contrast Mode |
| Color Contrast | WCAG Standard | Requires minimum 4.5:1 contrast ratio for normal text |

**Example:**
```css
/* 1. Beautiful & Accessible Keyboard Focus Indicator */
:focus {
  outline: none; /* Remove default ugly ring */
}

/* Only show focus ring when user navigates with Keyboard (Tab key) */
:focus-visible {
  outline: 3px solid #2563eb;
  outline-offset: 2px;
  border-radius: 4px;
}

/* 2. Standard Screen Reader Only Utility */
.sr-only {
  position: absolute;
  width: 1px;
  height: 1px;
  padding: 0;
  margin: -1px;
  overflow: hidden;
  clip: rect(0, 0, 0, 0);
  white-space: nowrap;
  border: 0;
}

/* 3. Skip to Main Content Link (Visible on focus) */
.skip-link {
  position: absolute;
  top: -40px;
  left: 10px;
  background: #000000;
  color: #ffffff;
  padding: 8px 16px;
  z-index: 1000;
  transition: top 0.2s ease;
}

.skip-link:focus {
  top: 10px;
}
```
