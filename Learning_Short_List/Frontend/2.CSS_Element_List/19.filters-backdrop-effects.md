# 19. FILTERS & BACKDROP EFFECTS (GLASSMORPHISM)

| Property / Function | Values | Description |
| --- | --- | --- |
| `filter: blur()` | `blur(5px)` | Blurs element contents |
| `filter: brightness()` | `brightness(1.2)` | `brightness(80%)` | Adjusts brightness multiplier |
| `filter: contrast()` | `contrast(150%)` | Adjusts visual contrast |
| `filter: grayscale()` | `grayscale(100%)` | Converts element to black and white |
| `filter: hue-rotate()` | `hue-rotate(90deg)` | Rotates hue color angle |
| `filter: drop-shadow()` | `drop-shadow(4px 4px 10px rgba(0,0,0,0.5))` | Casts shadow around non-transparent pixels |
| `backdrop-filter` | `blur(10px) brightness(90%)` | Applies filter effect to area BEHIND element (Glassmorphism) |
| `mix-blend-mode` | `multiply` | `screen` | `overlay` | `difference` | Blends element with its background |
| `background-blend-mode` | `multiply` | `overlay` | Blends multiple backgrounds on same element |

**Example:**
```css
/* Glassmorphism Glass Card */
.glass-panel {
  background: rgba(255, 255, 255, 0.2);
  backdrop-filter: blur(12px) saturate(180%);
  -webkit-backdrop-filter: blur(12px) saturate(180%);
  border: 1px solid rgba(255, 255, 255, 0.3);
  border-radius: 16px;
  padding: 32px;
  box-shadow: 0 8px 32px rgba(0, 0, 0, 0.1);
  color: #1e293b;
}

/* Image Filter Hover Effect */
.gallery-img {
  filter: grayscale(80%) brightness(90%);
  transition: filter 0.3s ease;
  border-radius: 8px;
}

.gallery-img:hover {
  filter: grayscale(0%) brightness(100%);
}

/* SVG Drop Shadow */
.transparent-logo {
  filter: drop-shadow(0 4px 6px rgba(0, 0, 0, 0.25));
}
```
