# 21. TABLES STYLING

| Property | Values | Description |
| --- | --- | --- |
| `border-collapse` | `collapse` | `separate` | Merges adjacent table borders into single border |
| `border-spacing` | `<length>` | Spacing between cell borders (when `border-collapse: separate`) |
| `table-layout` | `auto` | `fixed` | `fixed` speeds up rendering and respects column widths strictly |
| `caption-side` | `top` | `bottom` | Position of `<caption>` element |
| `empty-cells` | `show` | `hide` | Controls rendering of empty table cells |

**Example:**
```css
/* Modern Clean Data Table */
.data-table {
  width: 100%;
  border-collapse: collapse;
  table-layout: fixed;
  font-family: sans-serif;
  text-align: left;
}

.data-table caption {
  caption-side: top;
  font-size: 1.25rem;
  font-weight: 700;
  margin-bottom: 12px;
  color: #1e293b;
}

.data-table th, 
.data-table td {
  padding: 12px 16px;
  border-bottom: 1px solid #e2e8f0;
}

.data-table th {
  background-color: #f8fafc;
  color: #475569;
  font-weight: 600;
  text-transform: uppercase;
  font-size: 0.75rem;
  letter-spacing: 0.05em;
}

/* Zebra Striping */
.data-table tbody tr:nth-child(even) {
  background-color: #f8fafc;
}

.data-table tbody tr:hover {
  background-color: #f1f5f9;
}
```
