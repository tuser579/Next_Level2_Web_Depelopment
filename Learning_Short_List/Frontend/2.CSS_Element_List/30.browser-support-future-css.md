# 30. BROWSER SUPPORT & MODERN CSS FEATURES

| Feature / Selector | Syntax | Description |
| --- | --- | --- |
| `@supports` | `@supports (display: grid) { ... }` | CSS feature query for progressive enhancement |
| `:has()` | `parent:has(child)` | The parent relational selector |
| `:is()` & `:where()` | `:is(h1, h2, h3)` | Groups selectors (`:where` has 0 specificity) |
| `@scope` | `@scope (.card) { ... }` | Scopes styles specifically to a DOM subtree boundary |
| `@starting-style` | `@starting-style { opacity: 0; }` | Animates entry transitions when element changes from `display: none` |
| Vendor Prefixes | `-webkit-`, `-moz-` | Legacy browser engine prefixes |

**Example:**
```css
/* 1. Feature Query with @supports */
.layout {
  display: flex;
}

@supports (display: grid) {
  .layout {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
  }
}

/* 2. Grouping with :is() and :where() */
:where(header, main, footer) p {
  margin-bottom: 1rem; /* 0 specificity: easily overridden */
}

/* 3. Popover / Dialog Entry Animation with @starting-style */
dialog[open] {
  opacity: 1;
  transform: scale(1);
  transition: opacity 0.3s ease, transform 0.3s ease, display 0.3s ease allow-discrete;

  @starting-style {
    opacity: 0;
    transform: scale(0.9);
  }
}
```
