# 4. COLORS & BACKGROUNDS

| Property / Function | Format / Values | Description |
| --- | --- | --- |
| `color` | `<color>` | Text and foreground color |
| Hex format | `#RGB`, `#RRGGBB`, `#RRGGBBAA` | Hexadecimal color with optional alpha |
| `rgb()` / `rgba()` | `rgb(255 0 128 / 0.5)` | Red, Green, Blue with alpha channel |
| `hsl()` / `hsla()` | `hsl(210 100% 50% / 0.8)` | Hue, Saturation, Lightness, Alpha |
| `oklch()` | `oklch(0.6 0.2 250)` | Perceptually uniform modern color space |
| `background-color` | `<color>` | `transparent` | Solid background color |
| `background-image` | `url()`, `linear-gradient()`, `radial-gradient()`, `conic-gradient()` | Background image or CSS gradient |
| `background-repeat` | `repeat` | `no-repeat` | `repeat-x` | `repeat-y` | `space` | `round` | Image tile repetition |
| `background-position` | `center` | `top left` | `x% y%` | `<length>` | Starting position of image |
| `background-size` | `cover` | `contain` | `auto` | `<length>` | Sizing mode of background image |
| `background-attachment` | `scroll` | `fixed` | `local` | Scroll behavior (e.g. parallax with `fixed`) |
| `background-clip` | `border-box` | `padding-box` | `content-box` | `text` | Area where background is painted |

**Example:**
```css
/* Modern Color definitions */
:root {
  --primary-hex: #3b82f6;
  --primary-rgb: rgb(59 130 246 / 0.9);
  --primary-hsl: hsl(217 91% 60%);
  --modern-oklch: oklch(0.65 0.24 260);
}

/* Rich Hero Banner with Gradients and Background */
.hero-banner {
  color: #ffffff;
  background-color: #0f172a;
  background-image: 
    linear-gradient(135deg, rgba(15, 23, 42, 0.8), rgba(59, 130, 246, 0.6)),
    url('hero-bg.webp');
  background-position: center;
  background-size: cover;
  background-repeat: no-repeat;
  background-attachment: fixed;
  padding: 80px 24px;
}

/* Gradient Text Effect with background-clip */
.gradient-heading {
  background: linear-gradient(90deg, #3b82f6, #ec4899);
  -webkit-background-clip: text;
  background-clip: text;
  -webkit-text-fill-color: transparent;
  font-size: 3rem;
  font-weight: 800;
}
```
