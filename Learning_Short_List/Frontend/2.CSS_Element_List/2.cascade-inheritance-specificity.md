# 2. CASCADE, INHERITANCE & SPECIFICITY

| Concept / Rule | Type | Description |
| --- | --- | --- |
| Inline styles (`style="..."`) | Specificity: 1-0-0-0 | Highest normal specificity weight |
| ID selector (`#header`) | Specificity: 0-1-0-0 | Weight of 100 in traditional point systems |
| Class / Attribute / Pseudo-class | Specificity: 0-0-1-0 | `.btn`, `[type=text]`, `:hover` weight |
| Element / Pseudo-element | Specificity: 0-0-0-1 | `p`, `div`, `h1`, `::before` weight |
| Universal (`*`) & `:where()` | Specificity: 0-0-0-0 | Zero specificity contribution |
| `!important` | Cascade Override | Overrides normal cascade order (use sparingly) |
| `inherit` | Keyword | Forces inheritance of property from parent |
| `initial` | Keyword | Resets property to browser default initial value |
| `unset` | Keyword | Acts as `inherit` if inheritable, else `initial` |
| `revert` | Keyword | Rolls back to user-agent or user stylesheet style |
| `@layer` | Cascade Layers | Organizes styles into priority layers regardless of specificity |

**Example:**
```css
/* Specificity hierarchy example: */
/* (0, 0, 0, 1) - Element */
p {
  color: #333333;
}

/* (0, 0, 1, 0) - Class overrides Element */
.text-danger {
  color: #ef4444;
}

/* (0, 1, 0, 0) - ID overrides Class */
#main-banner {
  color: #10b981;
}

/* Keyword value usage */
.child-card {
  color: inherit;       /* Inherit text color from parent */
  margin: initial;      /* Reset margin to default 0 */
  all: unset;           /* Reset all CSS properties */
}

/* Modern Cascade Layers */
@layer reset, base, components, utilities;

@layer base {
  h1 { font-size: 2rem; color: #0f172a; }
}

@layer components {
  .title { font-size: 2.5rem; } /* Takes precedence over @layer base */
}
```
