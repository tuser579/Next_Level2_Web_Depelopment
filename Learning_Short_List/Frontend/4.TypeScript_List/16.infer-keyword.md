# 16. THE 'INFER' KEYWORD IN CONDITIONAL TYPES

| Pattern / Utility | Syntax Example | Description |
| --- | --- | --- |
| `infer` in Return | `T extends (...args: any[]) => infer R ? R : any` | Infers and extracts the return type of a function |
| `infer` in Parameters | `T extends (...args: infer P) => any ? P : never` | Extracts parameter types tuple from a function |
| `infer` in Promises | `T extends Promise<infer U> ? U : T` | Unwraps the inner resolved value type of a Promise (like `Awaited<T>`) |
| `infer` in Arrays | `T extends (infer E)[] ? E : T` | Extracts element type from an array |

**Example:**
```typescript
// 1. Custom ReturnType implementation using infer
type MyReturnType<T> = T extends (...args: any[]) => infer R ? R : never;

function calculateStats(scores: number[]) {
  return { average: 85.5, count: scores.length, passed: true };
}

type StatsResult = MyReturnType<typeof calculateStats>;
// { average: number; count: number; passed: boolean; }

// 2. Unwrapping Promises recursively (similar to built-in Awaited<T>)
type UnwrapPromise<T> = T extends Promise<infer U> ? UnwrapPromise<U> : T;

type Resolved1 = UnwrapPromise<Promise<string>>;             // string
type Resolved2 = UnwrapPromise<Promise<Promise<number[]>>>; // number[]

// 3. Extracting First Element from a Tuple
type Head<T extends any[]> = T extends [infer First, ...any[]] ? First : never;

type FirstArg = Head<[string, number, boolean]>; // string
```
