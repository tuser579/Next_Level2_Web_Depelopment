# 19. BUILT-IN UTILITY TYPES (PART 1)

| Utility Type | Definition | Description |
| --- | --- | --- |
| `Partial<T>` | All optional | Constructs a type with all properties of `T` set to optional (`?`) |
| `Required<T>` | All required | Constructs a type with all properties of `T` set to required (`-?`) |
| `Readonly<T>` | All readonly | Constructs a type with all properties of `T` set to `readonly` |
| `Record<K, T>` | Key-value dictionary | Constructs an object type with property keys `K` and value types `T` |
| `Pick<T, K>` | Pick specific keys | Constructs a type picking the set of properties `K` from `T` |
| `Omit<T, K>` | Drop specific keys | Constructs a type picking all properties from `T` and dropping `K` |

**Example:**
```typescript
interface Product {
  id: number;
  name: string;
  description: string;
  price: number;
  tags?: string[];
}

// 1. Partial<T> (Ideal for patch/update requests)
type UpdateProductInput = Partial<Product>;
function updateProduct(id: number, fields: UpdateProductInput) {
  // Accepts any subset of Product properties
}

// 2. Required<T> (Guarantees every field is present)
type CompleteProduct = Required<Product>; // tags is now required!

// 3. Pick<T, Keys> (Select specific fields for a preview card)
type ProductPreview = Pick<Product, "id" | "name" | "price">;
const card: ProductPreview = { id: 101, name: "Headphones", price: 79.99 };

// 4. Omit<T, Keys> (Create payload omitting auto-generated id)
type CreateProductPayload = Omit<Product, "id">;
const newProduct: CreateProductPayload = {
  name: "Mouse",
  description: "Ergonomic mouse",
  price: 29.99
};

// 5. Readonly<T>
const frozenProduct: Readonly<Product> = {
  id: 1, name: "Keyboard", description: "Mechanical", price: 99
};
// frozenProduct.price = 89; // ❌ Cannot assign to 'price' (read-only)
```
