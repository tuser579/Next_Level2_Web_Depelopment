# 29. DECLARATION FILES (.D.TS) & DEFINITELY TYPED

| Declaration Syntax | Usage | Description |
| --- | --- | --- |
| `declare const` / `let` | Global Variables | Declares global variable provided by external scripts (e.g. CDN script) |
| `declare function` | Global Functions | Declares signatures for external C-style or JS functions |
| `declare namespace` | Library Namespaces | Groups types and functions under legacy library namespace (e.g. `jQuery`) |
| `@types/*` | DefinitelyTyped Packages | Community type definitions installed via npm (e.g. `@types/node`, `@types/lodash`) |

**Example:**
```typescript
// === sample-library.d.ts ===
// Ambient declarations for a legacy JavaScript library loaded via CDN
declare namespace MyChartLib {
  interface ChartOptions {
    width?: number;
    height?: number;
    theme?: "dark" | "light";
  }

  class Chart {
    constructor(canvasId: string, options?: ChartOptions);
    render(): void;
    destroy(): void;
  }

  const version: string;
}

// Global script variable declaration
declare const GOOGLE_MAPS_API_KEY: string;

// Usage in TypeScript project:
const chart = new MyChartLib.Chart("sales-canvas", {
  theme: "dark",
  width: 800
});
chart.render();
```
