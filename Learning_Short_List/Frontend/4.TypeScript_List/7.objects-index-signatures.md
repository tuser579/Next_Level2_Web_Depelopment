# 7. OBJECTS, INDEX SIGNATURES & RECORD

| Feature / Utility | Syntax Example | Description |
| --- | --- | --- |
| Optional Properties | `prop?: string` | Property may be present or `undefined` |
| Readonly Properties | `readonly id: number` | Cannot be reassigned after object initialization |
| Index Signatures | `[key: string]: number` | Allows object to contain arbitrary keys mapping to specific value type |
| `Record<K, V>` | `Record<string, User>` | Clean utility type for dictionaries and maps |
| Excess Property Checking | Object literal assignment check | Disallows unknown properties when assigning raw object literals |

**Example:**
```typescript
// 1. Readonly and Optional Object Properties
interface UserProfile {
  readonly id: string; // Cannot be modified
  username: string;
  email: string;
  bio?: string;        // Optional
}

const profile: UserProfile = {
  id: "usr_789",
  username: "dev_pro",
  email: "dev@example.com"
};
// profile.id = "new_id"; // ❌ Cannot assign to 'id' because it is a read-only property

// 2. Index Signatures (Dynamic key dictionaries)
interface MetricDictionary {
  [metricName: string]: number;
}

const serverMetrics: MetricDictionary = {
  cpuUsage: 45.2,
  memoryUsage: 78.9,
  networkLatencyMs: 12
};

// 3. Record<Keys, ValueType> (Preferred over index signatures)
type Environment = "development" | "staging" | "production";

interface EnvConfig {
  apiUrl: string;
  enableDebug: boolean;
}

const configMap: Record<Environment, EnvConfig> = {
  development: { apiUrl: "http://localhost:3000", enableDebug: true },
  staging: { apiUrl: "https://staging.api.com", enableDebug: true },
  production: { apiUrl: "https://api.com", enableDebug: false }
};
```
