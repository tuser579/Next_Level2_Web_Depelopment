# 25. DECORATORS (STAGE 3 STANDARD)

| Decorator Type | Target | Description |
| --- | --- | --- |
| Class Decorator | `class C` | Wraps or replaces class constructor |
| Method Decorator | `method() {}` | Wraps or modifies method execution logic (e.g. logging, caching) |
| Field Decorator | `field: string` | Modifies field initial value |
| Getter / Setter Decorator | `get prop() {}` | Intercepts accessor reading or writing |

**Example:**
```typescript
// Standard TC39 Class Method Decorator (TS 5.0+)
function loggedMethod(
  target: Function,
  context: ClassMethodDecoratorContext
) {
  const methodName = String(context.name);
  
  return function (this: any, ...args: any[]) {
    console.log(`[CALL]: ${methodName} with args:`, args);
    const result = target.call(this, ...args);
    console.log(`[RESULT]: ${methodName} returned:`, result);
    return result;
  };
}

class OrderService {
  @loggedMethod
  createOrder(item: string, quantity: number): string {
    return `Order #101 created for ${quantity}x ${item}`;
  }
}

const service = new OrderService();
service.createOrder("Mechanical Keyboard", 2);
```
