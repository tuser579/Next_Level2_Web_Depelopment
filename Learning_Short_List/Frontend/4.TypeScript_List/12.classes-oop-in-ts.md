# 12. CLASSES & ACCESS MODIFIERS IN TYPESCRIPT

| Modifier / Keyword | Scope Visibility | Description |
| --- | --- | --- |
| `public` (default) | Everywhere | Freely accessible from outside the class instance |
| `private` | Inside Class Only | Compile-time protection: accessible only within declaring class |
| `protected` | Class & Subclasses | Accessible within declaring class and its child derived classes |
| `readonly` | Immutable | Field can only be assigned in declaration or constructor |
| Parameter Properties | `constructor(public name: string)` | Shorthand declaring and initializing class fields directly in constructor signature |
| `implements` | Contract Check | Enforces class conforms strictly to an interface shape |

**Example:**
```typescript
interface AuthenticatedUser {
  userId: string;
  getAuthToken(): string;
}

class UserAccount implements AuthenticatedUser {
  // Parameter Properties (Declares & initializes fields in 1 line!)
  constructor(
    public readonly userId: string,
    protected email: string,
    private apiKey: string
  ) {}

  public getAuthToken(): string {
    return `auth_${this.apiKey}`;
  }

  protected logSecurityEvent(event: string): void {
    console.log(`User ${this.userId} (${this.email}): ${event}`);
  }
}

class AdminAccount extends UserAccount {
  public revokeUserAccess(): void {
    // Protected members are accessible in subclasses
    this.logSecurityEvent("Access Revoked");
    // this.apiKey; // ❌ Error: 'apiKey' is private to UserAccount
  }
}

const account = new UserAccount("usr_1", "user@test.com", "secret_key");
console.log(account.userId);       // ✅ public readonly
console.log(account.getAuthToken());// ✅ public method
// console.log(account.apiKey);   // ❌ private property
```
