# 18. TEMPLATE LITERAL TYPES & INTRINSICS

| Type / Utility | Syntax Example | Description |
| --- | --- | --- |
| Template Literal Type | `` `${Prefix}_${Suffix}` `` | Constructs new string literal types via template string interpolation |
| `Uppercase<StringType>` | `Uppercase<'hello'>` | Converts string literal type to uppercase (`'HELLO'`) |
| `Lowercase<StringType>` | `Lowercase<'HELLO'>` | Converts string literal type to lowercase (`'hello'`) |
| `Capitalize<StringType>` | `Capitalize<'name'>` | Capitalizes first character (`'Name'`) |
| `Uncapitalize<StringType>` | `Uncapitalize<'Name'>` | Lowercases first character (`'name'`) |

**Example:**
```typescript
// 1. Event Handler Names Generation
type UIEvent = "click" | "hover" | "focus";
type EventHandler = `on${Capitalize<UIEvent>}`; // "onClick" | "onHover" | "onFocus"

// 2. CSS Position / Spacing Combinations
type Vertical = "top" | "bottom";
type Horizontal = "left" | "right";
type Alignment = `${Vertical}-${Horizontal}`; 
// "top-left" | "top-right" | "bottom-left" | "bottom-right"

// 3. Strongly Typed Dot-Notation Access Paths
type Entity = "user" | "post";
type Action = "create" | "update" | "delete";
type PermissionString = `${Entity}:${Action}`; 
// "user:create" | "user:update" | "user:delete" | "post:create" ...

function checkPermission(permission: PermissionString): boolean {
  return true;
}

checkPermission("user:create"); // ✅ Valid!
// checkPermission("user:read");   // ❌ Error: Argument not assignable
```
