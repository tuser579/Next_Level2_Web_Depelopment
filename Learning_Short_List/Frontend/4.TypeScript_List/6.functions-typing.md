# 6. FUNCTIONS & FUNCTION OVERLOADS

| Feature | Syntax Example | Description |
| --- | --- | --- |
| Typed Parameters & Return | `function add(a: number, b: number): number` | Type definitions for inputs and output |
| Optional Parameters | `function log(msg: string, tag?: string)` | Parameter marked with `?` is optional (`tag: string | undefined`) |
| Default Parameters | `function calc(val: number, rate = 0.05)` | Inferred type from default value |
| Rest Parameters | `function sum(...nums: number[])` | Collects arguments into a typed array |
| Function Type Signatures | `type Callback = (data: string) => void;` | Reusable type definition for function callbacks |
| Function Overloads | Multiple overload signatures + 1 implementation | Allows function to accept different argument combinations and return differing types safely |

**Example:**
```typescript
// 1. Typed Function Signatures
type MathOperation = (x: number, y: number) => number;

const multiply: MathOperation = (x, y) => x * y;

// 2. Optional and Rest parameters
function formatGreeting(name: string, prefix?: string, ...tags: string[]): string {
  const p = prefix ? `${prefix} ` : "";
  const t = tags.length ? ` [${tags.join(", ")}]` : "";
  return `${p}Hello, ${name}!${t}`;
}

// 3. Function Overloads (Different parameters -> Different return types)
// Overload Signatures:
function getInfo(id: number): { id: number; name: string };
function getInfo(name: string): { id: number; name: string }[];
// Implementation Signature:
function getInfo(query: number | string): any {
  if (typeof query === "number") {
    return { id: query, name: `User_${query}` };
  }
  return [{ id: 1, name: query }];
}

const singleUser = getInfo(42);       // Inferred as: { id: number; name: string }
const userList = getInfo("Sarah");    // Inferred as: { id: number; name: string }[]
```
