# 17. MAPPED TYPES & KEY REMAPPING

| Feature / Modifier | Syntax | Description |
| --- | --- | --- |
| Mapped Type | `[K in keyof T]: T[K]` | Iterates over keys of `T` to construct new property types |
| Add/Remove `readonly` | `+readonly` or `-readonly` | Makes all properties read-only or removes read-only constraint |
| Add/Remove Optional `?` | `+?` or `-?` | Makes all properties optional or required (`-?`) |
| Key Remapping via `as` | `[K in keyof T as NewKey]: T[K]` | Filters or renames property keys using template literal types |

**Example:**
```typescript
interface User {
  id: string;
  name: string;
  age?: number;
  readonly createdAt: Date;
}

// 1. Custom Partial & Readonly mapped types
type CustomPartial<T> = {
  [K in keyof T]?: T[K]; // Add optional to all
};

type CustomMutable<T> = {
  -readonly [K in keyof T]: T[K]; // Remove readonly
};

// 2. Key Remapping using 'as' & Template Literals (Getters Generator)
type Getters<T> = {
  [K in keyof T as `get${Capitalize<string & K>}`]: () => T[K];
};

type UserGetters = Getters<User>;
/* Inferred as:
{
  getId: () => string;
  getName: () => string;
  getAge: () => number | undefined;
  getCreatedAt: () => Date;
} */
```
