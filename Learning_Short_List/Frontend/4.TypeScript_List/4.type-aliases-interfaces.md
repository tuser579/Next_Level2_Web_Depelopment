# 4. TYPE ALIASES & INTERFACES

| Feature | `type` Alias | `interface` |
| --- | --- | --- |
| Definition Syntax | `type User = { ... }` | `interface User { ... }` |
| Extensibility | Extends via Intersection (`&`) | Extends via `extends` keyword |
| Declaration Merging | ❌ Duplicate identifier error | ✅ Merges automatically across declarations |
| Union & Primitives | ✅ `type ID = string | number;` | ❌ Cannot directly declare union or primitive alias |
| Tuples & Functions | ✅ Natural concise syntax | ✅ Supported via callable signatures |
| Implementation in Classes | ✅ `class C implements Type` | ✅ `class C implements Interface` |

**Example:**
```typescript
// 1. Interface Declaration & Extension
interface Vehicle {
  brand: string;
  year: number;
}

interface Car extends Vehicle {
  doorsCount: number;
  isElectric: boolean;
}

const tesla: Car = {
  brand: "Tesla",
  year: 2024,
  doorsCount: 4,
  isElectric: true
};

// 2. Declaration Merging in Interfaces (Useful for extending 3rd-party libs)
interface WindowConfig {
  theme: string;
}
interface WindowConfig {
  debugMode: boolean; // Automatically merged into WindowConfig!
}

const config: WindowConfig = { theme: "dark", debugMode: true };

// 3. Type Aliases (Unions, Intersections, Complex shapes)
type ID = string | number;

type Timestamps = {
  createdAt: Date;
  updatedAt: Date;
};

type UserProfile = {
  id: ID;
  username: string;
} & Timestamps; // Intersection (&)

const user: UserProfile = {
  id: "usr_101",
  username: "alex_dev",
  createdAt: new Date(),
  updatedAt: new Date()
};
```
