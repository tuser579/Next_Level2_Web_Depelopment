# 14. KEYOF, TYPEOF & INDEXED ACCESS TYPES

| Operator / Pattern | Type Operation | Description |
| --- | --- | --- |
| `keyof T` | Type Operator | Produces a union of string/numeric literal types representing keys of `T` |
| `typeof val` (in type space) | Type Query | Captures the TypeScript type of an existing variable or value |
| `Type[Key]` | Indexed Access | Looks up the exact type of a specific property on another type |
| `ArrayType[number]` | Element Access | Extracts the union type of all elements in an array or tuple |

**Example:**
```typescript
// 1. typeof type query (Inferring type from constant data)
const appConfig = {
  endpoint: "https://api.cloud.com",
  maxRetries: 3,
  debug: false
};

type AppConfig = typeof appConfig; 
// Inferred as: { endpoint: string; maxRetries: number; debug: boolean; }

// 2. keyof operator
type ConfigKey = keyof AppConfig; 
// "endpoint" | "maxRetries" | "debug"

// 3. Indexed Access Types
interface DatabaseRecord {
  id: string;
  metadata: {
    createdAt: Date;
    author: { name: string; email: string };
  };
  tags: string[];
}

type MetadataType = DatabaseRecord["metadata"];
type AuthorType = DatabaseRecord["metadata"]["author"]; // { name: string; email: string; }
type TagType = DatabaseRecord["tags"][number];           // string
```
