# 24. TSCONFIG & COMPILER OPTIONS

| Compiler Option | Recommended Value | Description |
| --- | --- | --- |
| `strict` | `true` | Enables all strict type-checking flags simultaneously |
| `target` | `"ES2022"` / `"ESNext"` | Specifies ECMAScript target output version |
| `module` & `moduleResolution` | `"NodeNext"` / `"Bundler"` | Specifies module code generation and resolution strategy (Vite/Next.js use `"Bundler"`) |
| `noImplicitAny` | `true` | Errors on expressions and declarations with implied `any` type |
| `strictNullChecks` | `true` | Treats `null` and `undefined` as distinct separate types |
| `noUncheckedIndexedAccess` | `true` | Adds `undefined` to index access lookups for enhanced safety |
| `skipLibCheck` | `true` | Skips type checking of all `.d.ts` declaration files for fast builds |

**Example:**
```typescript
// Standard Recommended Production tsconfig.json
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "ESNext",
    "moduleResolution": "Bundler",
    "lib": ["DOM", "DOM.Iterable", "ESNext"],
    
    /* Strict Type-Checking */
    "strict": true,
    "noImplicitAny": true,
    "strictNullChecks": true,
    "noUncheckedIndexedAccess": true,
    "noImplicitOverride": true,
    
    /* Emit & Build Performance */
    "noEmit": true,
    "isolatedModules": true,
    "skipLibCheck": true,
    "forceConsistentCasingInFileNames": true,
    
    /* Path Aliases */
    "baseUrl": ".",
    "paths": {
      "@/*": ["src/*"]
    }
  },
  "include": ["src/**/*"]
}
```
