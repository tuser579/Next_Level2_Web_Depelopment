# 22. THE 'SATISFIES' OPERATOR (TS 4.9+)

| Feature | `satisfies` | Type Annotation (`: Type`) |
| --- | --- | --- |
| Type Validation | ✅ Validates structure against type | ✅ Validates structure against type |
| Type Narrowing / Inference | ✅ Preserves EXACT literal and specific types | ❌ Widens type to general interface type definition |
| Property Autocomplete | ✅ Retains exact property keys and values | ❌ Restricts properties to declared interface keys |

**Example:**
```typescript
type RGB = [red: number, green: number, blue: number];
type Color = string | RGB;

type Palette = Record<"primary" | "secondary" | "accent", Color>;

// Using 'satisfies': Validates Palette contract WITHOUT widening types!
const themeColors = {
  primary: "#3b82f6",
  secondary: [240, 240, 240],
  accent: "coral"
} satisfies Palette;

// ✅ TypeScript remembers that primary is a STRING:
console.log(themeColors.primary.toUpperCase()); // Works!

// ✅ TypeScript remembers that secondary is an RGB TUPLE:
console.log(themeColors.secondary.map(v => v / 2)); // Works!

/* If we used type annotation (: Palette) instead:
   themeColors.primary would be (string | RGB), and .toUpperCase() would ERROR! */
```
