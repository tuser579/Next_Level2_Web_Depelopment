# 1. PRIMITIVE TYPES & TYPE INFERENCE

| Type / Feature | Syntax Example | Description |
| --- | --- | --- |
| `string` | `let name: string = 'Alex';` | Textual data |
| `number` | `let count: number = 42;` | Integers and floating-point values |
| `boolean` | `let isActive: boolean = true;` | Boolean `true` or `false` |
| `bigint` | `let big: bigint = 100n;` | Arbitrary large integers |
| `symbol` | `let sym: symbol = Symbol('key');` | Unique identifier values |
| `null` & `undefined` | `let n: null = null;` | Absence of value (strictly checked under `strictNullChecks`) |
| Literal Types | `let dir: 'left' | 'right' = 'left';` | Exact value used as a specific type |
| Type Inference | `let age = 25; // number inferred` | TypeScript automatically deduces types without explicit annotations |

**Example:**
```typescript
// 1. Explicit Type Annotations
const appName: string = "TaskManager Pro";
const version: number = 2.4;
const isProduction: boolean = true;
const maxRequests: bigint = 9007199254740991n;

// 2. Type Inference (TypeScript deduces the type automatically)
let userCount = 150; // Inferred as number
// userCount = "150"; // ❌ Type 'string' is not assignable to type 'number'

// 3. Literal Types (Specific exact values)
type ThemeMode = "light" | "dark" | "system";
let currentTheme: ThemeMode = "dark";
// currentTheme = "blue"; // ❌ Type '"blue"' is not assignable to type 'ThemeMode'

// 4. Null & Undefined handling under strictNullChecks
let optionalBio: string | null = null;
optionalBio = "Senior Full-Stack Engineer";
```
