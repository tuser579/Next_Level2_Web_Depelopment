# 13. ABSTRACT CLASSES & GETTERS / SETTERS

| Feature / Keyword | Type | Description |
| --- | --- | --- |
| `abstract class` | Class Modifier | Base blueprint class that cannot be instantiated directly (`new Base()`) |
| `abstract method()` | Method Signature | Method contract that must be implemented by concrete derived subclasses |
| `override` | Method Keyword | Explicitly declares that a method overrides a base class method (under `noImplicitOverride`) |
| `get` / `set` | Accessors | Encapsulates property reading/writing with typed signatures |

**Example:**
```typescript
// 1. Abstract Base Class
abstract class PaymentProcessor {
  constructor(public readonly currency: string) {}

  // Concrete method shared by all processors
  formatAmount(amount: number): string {
    return `${amount.toFixed(2)} ${this.currency}`;
  }

  // Abstract method: MUST be implemented by subclasses
  abstract processPayment(amount: number): Promise<boolean>;
}

// 2. Concrete Subclass with 'override'
class StripeProcessor extends PaymentProcessor {
  private _apiKey: string = "sk_test_123";

  // Getter / Setter with type annotations
  get isConfigured(): boolean {
    return this._apiKey.startsWith("sk_");
  }

  override async processPayment(amount: number): Promise<boolean> {
    console.log(`Processing Stripe payment for ${this.formatAmount(amount)}`);
    return true;
  }
}

// const p = new PaymentProcessor("USD"); // ❌ Cannot create an instance of an abstract class
const stripe = new StripeProcessor("USD");
stripe.processPayment(99.5);
```
