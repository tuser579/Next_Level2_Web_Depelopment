# 15. CONDITIONAL TYPES

| Syntax / Concept | Form | Description |
| --- | --- | --- |
| Conditional Type | `T extends U ? X : Y` | Selects type `X` if `T` is assignable to `U`, else selects `Y` |
| Distributive Conditional | `T extends U ? X : Y` over naked union | Automatically distributes across union types (`(A | B) extends U => (A extends U) | (B extends U)`) |
| Type Filtering | `T extends Function ? never : T` | Filters out unwanted types from union by mapping to `never` |

**Example:**
```typescript
// 1. Basic Conditional Type
type IsString<T> = T extends string ? "Yes, it is a string" : "No, other type";

type Test1 = IsString<"hello">; // "Yes, it is a string"
type Test2 = IsString<123>;     // "No, other type"

// 2. Distributive Type Filtering
type NonNullableCustom<T> = T extends null | undefined ? never : T;

type InputTypes = string | number | null | undefined | boolean;
type CleanedTypes = NonNullableCustom<InputTypes>;
// string | number | boolean (null & undefined mapped to never and dropped!)

// 3. Dynamic Function Return Type
type ApiResponsePayload<T> = T extends "users"
  ? { id: number; name: string }[]
  : T extends "config"
  ? { theme: string; version: number }
  : unknown;

function fetchApi<T extends "users" | "config">(resource: T): ApiResponsePayload<T> {
  // Implementation
  return {} as any;
}

const users = fetchApi("users");   // Inferred as: { id: number; name: string }[]
const config = fetchApi("config"); // Inferred as: { theme: string; version: number }
```
