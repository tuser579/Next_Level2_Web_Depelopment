# 3. ARRAYS, TUPLES & ENUMS

| Structure | Syntax Example | Description |
| --- | --- | --- |
| Array | `number[]` or `Array<number>` | Homogeneous collection of elements |
| Readonly Array | `readonly string[]` or `ReadonlyArray<string>` | Immutable array where mutating methods (`push`, `splice`) are forbidden |
| Tuple | `[string, number, boolean?]` | Fixed-length array where each element index has a predetermined type |
| Named Tuple | `[id: number, name: string]` | Tuple with descriptive labels for each element position |
| Numeric Enum | `enum Status { Active = 1, Inactive }` | Named constants mapped to numbers with bidirectional lookup |
| String Enum | `enum Role { Admin = 'ADMIN' }` | Named constants mapped to string values |
| `const enum` | `const enum Direction { Up, Down }` | Inlined directly during compilation for zero runtime overhead |

**Example:**
```typescript
// 1. Arrays & Readonly Arrays
const scores: number[] = [85, 92, 78];
const permissions: readonly string[] = ["READ", "WRITE"];
// permissions.push("DELETE"); // ❌ Property 'push' does not exist on 'readonly string[]'

// 2. Named Tuples (Ideal for coordinates, key-value pairs, useState patterns)
type LatLng = [latitude: number, longitude: number];
const location: LatLng = [37.7749, -122.4194];

type ResponseState = [data: string | null, isLoading: boolean];
const apiState: ResponseState = ["Fetched payload", false];

// 3. Enums (Numeric & String)
enum HttpStatus {
  OK = 200,
  BadRequest = 400,
  Unauthorized = 401,
  NotFound = 404
}

const responseStatus: HttpStatus = HttpStatus.OK;

// 4. Const Enum (Zero runtime overhead - inlined at compile time)
const enum Direction {
  Up = "UP",
  Down = "DOWN",
  Left = "LEFT",
  Right = "RIGHT"
}

const move = Direction.Up; // Compiles directly to: const move = "UP";
```
