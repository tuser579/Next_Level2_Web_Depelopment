# 23. MODULES, TYPE-ONLY IMPORTS & AMBIENT TYPES

| Feature | Syntax | Description |
| --- | --- | --- |
| Type-Only Import | `import type { User } from './user';` | Import stripped completely at compile time; guarantees zero runtime JS emission |
| Inline Type Import | `import { login, type User } from './auth';` | Imports both JS values and pure types in a single statement |
| Ambient Module Declaration | `declare module '*.svg' { ... }` | Defines types for assets/non-TS files (CSS, SVG, Images) |
| `declare global` | `declare global { ... }` | Augments global scope objects (e.g. `window`, `process.env`) |

**Example:**
```typescript
// === 1. Type-only imports ===
import type { DatabaseConfig } from "./db.js";
import { connectDB, type ConnectionState } from "./db.js";

// === 2. Ambient Module Declarations (e.g. in globals.d.ts) ===
// Allows importing SVG and CSS files in TypeScript without error
declare module "*.svg" {
  const content: string;
  export default content;
}

declare module "*.module.css" {
  const classes: { readonly [key: string]: string };
  export default classes;
}

// === 3. Augmenting global window / NodeJS process ===
declare global {
  interface Window {
    analyticsTracker: {
      trackEvent(name: string, payload: Record<string, unknown>): void;
    };
  }
}

// Usage in application:
window.analyticsTracker?.trackEvent("user_signup", { plan: "pro" });
```
