# 20. BUILT-IN UTILITY TYPES (PART 2)

| Utility Type | Definition | Description |
| --- | --- | --- |
| `Exclude<T, U>` | Set Difference | Excludes from union `T` all union members assignable to `U` |
| `Extract<T, U>` | Set Intersection | Extracts from union `T` all union members assignable to `U` |
| `NonNullable<T>` | Null/Undefined removal | Constructs a type excluding `null` and `undefined` from `T` |
| `ReturnType<T>` | Function Return | Extracts the return type of function type `T` |
| `Parameters<T>` | Function Parameters | Extracts parameters of function type `T` in a tuple |
| `Awaited<T>` | Promise unwrap | Recursively unwraps the resolved type of a Promise / thenable |

**Example:**
```typescript
// 1. Exclude<T, U> and Extract<T, U>
type Status = "draft" | "review" | "published" | "archived" | "deleted";

type ActiveStatus = Exclude<Status, "archived" | "deleted">; 
// "draft" | "review" | "published"

type InactiveStatus = Extract<Status, "archived" | "deleted">; 
// "archived" | "deleted"

// 2. ReturnType<T> and Parameters<T>
function createUser(name: string, role: "admin" | "user", isActive = true) {
  return { id: Math.random(), name, role, isActive, createdAt: new Date() };
}

type UserType = ReturnType<typeof createUser>;
type UserParams = Parameters<typeof createUser>; // [name: string, role: "admin" | "user", isActive?: boolean]

// 3. Awaited<T> (Unwrapping async operations)
async function fetchAccount() {
  return { accountId: "acc_99", balance: 5400 };
}

type Account = Awaited<ReturnType<typeof fetchAccount>>; 
// Inferred as: { accountId: string; balance: number; }
```
