# 2. OPERATORS & EXPRESSIONS

| Operator | Name | Description |
| --- | --- | --- |
| `+`, `-`, `*`, `/`, `%`, `**` | Arithmetic | Add, subtract, multiply, divide, modulus (remainder), exponentiation |
| `===` vs `==` | Strict vs Loose Equality | `===` compares value & type without coercion; `==` coerces types (avoid) |
| `!==` vs `!=` | Strict vs Loose Inequality | `!==` strict inequality; `!=` loose inequality |
| `&&` | Logical AND | Returns first falsy value, or last value if all truthy (short-circuit) |
| `||` | Logical OR | Returns first truthy value, or last value if all falsy |
| `??` | Nullish Coalescing | Returns right-hand side ONLY if left is `null` or `undefined` (unlike `||`) |
| `?.` | Optional Chaining | Safely accesses nested object properties without throwing TypeError if null/undefined |
| `? :` | Ternary Operator | Inline conditional: `condition ? ifTrue : ifFalse` |
| `...` | Spread / Rest | Spreads elements or collects rest parameters into an array |
| `+=`, `-=`, `*=`, `/=` | Compound Assignment | Performs operation and reassigns variable in place |

**Example:**
```javascript
// Strict equality vs Loose equality
console.log(5 === "5");  // false (different types)
console.log(5 == "5");   // true (type coercion - avoid!)

// Nullish Coalescing (??) vs Logical OR (||)
const count = 0;
console.log(count || 10);  // 10 (because 0 is falsy)
console.log(count ?? 10);  // 0  (0 is NOT null or undefined)

// Optional Chaining (?.)
const user = { profile: { address: null } };
const street = user?.profile?.address?.street ?? "No street provided";
console.log(street); // "No street provided" (does not throw error!)

// Ternary Operator
const status = age >= 18 ? "Adult" : "Minor";

// Spread Operator
const arr1 = [1, 2];
const arr2 = [...arr1, 3, 4]; // [1, 2, 3, 4]
const mergedUser = { ...user, active: true };
```
