# 28. GENERATORS & ITERATOR PROTOCOLS

| Syntax / Protocol | Type | Description |
| --- | --- | --- |
| `function* name() {}` | Generator Function | Defines generator function that can yield execution and resume |
| `yield value` | Keyword | Pauses generator execution and returns value to caller |
| `yield* iterable` | Delegation | Delegates iteration to another generator or iterable |
| `gen.next(val)` | Method | Resumes generator, returning `{ value, done }` |
| `[Symbol.iterator]` | Protocol | Custom method making any object iterable in `for...of` loops |
| Async Generators | `async function*` | Yields promises over time; consumed via `for await...of` |

**Example:**
```javascript
// 1. Infinite ID Generator
function* idGenerator(start = 1) {
  let id = start;
  while (true) {
    yield id++;
  }
}

const gen = idGenerator(100);
console.log(gen.next().value); // 100
console.log(gen.next().value); // 101
console.log(gen.next().value); // 102

// 2. Custom Iterable Object with [Symbol.iterator]
const todoCollection = {
  todos: ["Learn JS", "Build Project", "Deploy App"],
  *[Symbol.iterator]() {
    for (const todo of this.todos) {
      yield `📝 ${todo}`;
    }
  }
};

for (const item of todoCollection) {
  console.log(item);
}
// "📝 Learn JS"
// "📝 Build Project"
// "📝 Deploy App"
```
