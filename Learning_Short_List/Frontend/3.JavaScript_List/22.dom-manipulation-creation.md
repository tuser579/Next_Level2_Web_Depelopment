# 22. DOM CREATION & MANIPULATION

| Method | Target | Description |
| --- | --- | --- |
| `document.createElement(tag)` | Factory | Creates new DOM element in memory |
| `element.append(...nodes/strings)` | Insertion | Appends elements or text strings at the end of parent |
| `element.prepend(...nodes/strings)` | Insertion | Prepends elements or text strings at the beginning |
| `element.before()` / `element.after()` | Insertion | Inserts nodes immediately before or after element as siblings |
| `element.remove()` | Removal | Removes element directly from DOM tree |
| `element.replaceWith(newNode)` | Replacement | Replaces element with another node |
| `document.createDocumentFragment()` | Performance | Lightweight memory container for batch inserting multiple DOM nodes |
| `element.innerHTML` vs `element.textContent` | Content | `textContent` is safe against XSS; `innerHTML` parses HTML |

**Example:**
```javascript
// 1. High-Performance batch insertion using DocumentFragment
const userList = document.querySelector("#user-list");
const fragment = document.createDocumentFragment();

const users = ["Emma Watson", "John Krasinski", "Cillian Murphy"];

users.forEach((name) => {
  const li = document.createElement("li");
  li.className = "user-item";
  li.textContent = name; // Safe against XSS!

  const btn = document.createElement("button");
  btn.textContent = "Remove";
  btn.onclick = () => li.remove(); // Simple removal

  li.append(" - ", btn);
  fragment.append(li);
});

// Single DOM reflow!
userList.append(fragment);
```
