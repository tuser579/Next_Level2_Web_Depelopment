# 30. MODERN JAVASCRIPT FEATURES (ES2020 - ES2026+)

| Feature | Standard | Description |
| --- | --- | --- |
| Optional Chaining `?.` & Nullish `??` | ES2020 | Safe navigation and precise null/undefined checks |
| `Promise.allSettled()` | ES2020 | Resilient parallel promise handling |
| Logical Assignment `&&=`, `\|\|=`, `??=` | ES2021 | Assigns value conditionally in place |
| `String.prototype.replaceAll()` | ES2021 | Replaces all matching occurrences cleanly |
| `Array.prototype.at()` | ES2022 | Index lookup supporting negative indices (`.at(-1)`) |
| `Object.hasOwn()` | ES2022 | Safe property ownership check |
| Non-mutating Array Methods (`toSorted`, `toReversed`, `toSpliced`) | ES2023 | Immutable array transformations |
| `Promise.withResolvers()` | ES2024 | Exposes resolve and reject handlers alongside promise |
| `Object.groupBy()` / `Map.groupBy()` | ES2024 | Groups array items by callback key without manual reduce |

**Example:**
```javascript
// 1. Array.prototype.toSorted() & toReversed() (Immutable!)
const originalList = [3, 1, 4, 1, 5];
const sortedList = originalList.toSorted((a, b) => a - b);
console.log("Sorted:", sortedList);     // [1, 1, 3, 4, 5]
console.log("Original:", originalList); // [3, 1, 4, 1, 5] (Untouched!)

// 2. Object.groupBy() (ES2024)
const inventory = [
  { name: "Asparagus", type: "vegetable" },
  { name: "Banana", type: "fruit" },
  { name: "Carrot", type: "vegetable" },
  { name: "Apple", type: "fruit" }
];

const grouped = Object.groupBy(inventory, item => item.type);
console.log(grouped);
/* {
     vegetable: [{ name: "Asparagus"... }, { name: "Carrot"... }],
     fruit: [{ name: "Banana"... }, { name: "Apple"... }]
   } */

// 3. Logical Assignment Operators
let options = { timeout: 0 };
options.timeout ??= 3000; // timeout is 0 (not null/undefined), so remains 0!
options.retries ??= 5;    // retries was undefined, so gets set to 5!
console.log(options);     // { timeout: 0, retries: 5 }
```
