# 13. DESTRUCTURING, REST & SPREAD

| Feature / Syntax | Target | Description |
| --- | --- | --- |
| Array Destructuring | `const [a, b, ...rest] = arr;` | Unpacks elements from arrays by position index |
| Object Destructuring | `const { prop, key: alias, def = 5 } = obj;` | Unpacks properties from objects by key name |
| Nested Destructuring | `const { user: { email } } = data;` | Destructures deeply nested object/array trees directly |
| Rest in Functions | `function fn(first, ...others) {}` | Gathers remaining parameters into an array |
| Spread in Arrays | `[...arr1, ...arr2]` | Expands iterable elements inside a new array |
| Spread in Objects | `{ ...obj1, key: 'new' }` | Copies own enumerable properties into a new object |

**Example:**
```javascript
// 1. Array Destructuring with Swap & Rest
const coords = [10, 20, 30, 40];
const [x, y, ...extra] = coords;
console.log(x, y);      // 10, 20
console.log(extra);     // [30, 40]

// Swap variables without temporary var
let first = "A", second = "B";
[first, second] = [second, first];
console.log(first, second); // "B", "A"

// 2. Object Destructuring with Aliasing and Defaults
const person = {
  firstName: "Elena",
  role: "Lead Architect",
  address: { city: "Stockholm", country: "Sweden" }
};

const { 
  firstName: name,              // Rename to 'name'
  role, 
  status = "Active",            // Default value if undefined
  address: { city }             // Nested extraction
} = person;

console.log(`${name} (${role}) lives in ${city}. Status: ${status}`);

// 3. Immutably updating state with Object Spread
const updatedPerson = {
  ...person,
  role: "CTO",                  // Override existing key
  lastPromoted: "2026-08-28"    // Add new key
};
```
