# 18. ASYNC JS & THE EVENT LOOP

| Component / API | Priority Order | Description |
| --- | --- | --- |
| Call Stack | Priority 1 (Synchronous) | Executes synchronous function frames in LIFO order |
| Microtask Queue | Priority 2 (High Priority) | Promises (`.then()`, `async/await`), `queueMicrotask()`, `MutationObserver` |
| Task Queue (Macrotask) | Priority 3 (Standard) | `setTimeout()`, `setInterval()`, `setImmediate()`, I/O events, DOM clicks |
| `queueMicrotask(fn)` | Microtask Dispatch | Schedules microtask to run immediately after current script completes |
| `setTimeout(fn, delay)` | Timer API | Schedules macrotask callback after minimum delay in milliseconds |
| `requestAnimationFrame(fn)` | Render Step | Runs callback before browser's next screen repaint (60/120fps) |

**Example:**
```javascript
// Event Loop Execution Order Challenge:
console.log("1. Synchronous Start");

setTimeout(() => {
  console.log("4. Macrotask (setTimeout)");
}, 0);

Promise.resolve().then(() => {
  console.log("3. Microtask (Promise .then)");
});

queueMicrotask(() => {
  console.log("3.5. Microtask (queueMicrotask)");
});

console.log("2. Synchronous End");

/* Output Order:
   1. Synchronous Start
   2. Synchronous End
   3. Microtask (Promise .then)
   3.5. Microtask (queueMicrotask)
   4. Macrotask (setTimeout)
*/
```
