# 20. ASYNC / AWAIT & TOP-LEVEL AWAIT

| Keyword / Pattern | Type | Description |
| --- | --- | --- |
| `async function` | Declaration | Wraps returned values automatically in a `Promise` |
| `await` | Operator | Pauses function execution until Promise settles (only inside async/modules) |
| Sequential Await | Pattern | `await p1; await p2;` (runs sequentially, takes sum of times) |
| Concurrent Await | Pattern | `await Promise.all([p1, p2])` (runs concurrently in parallel) |
| Top-Level Await | ES2022 Feature | Allows `await` at root level of ES Modules without wrapping in async function |

**Example:**
```javascript
// 1. Modern Async/Await with try/catch error handling
async function loadDashboardData(userId) {
  try {
    console.log("Fetching dashboard data...");
    
    // Concurrent fetching (Runs in PARALLEL!)
    const [userRes, postsRes] = await Promise.all([
      fetch(`https://jsonplaceholder.typicode.com/users/${userId}`),
      fetch(`https://jsonplaceholder.typicode.com/posts?userId=${userId}`)
    ]);

    if (!userRes.ok || !postsRes.ok) {
      throw new Error("Network request failed");
    }

    const user = await userRes.json();
    const posts = await postsRes.json();

    return { user, postsCount: posts.length };
  } catch (error) {
    console.error("Dashboard Load Error:", error.message);
    return null;
  }
}

// 2. Invoking async function
loadDashboardData(1).then((data) => console.log("Dashboard:", data));
```
