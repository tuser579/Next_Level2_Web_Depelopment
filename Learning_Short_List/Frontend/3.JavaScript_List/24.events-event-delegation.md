# 24. EVENTS & EVENT DELEGATION

| Concept / Method | Type | Description |
| --- | --- | --- |
| `addEventListener(event, fn, opts)` | Method | Registers event listener with options (`{ once: true, capture: true }`) |
| `removeEventListener(event, fn)` | Method | Removes registered listener (requires exact function reference) |
| `event.target` | Property | The exact deepest DOM element that triggered the event |
| `event.currentTarget` | Property | The element to which the event listener is attached |
| `event.preventDefault()` | Method | Prevents default browser action (e.g. form submission, link navigation) |
| `event.stopPropagation()` | Method | Stops event from bubbling up the DOM tree |
| Event Delegation | Pattern | Attaching a single listener to a parent to handle events on current and future children |

**Example:**
```javascript
// 1. Standard Event Handling with preventDefault
const form = document.querySelector("#signup-form");
form.addEventListener("submit", (e) => {
  e.preventDefault(); // Stop page reload
  console.log("Form submitted via AJAX!");
});

// 2. High-Performance Event Delegation Pattern
// Attach ONE listener on parent table instead of 1,000 listeners on every row button!
const table = document.querySelector("#data-table");

table.addEventListener("click", (e) => {
  // Check if a delete button was clicked
  const deleteBtn = e.target.closest(".btn-delete");
  if (!deleteBtn) return; // Ignore clicks elsewhere

  const row = deleteBtn.closest("tr");
  const itemId = deleteBtn.dataset.id;
  
  console.log(`Deleting item ID: ${itemId}`);
  row.remove();
});
```
