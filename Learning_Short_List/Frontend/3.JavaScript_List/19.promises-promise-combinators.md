# 19. PROMISES & PROMISE COMBINATORS

| Method / Combinator | Fulfillment Condition | Rejection Condition |
| --- | --- | --- |
| `new Promise((res, rej) => ...)` | Constructor | Represents eventual completion or failure of an async operation |
| `Promise.all([...])` | When ALL promises resolve | Rejects immediately on the FIRST rejected promise (all-or-nothing) |
| `Promise.allSettled([...])` | When ALL settle (never rejects) | Returns array of `{ status, value/reason }` for all promises |
| `Promise.race([...])` | First promise to SETTLE (resolve or reject) | Rejects if fastest promise rejects |
| `Promise.any([...])` | First promise to RESOLVE successfully | Rejects ONLY if ALL promises fail (`AggregateError`) |
| `Promise.withResolvers()` | Modern Utility | Returns `{ promise, resolve, reject }` without nesting executor function |

**Example:**
```javascript
// 1. Creating a Promise
const fetchUser = (id) => {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      id > 0 ? resolve({ id, name: "Alex" }) : reject(new Error("Invalid ID"));
    }, 300);
  });
};

// 2. Promise Combinators
const p1 = Promise.resolve("Data from Cache");
const p2 = fetchUser(1);
const p3 = new Promise((resolve) => setTimeout(() => resolve("Config Loaded"), 100));

// Promise.all (Wait for all to succeed)
Promise.all([p1, p2, p3])
  .then(([cache, user, config]) => {
    console.log("All succeeded:", cache, user, config);
  })
  .catch((err) => console.error("One failed:", err));

// Promise.allSettled (Resilient - guarantees results for all)
Promise.allSettled([fetchUser(1), fetchUser(-1)]).then((results) => {
  results.forEach((res) => {
    if (res.status === "fulfilled") {
      console.log("Success:", res.value);
    } else {
      console.log("Failed:", res.reason.message);
    }
  });
});
```
