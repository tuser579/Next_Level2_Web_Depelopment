# 3. CONTROL FLOW & CONDITIONALS

| Statement / Concept | Type | Description |
| --- | --- | --- |
| `if...else if...else` | Conditional | Executes block of code if condition resolves truthy |
| `switch...case` | Multi-branch | Evaluates expression against multiple `case` values (`break` required) |
| Truthy values | Evaluation | Everything not falsy (e.g. `"hello"`, `42`, `[]`, `{}`, `true`) |
| Falsy values | Evaluation | `false`, `0`, `-0`, `0n`, `""`, `null`, `undefined`, `NaN` |
| Short-circuit execution | Pattern | Executes function/expression only if condition holds: `isLoggedIn && showModal()` |

**Example:**
```javascript
// 1. if...else if...else
const role = "admin";

if (role === "admin") {
  console.log("Full access granted");
} else if (role === "editor") {
  console.log("Edit access granted");
} else {
  console.log("View-only access");
}

// 2. switch statement with fallthrough grouping
const day = "Saturday";

switch (day) {
  case "Monday":
  case "Tuesday":
  case "Wednesday":
  case "Thursday":
  case "Friday":
    console.log("Weekday - work time");
    break;
  case "Saturday":
  case "Sunday":
    console.log("Weekend - relax!");
    break;
  default:
    console.log("Invalid day");
}

// 3. Short-circuit conditional execution
const isLoggedIn = true;
isLoggedIn && console.log("Welcome back, user!");
```
