# 6. OBJECTS & OBJECT STATIC METHODS

| Method / Feature | Type | Description |
| --- | --- | --- |
| Object Literal | `{ key: val, method() {} }` | Defines key-value pairs with property/method shorthands |
| Computed Properties | `{ [dynamicKey]: val }` | Uses variable / expression inside brackets as key name |
| `Object.keys(obj)` | Static Method | Returns array of object's own enumerable string property names |
| `Object.values(obj)` | Static Method | Returns array of object's own enumerable property values |
| `Object.entries(obj)` | Static Method | Returns array of `[key, value]` pairs |
| `Object.fromEntries(entries)` | Static Method | Converts `[key, value]` array back into an Object |
| `Object.assign(target, ...sources)` | Static Method | Copies all enumerable properties to target object |
| `Object.freeze(obj)` | Static Method | Makes object completely immutable (cannot add, delete, or modify keys) |
| `Object.seal(obj)` | Static Method | Prevents adding/removing properties, but allows modifying existing ones |
| `Object.hasOwn(obj, prop)` | Static Method | Safe modern replacement for `hasOwnProperty()` |

**Example:**
```javascript
// 1. Object creation & computed keys
const dynamicKey = "role";
const user = {
  id: 101,
  name: "Sarah Connor",
  [dynamicKey]: "admin",
  greet() {
    return `Hello, I am ${this.name}`;
  }
};

// 2. Object static methods
const keys = Object.keys(user);       // ["id", "name", "role", "greet"]
const values = Object.values(user);   // [101, "Sarah Connor", "admin", [Function]]
const entries = Object.entries(user); // [["id", 101], ["name", "Sarah Connor"], ...]

// 3. Object transformations (filter properties)
const scores = { math: 90, english: 45, physics: 85 };
const passingScores = Object.fromEntries(
  Object.entries(scores).filter(([subject, score]) => score >= 50)
);
console.log(passingScores); // { math: 90, physics: 85 }

// 4. Freezing an object
const config = Object.freeze({ API_URL: "https://api.example.com", timeout: 5000 });
// config.timeout = 10000; // In strict mode, throws error!

// 5. Safe property check
console.log(Object.hasOwn(user, "name")); // true
```
