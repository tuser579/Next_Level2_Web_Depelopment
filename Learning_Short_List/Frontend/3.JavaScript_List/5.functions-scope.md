# 5. FUNCTIONS, SCOPE & CLOSURES

| Concept / Syntax | Type | Description |
| --- | --- | --- |
| Function Declaration | `function name() {...}` | Hoisted to the top of enclosing scope |
| Function Expression | `const fn = function() {...}` | Assigned to a variable; not hoisted before assignment |
| Arrow Function | `const fn = () => {...}` | Concise syntax; does not bind its own `this`, `arguments`, or `super` |
| Default Parameters | `function(a, b = 10)` | Provides fallback values if argument is omitted or `undefined` |
| Rest Parameters | `function(...args)` | Gathers remaining arguments into a true Array |
| Closure | Scope Concept | A function remembering and accessing variables from its outer lexical scope |
| IIFE | Pattern | Immediately Invoked Function Expression: `(function(){})()` |
| Currying | Pattern | Transforms `f(a, b)` into `f(a)(b)` via returning functions |

**Example:**
```javascript
// 1. Arrow Functions and Default Parameters
const calculateTotal = (price, taxRate = 0.08, discount = 0) => {
  return (price - discount) * (1 + taxRate);
};
console.log(calculateTotal(100)); // 108

// 2. Rest Parameters (...args)
const sumAll = (...numbers) => numbers.reduce((acc, n) => acc + n, 0);
console.log(sumAll(10, 20, 30, 40)); // 100

// 3. Closures (Encapsulating private state)
function createCounter(initialValue = 0) {
  let count = initialValue; // Private variable enclosed in closure
  return {
    increment: () => ++count,
    decrement: () => --count,
    getCount: () => count
  };
}

const counter = createCounter(5);
console.log(counter.increment()); // 6
console.log(counter.increment()); // 7
console.log(counter.getCount());  // 7

// 4. Currying
const multiply = (a) => (b) => a * b;
const double = multiply(2);
console.log(double(15)); // 30
```
