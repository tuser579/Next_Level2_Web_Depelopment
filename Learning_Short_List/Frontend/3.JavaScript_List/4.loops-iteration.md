# 4. LOOPS & ITERATION

| Loop Syntax | Best Used For | Description |
| --- | --- | --- |
| `for (let i = 0; ...)` | Indexed iteration | Standard counting loop with initializer, condition, and step |
| `for...of` | Iterables (Arrays, Sets, Strings) | Iterates directly over the VALUES of an iterable object |
| `for...in` | Object Properties (Keys) | Iterates over enumerable property KEYS (avoid for arrays) |
| `while` | Condition-based loop | Repeats block as long as condition evaluates to truthy |
| `do...while` | Post-condition loop | Executes body AT LEAST ONCE before evaluating condition |
| `break` | Flow Control | Immediately terminates and exits the loop |
| `continue` | Flow Control | Skips current iteration and jumps to next loop step |

**Example:**
```javascript
// 1. for...of Loop (Iterating values of an array or string)
const fruits = ["🍎 Apple", "🍌 Banana", "🍇 Grape"];
for (const fruit of fruits) {
  console.log(fruit);
}

// 2. for...in Loop (Iterating keys of an object)
const car = { make: "Tesla", model: "Model 3", year: 2024 };
for (const key in car) {
  if (Object.hasOwn(car, key)) {
    console.log(`${key}: ${car[key]}`);
  }
}

// 3. while loop with break and continue
let count = 0;
while (count < 10) {
  count++;
  if (count === 3) continue; // Skip 3
  if (count === 8) break;    // Exit when 8
  console.log(`Count: ${count}`);
}

// 4. do...while (always runs at least once)
let num = 10;
do {
  console.log(`Run once: ${num}`);
} while (num < 5);
```
