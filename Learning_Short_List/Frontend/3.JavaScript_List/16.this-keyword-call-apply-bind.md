# 16. THE 'THIS' KEYWORD, CALL, APPLY & BIND

| Method / Rule | Invocation Style | Description |
| --- | --- | --- |
| Default Binding | Standalone `fn()` | `this` is `window` (in non-strict mode) or `undefined` (in `'use strict'`) |
| Implicit Binding | Method `obj.method()` | `this` refers to the object before the dot (`obj`) |
| Explicit Binding | `call()`, `apply()`, `bind()` | Explicitly passes the object to be used as `this` |
| `fn.call(thisArg, arg1, arg2)` | Function Method | Executes function immediately with `thisArg` and comma-separated arguments |
| `fn.apply(thisArg, [arg1, arg2])` | Function Method | Executes function immediately with `thisArg` and an array of arguments |
| `fn.bind(thisArg, arg1)` | Function Method | Returns a NEW function permanently bound to `thisArg` |
| Arrow Functions | Lexical `this` | Inherits `this` from the enclosing lexical scope; cannot be bound with call/bind |

**Example:**
```javascript
const person1 = { name: "Alice", role: "Developer" };
const person2 = { name: "Bob", role: "Designer" };

function introduce(greeting, punctuation) {
  return `${greeting}, I am ${this.name}, working as a ${this.role}${punctuation}`;
}

// 1. call() -> comma separated arguments
console.log(introduce.call(person1, "Hello", "!"));
// "Hello, I am Alice, working as a Developer!"

// 2. apply() -> arguments passed in an array
console.log(introduce.apply(person2, ["Hi", "."]));
// "Hi, I am Bob, working as a Designer."

// 3. bind() -> returns new bound function for later execution
const introduceAlice = introduce.bind(person1, "Hey");
console.log(introduceAlice(" :)"));
// "Hey, I am Alice, working as a Developer :)"

// 4. Arrow function lexical `this` in callback
const timer = {
  seconds: 0,
  start() {
    setInterval(() => {
      this.seconds++; // `this` correctly points to `timer` object
    }, 1000);
  }
};
```
