# 8. ARRAY ITERATION & HIGHER-ORDER METHODS

| Method | Returns | Description |
| --- | --- | --- |
| `map(fn)` | New Array | Transforms every element by applying callback function |
| `filter(fn)` | New Array | Returns array of elements that pass callback condition |
| `reduce(fn, init)` | Single Value | Accumulates array elements into a single accumulated result |
| `forEach(fn)` | `undefined` | Executes callback for each element (used for side-effects) |
| `find(fn)` | Element | `undefined` | Returns first element satisfying callback condition |
| `findIndex(fn)` | Number (`-1` if none) | Returns index of first element satisfying callback |
| `some(fn)` | Boolean | Returns `true` if AT LEAST ONE element passes condition |
| `every(fn)` | Boolean | Returns `true` if ALL elements pass condition |
| `flat(depth)` | New Array | Flattens nested sub-arrays up to specified depth |
| `flatMap(fn)` | New Array | Maps each element using callback then flattens result by 1 level |
| `sort(compareFn)` | Mutated Array | Sorts array in place according to comparison function |
| `toSorted(compareFn)` | New Array | Modern non-mutating version of `sort()` |

**Example:**
```javascript
const products = [
  { id: 1, name: "Laptop", price: 1200, inStock: true },
  { id: 2, name: "Mouse", price: 25, inStock: true },
  { id: 3, name: "Keyboard", price: 80, inStock: false },
  { id: 4, name: "Monitor", price: 300, inStock: true }
];

// 1. map() -> Transform to array of names
const productNames = products.map(p => p.name);
// ["Laptop", "Mouse", "Keyboard", "Monitor"]

// 2. filter() -> Only in-stock items
const availableProducts = products.filter(p => p.inStock);

// 3. reduce() -> Calculate total price of available items
const totalCartValue = availableProducts.reduce((sum, p) => sum + p.price, 0);
console.log(`Total: $${totalCartValue}`); // Total: $1525

// 4. find() and some() / every()
const mouse = products.find(p => p.name === "Mouse");
const hasExpensiveItem = products.some(p => p.price > 1000); // true
const allInStock = products.every(p => p.inStock);           // false

// 5. toSorted() (Non-mutating sort)
const sortedByPrice = products.toSorted((a, b) => a.price - b.price);
```
