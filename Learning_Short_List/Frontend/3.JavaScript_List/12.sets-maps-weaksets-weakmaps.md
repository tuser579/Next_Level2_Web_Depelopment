# 12. SETS, MAPS, WEAKSETS & WEAKMAPS

| Collection | Key Characteristics | Main Methods |
| --- | --- | --- |
| `Set` | Collection of UNIQUE values of any type | `add()`, `delete()`, `has()`, `clear()`, `size` |
| `Map` | Key-Value pairs where KEYS can be ANY type (objects, functions, primitives) | `set()`, `get()`, `delete()`, `has()`, `clear()`, `size` |
| `WeakSet` | Collection of objects ONLY; objects held weakly (garbage-collectable) | `add()`, `delete()`, `has()` (Not iterable, no `.size`) |
| `WeakMap` | Key-Value pairs where KEYS MUST BE OBJECTS; held weakly | `set()`, `get()`, `delete()`, `has()` (Prevents memory leaks) |
| Set Operations (Modern) | Mathematical set methods | `union()`, `intersection()`, `difference()`, `isSubsetOf()` |

**Example:**
```javascript
// 1. Set: Remove duplicates from Array easily
const tags = ["js", "html", "css", "js", "html", "react"];
const uniqueTags = [...new Set(tags)];
console.log(uniqueTags); // ["js", "html", "css", "react"]

// 2. Map: Using objects as keys with reliable insertion order
const userSessions = new Map();
const user1 = { id: 1, name: "Alice" };
const user2 = { id: 2, name: "Bob" };

userSessions.set(user1, { token: "abc123xyz", lastActive: "10:00 AM" });
userSessions.set(user2, { token: "def456uvw", lastActive: "10:15 AM" });

console.log(userSessions.get(user1).token); // "abc123xyz"
console.log(userSessions.has(user2));        // true
console.log(`Active sessions: ${userSessions.size}`); // 2

// 3. Iterating a Map
for (const [userObj, session] of userSessions) {
  console.log(`${userObj.name} is logged in with token ${session.token}`);
}

// 4. WeakMap: Storing private data without memory leaks
const privateData = new WeakMap();
class UserAccount {
  constructor(apiKey) {
    privateData.set(this, apiKey); // Garbage collected when instance is destroyed
  }
}
```
