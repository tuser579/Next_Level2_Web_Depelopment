# 15. PROTOTYPES & PROTOTYPE CHAIN

| Property / Method | Type | Description |
| --- | --- | --- |
| `prototype` | Function Property | Object instance attached to constructor functions where shared methods reside |
| `__proto__` | Object Accessor | Pointer on an object instance linking to its prototype object |
| `Object.create(proto)` | Static Method | Creates a new object with specified prototype object |
| `Object.getPrototypeOf(obj)` | Static Method | Returns the prototype of the specified object |
| `Object.setPrototypeOf(obj, proto)` | Static Method | Sets the prototype of an object (slow, use `Object.create` instead) |
| Prototype Chain | Concept | Lookup mechanism traversing `__proto__` links up to `Object.prototype` (then `null`) |

**Example:**
```javascript
// 1. Prototype Pattern with Constructor Function
function Animal(name) {
  this.name = name;
}

// Shared methods placed on prototype save memory
Animal.prototype.speak = function() {
  return `${this.name} makes a noise.`;
};

function Dog(name, breed) {
  Animal.call(this, name); // Call super constructor
  this.breed = breed;
}

// Link prototypes for inheritance
Dog.prototype = Object.create(Animal.prototype);
Dog.prototype.constructor = Dog;

// Override / add child prototype method
Dog.prototype.speak = function() {
  return `${this.name} (${this.breed}) barks! 🐶`;
};

const myDog = new Dog("Buddy", "Golden Retriever");
console.log(myDog.speak()); // "Buddy (Golden Retriever) barks! 🐶"

// 2. Prototype chain verification
console.log(Object.getPrototypeOf(myDog) === Dog.prototype);        // true
console.log(Object.getPrototypeOf(Dog.prototype) === Animal.prototype); // true
```
