# 17. ERROR HANDLING & DEBUGGING

| Statement / Tool | Type | Description |
| --- | --- | --- |
| `try...catch` | Statement | Executes `try` block and catches any runtime exception thrown in `catch` |
| `finally` | Statement | Always executes after `try`/`catch` regardless of error outcome |
| `throw` | Statement | Throws a user-defined exception / `Error` object |
| `new Error(msg, { cause })` | Error Object | Creates standard error instance with optional modern `cause` chaining |
| `console.log()` / `console.error()` | Debugging | Logs info and error messages to browser console |
| `console.table()` | Debugging | Displays tabular data cleanly as an interactive table |
| `console.time()` / `timeEnd()` | Profiling | Measures execution time of operations |

**Example:**
```javascript
// 1. Custom Error Class with Error Causes
class ValidationError extends Error {
  constructor(message, options) {
    super(message, options);
    this.name = "ValidationError";
  }
}

function parseUserData(jsonString) {
  try {
    const data = JSON.parse(jsonString);
    if (!data.email) {
      throw new ValidationError("Email is required");
    }
    return data;
  } catch (err) {
    if (err instanceof ValidationError) {
      console.error(`Validation Failed: ${err.message}`);
    } else {
      // Re-throw with cause chaining
      throw new Error("Failed to process user data", { cause: err });
    }
  } finally {
    console.log("parseUserData operation completed.");
  }
}

// 2. Console debugging utilities
const users = [
  { id: 1, name: "Lucas", role: "Dev" },
  { id: 2, name: "Nina", role: "QA" }
];
console.table(users); // Displays clean table!

console.time("Loop Performance");
for (let i = 0; i < 1_000_000; i++) {}
console.timeEnd("Loop Performance");
```
