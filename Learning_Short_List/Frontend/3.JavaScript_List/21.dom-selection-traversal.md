# 21. DOM SELECTION & TRAVERSAL

| Method / Property | Returns | Description |
| --- | --- | --- |
| `document.querySelector(selector)` | Element | `null` | Returns first element matching CSS selector |
| `document.querySelectorAll(selector)` | NodeList (iterable) | Returns all elements matching CSS selector |
| `document.getElementById(id)` | Element | `null` | Fastest selection by ID |
| `element.closest(selector)` | Element | `null` | Traverses UP the ancestor tree to find nearest matching parent |
| `element.matches(selector)` | Boolean | Checks if element matches CSS selector |
| `element.parentElement` / `parentNode` | Element | Direct parent element |
| `element.children` | HTMLCollection | All direct child elements (skips text/comment nodes) |
| `element.nextElementSibling` / `previousElementSibling` | Element | `null` | Adjacent sibling elements |

**Example:**
```javascript
// Selecting elements
const submitBtn = document.querySelector("#submit-btn");
const navLinks = document.querySelectorAll(".nav-link"); // NodeList

// Iterating NodeList
navLinks.forEach((link) => {
  link.classList.add("active");
});

// Traversal: Finding closest matching ancestor
const deleteButton = document.querySelector(".delete-btn");
deleteButton.addEventListener("click", (e) => {
  // Find enclosing card component
  const card = e.target.closest(".card-item");
  if (card) {
    card.remove();
  }
});

// Check if element matches selector
if (submitBtn.matches(":disabled")) {
  console.log("Button is currently disabled");
}
```
