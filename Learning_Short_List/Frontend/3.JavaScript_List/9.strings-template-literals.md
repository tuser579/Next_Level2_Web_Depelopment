# 9. STRINGS & TEMPLATE LITERALS

| Method / Feature | Returns | Description |
| --- | --- | --- |
| Template Literal `` `Hello ${name}` `` | String | Interpolates expressions, variables, and multiline text |
| `slice(start, end)` | String | Extracts section of string (supports negative indices) |
| `replace(target, replacement)` | String | Replaces first match of target with replacement |
| `replaceAll(target, replacement)` | String | Replaces ALL occurrences of target |
| `split(separator)` | Array | Splits string into array of substrings |
| `trim()` / `trimStart()` / `trimEnd()` | String | Removes whitespace from both or specific ends |
| `toLowerCase()` / `toUpperCase()` | String | Converts casing of all characters |
| `startsWith()` / `endsWith()` | Boolean | Checks if string begins or ends with substring |
| `includes(substring)` | Boolean | Checks if substring exists inside string |
| `padStart()` / `padEnd()` | String | Pads string with fill characters until target length reached |
| `repeat(count)` | String | Constructs string with `count` copies concatenated |

**Example:**
```javascript
// 1. Template Literals & Multi-line strings
const user = { name: "Emily", role: "Designer", projectsCount: 14 };
const welcomeCard = `
  <div class="user-card">
    <h2>Welcome, ${user.name}!</h2>
    <p>Role: ${user.role.toUpperCase()}</p>
    <p>Active Projects: ${user.projectsCount}</p>
  </div>
`;

// 2. String search & slice methods
const email = "  user.contact@company.com  ";
const cleanEmail = email.trim(); // "user.contact@company.com"

console.log(cleanEmail.startsWith("user")); // true
console.log(cleanEmail.endsWith(".com"));    // true
console.log(cleanEmail.includes("@company"));// true

// Extract domain
const domain = cleanEmail.slice(cleanEmail.indexOf("@") + 1); // "company.com"

// 3. String padding for clean formatting
const invoiceId = "42";
console.log(invoiceId.padStart(6, "0")); // "000042"

// 4. replaceAll
const text = "JS is cool, JS is fast";
console.log(text.replaceAll("JS", "JavaScript")); 
// "JavaScript is cool, JavaScript is fast"
```
