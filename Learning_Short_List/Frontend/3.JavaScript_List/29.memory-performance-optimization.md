# 29. PERFORMANCE, DEBOUNCE, THROTTLE & WORKERS

| Technique / Tool | Purpose | Description |
| --- | --- | --- |
| Debounce | Rate Limiting | Delays execution until `N` ms have passed since LAST trigger (Search inputs) |
| Throttle | Rate Limiting | Guarantees function runs at most once every `N` ms (Scroll / Resize handlers) |
| `structuredClone(obj)` | Deep Cloning | Native fast deep cloning algorithm supporting circular references and Maps/Sets |
| Web Workers | Multithreading | Runs heavy CPU computations on background thread without freezing UI |
| Memory Leak Avoidance | Best Practice | Clean up event listeners, clear intervals, use WeakMap/WeakSet for cache |

**Example:**
```javascript
// 1. Debounce Implementation (Search autocomplete)
function debounce(func, delay = 300) {
  let timerId;
  return function (...args) {
    clearTimeout(timerId);
    timerId = setTimeout(() => func.apply(this, args), delay);
  };
}

const handleSearch = debounce((query) => {
  console.log(`Searching API for: ${query}`);
}, 400);

// 2. Throttle Implementation (Scroll progress)
function throttle(func, limit = 200) {
  let inThrottle = false;
  return function (...args) {
    if (!inThrottle) {
      func.apply(this, args);
      inThrottle = true;
      setTimeout(() => (inThrottle = false), limit);
    }
  };
}

window.addEventListener("scroll", throttle(() => {
  console.log("Calculating scroll position...");
}, 250));

// 3. structuredClone (Native deep clone)
const original = { user: { name: "Tom" }, date: new Date() };
const deepCopy = structuredClone(original);
deepCopy.user.name = "Jerry";
console.log(original.user.name); // "Tom" (Unchanged!)
```
