# 14. CLASSES & OBJECT-ORIENTED PROGRAMMING

| Feature / Keyword | Type | Description |
| --- | --- | --- |
| `class` | Declaration | Syntactic sugar over prototype-based inheritance |
| `constructor()` | Method | Special method for creating and initializing an object instance |
| `this` | Keyword | Refers to the current class instance object |
| `extends` | Inheritance | Creates a child subclass inheriting from a parent class |
| `super()` | Call | Calls the parent constructor or parent class methods |
| `get` / `set` | Accessors | Defines custom getter and setter logic for properties |
| `#privateField` | Encapsulation | Hard private property/method accessible ONLY inside the class |
| `static` | Class-Level | Defines static methods or properties called directly on the Class, not instance |

**Example:**
```javascript
// 1. Base Class with Private Fields & Static Methods
class BankAccount {
  #balance = 0; // Private field (inaccessible outside class)

  static bankName = "Global Federal";

  constructor(owner, initialDeposit = 0) {
    this.owner = owner;
    this.#balance = initialDeposit;
  }

  // Getter
  get balance() {
    return `$${this.#balance.toFixed(2)}`;
  }

  deposit(amount) {
    if (amount <= 0) throw new Error("Deposit must be positive");
    this.#balance += amount;
    return this.#balance;
  }

  static getBankInfo() {
    return `${this.bankName} - Established 2020`;
  }
}

// 2. Subclass with Inheritance (extends & super)
class SavingsAccount extends BankAccount {
  constructor(owner, initialDeposit, interestRate = 0.05) {
    super(owner, initialDeposit); // Call parent constructor
    this.interestRate = interestRate;
  }

  applyInterest() {
    console.log(`Interest rate is ${this.interestRate * 100}%`);
  }
}

const myAccount = new SavingsAccount("David", 500);
myAccount.deposit(250);
console.log(myAccount.balance); // "$750.00"
// console.log(myAccount.#balance); // SyntaxError: Private field must be declared
console.log(BankAccount.getBankInfo());
```
