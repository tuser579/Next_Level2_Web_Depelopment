# 7. ARRAYS & MUTATION / ACCESS METHODS

| Method / Syntax | Mutates Original? | Description |
| --- | --- | --- |
| `push(...items)` | Yes | Appends elements to the end of the array; returns new length |
| `pop()` | Yes | Removes and returns the last element |
| `unshift(...items)` | Yes | Prepends elements to the beginning; returns new length |
| `shift()` | Yes | Removes and returns the first element |
| `splice(start, count, ...items)` | Yes | Adds/removes elements at specific index in place |
| `slice(start, end)` | No (Pure) | Returns a shallow copy slice of array between start and end |
| `concat(...arrays)` | No (Pure) | Merges two or more arrays into a new array |
| `join(separator)` | No (Pure) | Joins all array elements into a string with separator |
| `includes(value)` | No (Pure) | Returns `true` if array contains specified value |
| `indexOf(value)` | No (Pure) | Returns first index of value, or `-1` if not found |
| `reverse()` / `toReversed()` | `reverse()` yes / `toReversed()` no | Reverses elements in place or returns new reversed copy |
| `at(index)` | No (Pure) | Returns element at index (supports negative index e.g. `.at(-1)` for last item) |

**Example:**
```javascript
const colors = ["🔴 Red", "🟢 Green", "🔵 Blue"];

// Adding and Removing
colors.push("🟡 Yellow");     // ["🔴 Red", "🟢 Green", "🔵 Blue", "🟡 Yellow"]
const last = colors.pop();     // "🟡 Yellow"
colors.unshift("🟣 Purple");  // ["🟣 Purple", "🔴 Red", "🟢 Green", "🔵 Blue"]
const first = colors.shift();  // "🟣 Purple"

// Slicing (Non-mutating)
const middleTwo = colors.slice(0, 2); // ["🔴 Red", "🟢 Green"]

// Splice (Mutating: start at index 1, delete 1 item, insert '🟠 Orange')
colors.splice(1, 1, "🟠 Orange");
console.log(colors); // ["🔴 Red", "🟠 Orange", "🔵 Blue"]

// Accessing with at()
console.log(colors.at(-1)); // "🔵 Blue" (last element!)

// Joining into String
console.log(colors.join(" - ")); // "🔴 Red - 🟠 Orange - 🔵 Blue"

// Includes & Index
console.log(colors.includes("🔵 Blue")); // true
console.log(colors.indexOf("🟢 Green"));  // -1 (not found)
```
