# 23. DOM ATTRIBUTES, CLASSES & STYLES

| Property / Method | Type | Description |
| --- | --- | --- |
| `classList.add(...names)` | Class Method | Adds one or more classes to element |
| `classList.remove(...names)` | Class Method | Removes one or more classes |
| `classList.toggle(name, force)` | Class Method | Toggles class on/off (optional boolean `force`) |
| `classList.contains(name)` | Class Method | Returns `true` if element has class |
| `element.dataset.prop` | Data Attributes | Reads / writes `data-*` custom attributes in camelCase |
| `getAttribute(name)` / `setAttribute(name, val)` | Attributes | Gets or sets arbitrary HTML attributes |
| `element.style.prop = val` | Inline Styles | Sets inline CSS style property (camelCase, e.g. `backgroundColor`) |
| `window.getComputedStyle(element)` | Computed Styles | Returns read-only object with all final calculated CSS styles |

**Example:**
```javascript
const card = document.querySelector(".product-card");

// 1. Class List manipulation
card.classList.add("highlighted", "shadow-lg");
card.classList.remove("dimmed");
card.classList.toggle("is-active");

if (card.classList.contains("is-active")) {
  console.log("Card is active");
}

// 2. Data attributes (data-product-id="456" -> dataset.productId)
const productId = card.dataset.productId;
card.dataset.category = "Electronics";

// 3. Dynamic inline styles vs Computed styles
card.style.backgroundColor = "#f0fdf4";
card.style.borderRadius = "12px";

// Read computed style (actual rendered pixel size)
const computed = window.getComputedStyle(card);
console.log(`Rendered padding: ${computed.padding}`);
console.log(`Rendered width: ${computed.width}`);
```
