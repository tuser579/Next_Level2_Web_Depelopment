# 1. VARIABLES & DATA TYPES

| Keyword / Type | Category | Description |
| --- | --- | --- |
| `const` | Variable Declaration | Block-scoped, cannot be reassigned; requires initial value |
| `let` | Variable Declaration | Block-scoped, can be reassigned; no hoisting initialization |
| `var` | Variable Declaration | Function-scoped, hoisted to top as undefined (legacy, avoid) |
| `String` | Primitive Type | Textual data enclosed in quotes: `"text"`, `'text'`, or `` `text` `` |
| `Number` | Primitive Type | Double-precision 64-bit float: integers and floats (e.g. `42`, `3.14`) |
| `BigInt` | Primitive Type | Arbitrary precision integers for numbers > `2^53 - 1` (`100n`) |
| `Boolean` | Primitive Type | Logical entity having `true` or `false` |
| `Undefined` | Primitive Type | Variable declared but not assigned a value (`undefined`) |
| `Null` | Primitive Type | Intentional absence of any object value (`null`) |
| `Symbol` | Primitive Type | Unique and immutable identifier (`Symbol("id")`) |
| `Object` | Reference Type | Key-value collections, Arrays, Functions, Dates, Maps, Sets |
| `typeof` | Operator | Returns type string (`"string"`, `"number"`, `"object"`, etc.) |
| `instanceof` | Operator | Tests if an object constructor prototype is in chain |

**Example:**
```javascript
// Modern variable declarations
const APP_NAME = "MyWebApp";
let userScore = 100;
userScore += 50; // Reassignment allowed with let

// Primitive types
const username = "Alex";           // String
const age = 28;                   // Number
const isSubscribed = true;        // Boolean
const accountBalance = 9007199254740995n; // BigInt
let profileImage = null;          // Null (intentional empty)
let userLocation;                 // Undefined (unassigned)
const uniqueId = Symbol("userId");// Symbol

// Reference types
const user = { name: "Alex", age: 28 };
const tags = ["developer", "frontend", "javascript"];

// Type checking
console.log(typeof username);      // "string"
console.log(typeof age);           // "number"
console.log(typeof null);          // "object" (known JS quirk)
console.log(Array.isArray(tags));  // true (recommended way to check arrays)
console.log(user instanceof Object);// true
```
