# 27. ES MODULES (IMPORT & EXPORT)

| Syntax | Type | Description |
| --- | --- | --- |
| `export const a = 1;` | Named Export | Exports individual variables, functions, or classes by name |
| `export default App;` | Default Export | Exports primary entity from module (one default per file) |
| `import { a, b } from './mod.js'` | Named Import | Imports specific named bindings |
| `import App from './mod.js'` | Default Import | Imports default export under any chosen name |
| `import * as Utils from './utils.js'` | Namespace Import | Imports all exports as properties on a single object |
| `import('./module.js')` | Dynamic Import | Returns Promise for module (enables lazy-loading and code-splitting) |

**Example:**
```javascript
// === mathUtils.js ===
export const PI = 3.14159;

export function add(a, b) {
  return a + b;
}

export default class Calculator {
  multiply(a, b) { return a * b; }
}

// === main.js ===
// Named, default, and namespace imports
import Calculator, { PI, add } from "./mathUtils.js";
import * as MathLib from "./mathUtils.js";

console.log(add(5, 10)); // 15
console.log(PI);         // 3.14159

// Dynamic lazy import on user interaction (code-splitting)
const loadChartBtn = document.querySelector("#load-chart");
loadChartBtn.addEventListener("click", async () => {
  const { renderChart } = await import("./heavyChartLibrary.js");
  renderChart("#chart-container");
});
```
