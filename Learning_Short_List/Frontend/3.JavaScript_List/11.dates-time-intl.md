# 11. DATES, TIME & INTL API

| Method / API | Type | Description |
| --- | --- | --- |
| `new Date()` | Constructor | Creates Date object for current date and time |
| `Date.now()` | Static Method | Returns timestamp in milliseconds elapsed since Jan 1, 1970 UTC |
| `date.toISOString()` | Method | Returns ISO 8601 formatted date string (`"2026-08-28T01:30:00.000Z"`) |
| `date.getFullYear()` / `getMonth()` / `getDate()` | Getters | Gets 4-digit year, 0-indexed month (0-11), and day of month (1-31) |
| `Intl.DateTimeFormat` | Internationalization | Formats dates and times according to locale standards |
| `Intl.NumberFormat` | Internationalization | Formats currencies, percentages, and numbers according to locale |
| `Intl.RelativeTimeFormat` | Internationalization | Formats relative times (e.g. "3 days ago", "in 2 hours") |

**Example:**
```javascript
// 1. Current Date and Timestamp
const now = new Date();
console.log(now.toISOString()); // e.g. "2026-08-28T01:30:00.000Z"
console.log(Date.now());        // Milliseconds timestamp

// 2. Intl.DateTimeFormat (Locale Date Formatting)
const date = new Date("2026-08-28T10:30:00");
const dateFormatter = new Intl.DateTimeFormat("en-US", {
  weekday: "long",
  year: "numeric",
  month: "long",
  day: "numeric",
  hour: "2-digit",
  minute: "2-digit"
});
console.log(dateFormatter.format(date));
// "Friday, August 28, 2026 at 10:30 AM"

// 3. Intl.NumberFormat (Currency formatting)
const currencyFormatter = new Intl.NumberFormat("en-US", {
  style: "currency",
  currency: "USD"
});
console.log(currencyFormatter.format(12499.99)); // "$12,499.99"

// 4. Intl.RelativeTimeFormat
const rtf = new Intl.RelativeTimeFormat("en", { numeric: "auto" });
console.log(rtf.format(-1, "day"));   // "yesterday"
console.log(rtf.format(3, "hour"));   // "in 3 hours"
```
