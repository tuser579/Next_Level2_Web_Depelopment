# 10. NUMBERS, MATH & BIGINT

| Function / Constant | Returns | Description |
| --- | --- | --- |
| `Number.parseInt(str, radix)` | Integer | `NaN` | Parses string to integer in specified base (e.g. 10) |
| `Number.parseFloat(str)` | Float | `NaN` | Parses string to floating point number |
| `Number.isInteger(num)` | Boolean | Checks if value is a finite integer |
| `Number.isNaN(val)` | Boolean | Reliably checks if value is strictly `NaN` |
| `toFixed(digits)` | String | Formats number with fixed number of decimal places |
| `Math.round()` / `Math.floor()` / `Math.ceil()` | Number | Rounds to nearest, rounds down, or rounds up integer |
| `Math.random()` | Number | Generates pseudo-random float between `0` (inclusive) and `1` (exclusive) |
| `Math.min(...nums)` / `Math.max(...nums)` | Number | Returns lowest or highest number among arguments |
| `Math.abs(num)` | Number | Returns absolute (positive) value of number |
| `BigInt` | Type | Handles arbitrary precision numbers beyond `Number.MAX_SAFE_INTEGER` (`2^53 - 1`) |

**Example:**
```javascript
// 1. Parsing & Validation
const input = "42.75px";
console.log(Number.parseFloat(input)); // 42.75
console.log(Number.parseInt(input, 10));// 42
console.log(Number.isNaN(Number("invalid"))); // true

// 2. Currency / Decimal formatting
const price = 19.998;
console.log(price.toFixed(2)); // "20.00" (returns string)

// 3. Random integer generator utility
function getRandomInt(min, max) {
  return Math.floor(Math.random() * (max - min + 1)) + min;
}
console.log(`Random dice roll (1-6): ${getRandomInt(1, 6)}`);

// 4. Math min / max with spread
const scores = [88, 92, 79, 99, 64];
console.log(Math.max(...scores)); // 99
console.log(Math.min(...scores)); // 64

// 5. BigInt for huge integers
const hugeNum1 = 9007199254740991n;
const hugeNum2 = 100n;
console.log(hugeNum1 + hugeNum2); // 9007199254741091n
```
