# 5. EVENT HANDLING & SYNTHETICEVENT

| Feature | Syntax Example | Description |
| --- | --- | --- |
| Event Handler Binding | `onClick={handleClick}` | Passes function reference (DO NOT invoke with `()` in JSX) |
| Passing Arguments | `onClick={() => handleDelete(item.id)}` | Wraps call in arrow function to pass parameters |
| SyntheticEvent | `function handleClick(e)` | React cross-browser wrapper around browser native event |
| Prevent Default | `e.preventDefault()` | Stops default browser action (e.g. form refresh) |
| Stop Propagation | `e.stopPropagation()` | Prevents event from bubbling to parent components |

**Example:**
```jsx
import React from "react";

export default function EventHandlingDemo() {
  // 1. Basic event handler with SyntheticEvent
  const handleClick = (e) => {
    console.log("Clicked button target:", e.target);
  };

  // 2. Passing arguments using arrow function
  const handleDelete = (itemId, itemName, e) => {
    e.stopPropagation(); // Stop event bubbling to parent row
    console.log(`Deleting ID: ${itemId} (${itemName})`);
  };

  // 3. Form submit with preventDefault
  const handleSubmit = (e) => {
    e.preventDefault();
    console.log("Form submitted without page reload!");
  };

  return (
    <div className="event-box" onClick={() => console.log("Parent clicked")}>
      <form onSubmit={handleSubmit}>
        <input type="text" placeholder="Type here..." />
        <button type="submit">Submit Form</button>
      </form>

      <button onClick={handleClick}>Click Me</button>

      <div className="item-row">
        <span>Item #42</span>
        <button onClick={(e) => handleDelete(42, "Wireless Headphones", e)}>
          Delete Item
        </button>
      </div>
    </div>
  );
}
```
