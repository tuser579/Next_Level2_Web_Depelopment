# 1. JSX SYNTAX & CORE RULES

| Rule / Feature | Syntax Example | Description |
| --- | --- | --- |
| Single Root Element | `<> ... </>` or `<div> ... </div>` | Component must return a single top-level parent or Fragment |
| Embedding JS Expressions | `<h1>{user.name.toUpperCase()}</h1>` | Wrap any valid JavaScript expression in curly braces `{}` |
| CamelCase HTML Attributes | `className`, `htmlFor`, `tabIndex`, `onClick` | HTML attribute names are converted to camelCase in JSX |
| Self-Closing Tags | `<img src="..." alt="" />`, `<input />` | All empty/void HTML tags MUST be explicitly self-closed (`/>`) |
| Inline Style Objects | `style={{ backgroundColor: 'red', margin: 10 }}` | Passes CSS properties as camelCase key-value JavaScript object |
| React Fragments | `<React.Fragment key={id}>` or `<>` | Groups elements without creating extra wrapping DOM nodes |

**Example:**
```jsx
import React from "react";

export default function UserGreeting() {
  const user = {
    name: "Alex Rivera",
    role: "Lead Engineer",
    avatarUrl: "https://i.pravatar.cc/100",
    isOnline: true
  };

  const statusStyle = {
    color: user.isOnline ? "#10b981" : "#6b7280",
    fontWeight: "bold",
    fontSize: "0.875rem"
  };

  return (
    // React Fragment: No extra <div> wrapper in DOM
    <>
      <div className="card-profile">
        {/* Self-closing tag */}
        <img 
          src={user.avatarUrl} 
          alt={`${user.name}'s avatar`} 
          className="avatar-img" 
        />

        {/* Embedded JS Expressions in JSX */}
        <h2>{user.name}</h2>
        <p className="role-tag">{user.role.toUpperCase()}</p>

        {/* Inline CSS style object */}
        <p style={statusStyle}>
          ● {user.isOnline ? "Active Now" : "Offline"}
        </p>
      </div>
    </>
  );
}
```
