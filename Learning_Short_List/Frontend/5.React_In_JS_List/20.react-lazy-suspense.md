# 20. CODE-SPLITTING: REACT.LAZY & SUSPENSE

| API | Syntax Example | Description |
| --- | --- | --- |
| `React.lazy()` | `const Analytics = React.lazy(() => import('./Analytics'));` | Dynamically loads component chunk ONLY when rendered |
| `<Suspense fallback={<Loader/>}>` | `<Suspense fallback={<Spinner/>}> <Comp/> </Suspense>` | Displays loading fallback UI while lazy components are downloading |

**Example:**
```jsx
import React, { Suspense, useState } from "react";

// 1. Code-split heavy component dynamically
const HeavyChart = React.lazy(() => import("./HeavyChart"));

export default function AnalyticsPage() {
  const [showChart, setShowChart] = useState(false);

  return (
    <div>
      <h2>Analytics Overview</h2>
      <button onClick={() => setShowChart(true)}>Load Heavy Chart</button>

      {showChart && (
        // 2. Wrap in Suspense with fallback loader
        <Suspense fallback={<div className="loader">⚡ Loading Chart Chunk...</div>}>
          <HeavyChart />
        </Suspense>
      )}
    </div>
  );
}
```
