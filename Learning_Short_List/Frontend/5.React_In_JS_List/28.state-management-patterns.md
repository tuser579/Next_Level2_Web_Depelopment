# 28. GLOBAL STATE MANAGEMENT (ZUSTAND & REDUX)

| Library | Core Pattern | Best Suited For |
| --- | --- | --- |
| Context API | `createContext` + `useContext` | Low-frequency state (Theming, Authentication, Localization) |
| Zustand | `create((set) => ({ count: 0, inc: () => set(...) }))` | Simple, boilerplate-free, high-performance global store |
| Redux Toolkit (RTK) | `createSlice`, `configureStore`, `useDispatch`, `useSelector` | Large-scale enterprise apps with complex state and devtools replay |

**Example:**
```jsx
// Example: Lightweight Zustand Store (Zero Boilerplate!)
// npm install zustand
import { create } from "zustand";

export const useCartStore = create((set) => ({
  cartItems: [],
  addItem: (item) => set((state) => ({ cartItems: [...state.cartItems, item] })),
  removeItem: (id) => set((state) => ({ 
    cartItems: state.cartItems.filter(i => i.id !== id) 
  })),
  clearCart: () => set({ cartItems: [] })
}));

// Usage in any component (No Provider wrapper required!):
export function CartCounter() {
  // Selects only cartItems count for fine-grained re-renders
  const count = useCartStore((state) => state.cartItems.length);
  return <span>🛒 Cart ({count})</span>;
}

export function AddProductButton({ product }) {
  const addItem = useCartStore((state) => state.addItem);
  return <button onClick={() => addItem(product)}>Add {product.name}</button>;
}
```
