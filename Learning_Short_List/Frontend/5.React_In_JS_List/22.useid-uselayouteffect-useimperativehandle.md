# 22. USEID, USELAYOUTEFFECT & USEIMPERATIVEHANDLE

| Hook | Execution Timing | Main Purpose |
| --- | --- | --- |
| `useId()` | Render time | Generates unique, collision-free, SSR-safe accessibility IDs for form inputs and labels |
| `useLayoutEffect()` | Synchronously AFTER DOM mutation, BEFORE screen paint | Reads DOM measurements (e.g. scroll position, tooltip layout) without visual flickering |
| `useImperativeHandle()` | With `forwardRef` | Customizes the instance value exposed to parent ref (exposing specific methods only) |

**Example:**
```jsx
import React, { useId, useLayoutEffect, useRef, forwardRef, useImperativeHandle } from "react";

// 1. useId: Accessible form element linking
export function AccessibleInput({ label }) {
  const id = useId(); // Generates unique ID like ":r1:"
  return (
    <div>
      <label htmlFor={id}>{label}</label>
      <input id={id} type="text" />
    </div>
  );
}

// 2. useImperativeHandle with forwardRef
export const CustomPlayer = forwardRef((props, ref) => {
  const audioRef = useRef(null);

  useImperativeHandle(ref, () => ({
    playTrack: () => audioRef.current?.play(),
    pauseTrack: () => audioRef.current?.pause()
  }));

  return <audio ref={audioRef} src="/audio/song.mp3" />;
});
```
