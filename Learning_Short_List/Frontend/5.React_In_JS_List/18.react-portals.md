# 18. REACT PORTALS

| Function | Arguments | Use Case |
| --- | --- | --- |
| `ReactDOM.createPortal(children, domNode)` | `children` (JSX), `domNode` (Target DOM Element) | Renders child element into a DOM node outside the parent component's DOM hierarchy |
| Event Bubbling through Portals | Natural React tree bubbling | Events fired inside portal bubble up through React parent tree regardless of DOM location |
| Common Scenarios | Modals, Tooltips, Overlays | Bypasses parent CSS `overflow: hidden`, `z-index`, or `transform` clipping |

**Example:**
```jsx
import React from "react";
import ReactDOM from "react-dom";

function Modal({ isOpen, onClose, children }) {
  if (!isOpen) return null;

  // Teleports modal JSX directly to document.body (or a #modal-root element)
  return ReactDOM.createPortal(
    <div className="modal-backdrop" onClick={onClose}>
      <div className="modal-window" onClick={(e) => e.stopPropagation()}>
        <button className="modal-close" onClick={onClose}>✕</button>
        {children}
      </div>
    </div>,
    document.body
  );
}

export default function Page() {
  const [open, setOpen] = React.useState(false);

  return (
    <div className="page-wrapper">
      <button onClick={() => setOpen(true)}>Open Modal via Portal</button>
      
      <Modal isOpen={open} onClose={() => setOpen(false)}>
        <h2>Portal Modal Window</h2>
        <p>Rendered outside the root div, directly in body!</p>
      </Modal>
    </div>
  );
}
```
