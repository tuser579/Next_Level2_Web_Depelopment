# 29. REACT PERFORMANCE OPTIMIZATION

| Optimization Strategy | Implementation Tool | Impact |
| --- | --- | --- |
| List Virtualization | `react-window` / `@tanstack/react-virtual` | Renders only visible items in huge lists (10,000+ rows) |
| State Colocation | Keep state closest to where it's used | Prevents entire parent trees from re-rendering |
| Dynamic Code Splitting | `React.lazy()` | Reduces initial bundle size downloaded by user |
| Memoization | `React.memo`, `useMemo`, `useCallback` | Prevents redundant re-renders on expensive subtrees |

**Example:**
```jsx
import React, { useState } from "react";

// State Colocation Example:
// ❌ BAD: Putting modal input text state at the top Dashboard level
// ✅ GOOD: Encapsulating dialog state inside the Dialog component itself!

function SearchModal() {
  const [query, setQuery] = useState(""); // Localized state: only SearchModal re-renders on typing!
  return (
    <div className="modal">
      <input value={query} onChange={(e) => setQuery(e.target.value)} />
      <p>Searching for: {query}</p>
    </div>
  );
}

export default function Dashboard() {
  const [isOpen, setIsOpen] = useState(false);

  return (
    <div>
      <h1>Main Dashboard (Does NOT re-render on modal typing)</h1>
      <button onClick={() => setIsOpen(true)}>Open Search</button>
      {isOpen && <SearchModal />}
    </div>
  );
}
```
