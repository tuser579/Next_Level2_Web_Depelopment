# 30. REACT BEST PRACTICES & SECURITY

| Best Practice | Category | Description |
| --- | --- | --- |
| Avoid `dangerouslySetInnerHTML` | Security (XSS) | Prevents Cross-Site Scripting; sanitize with DOMPurify if HTML is mandatory |
| Immutable State Updates | Reliability | Never mutate state variables directly (`state.push()` ❌) |
| Clean Effect Dependencies | Predictability | Declare all referenced variables inside `useEffect` dependency array |
| Component Organization | Architecture | Keep components small, modular, focused on a single responsibility |

**Example:**
```jsx
import React from "react";

export default function SafeContentRenderer({ untrustedHtmlString }) {
  // 1. Safe rendering: React automatically escapes HTML strings to prevent XSS
  const safeText = "<script>alert('hacked')</script>";

  return (
    <div className="security-container">
      {/* Renders literally as text, neutralizing malicious scripts */}
      <p>{safeText}</p>

      {/* If raw HTML is unavoidable, sanitize with DOMPurify first:
          import DOMPurify from 'dompurify';
          <div dangerouslySetInnerHTML={{ __html: DOMPurify.sanitize(untrustedHtmlString) }} />
      */}
    </div>
  );
}
```
