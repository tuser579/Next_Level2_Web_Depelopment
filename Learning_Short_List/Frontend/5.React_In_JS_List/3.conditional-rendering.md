# 3. CONDITIONAL RENDERING

| Technique | Syntax | Best Used For |
| --- | --- | --- |
| Ternary Operator | `isLoggedIn ? <UserDash/> : <LoginForm/>` | Choosing between two alternative elements |
| Logical AND (`&&`) | `unreadCount > 0 && <Badge count={unreadCount}/>` | Rendering element conditionally (Warning: avoid `count && <Badge/>` if count can be `0`) |
| Early Return | `if (isLoading) return <Spinner />;` | Exiting component render early for loading or error states |
| Switch / Helper Function | `const renderView = () => { switch(tab) ... }` | Complex multi-branch UI state transitions |

**Example:**
```jsx
import React from "react";

export default function NotificationCenter({ user, unreadCount, isLoading }) {
  // 1. Early return pattern for loading state
  if (isLoading) {
    return <div className="spinner">Loading notifications...</div>;
  }

  // 2. Early return if user is not authenticated
  if (!user) {
    return <p>Please log in to view your notifications.</p>;
  }

  return (
    <div className="notifications-box">
      <h2>Welcome back, {user.name}!</h2>

      {/* 3. Ternary Operator (Either/Or) */}
      <p>
        Status: {user.isPremium ? "⭐ Premium Member" : "Free Tier Member"}
      </p>

      {/* 4. Logical AND (&&) - ensure numeric checks are boolean! */}
      {unreadCount > 0 && (
        <div className="badge-alert">
          You have {unreadCount} new unread message{unreadCount > 1 ? "s" : ""}!
        </div>
      )}

      {unreadCount === 0 && <p>All caught up! No new messages.</p>}
    </div>
  );
}
```
