# 25. STYLING IN REACT (CSS MODULES, INLINE & TAILWIND)

| Styling Approach | Import / Syntax | Description |
| --- | --- | --- |
| CSS Modules | `import styles from './Card.module.css'` | Locally scoped CSS classes preventing global stylesheet collision |
| Inline Styles | `style={{ color: 'blue' }}` | Dynamic JavaScript style objects |
| Tailwind CSS | `className="flex items-center p-4 bg-white"` | Utility-first CSS classes directly in JSX |
| Conditional Classes | `className={`btn ${isActive ? 'btn-active' : ''}`}` | Dynamic class string composition |

**Example:**
```jsx
import React from "react";
// import styles from "./Button.module.css"; // CSS Modules

export default function StyledButtons({ isActive }) {
  // Dynamic inline style
  const customPadding = {
    padding: "10px 20px",
    borderRadius: "8px"
  };

  return (
    <div className="flex gap-4 p-6 bg-slate-50">
      {/* 1. Tailwind utility classes */}
      <button className="px-4 py-2 text-white bg-blue-600 rounded-lg hover:bg-blue-700">
        Tailwind Button
      </button>

      {/* 2. Dynamic class combination */}
      <button 
        style={customPadding} 
        className={`border ${isActive ? "border-green-500 text-green-600" : "border-gray-300"}`}
      >
        Dynamic Button
      </button>
    </div>
  );
}
```
