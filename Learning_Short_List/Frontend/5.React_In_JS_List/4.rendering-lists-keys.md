# 4. RENDERING LISTS & THE 'KEY' PROP

| Concept | Pattern / Rule | Description |
| --- | --- | --- |
| `Array.prototype.map()` | `items.map(item => <li key={item.id}>{item.name}</li>)` | Transforms raw array data into array of JSX elements |
| The `key` Prop | `key={item.id}` | Unique string/number identifier giving React stable identity across renders |
| Why Avoid Array Index as Key | ❌ `key={index}` | Causes bugs with state loss, ordering mutations, deletion, and performance drops |
| Filtering and Mapping | `items.filter(...).map(...)` | Chaining array methods to render filtered lists |

**Example:**
```jsx
import React from "react";

export default function TodoList() {
  const todos = [
    { id: "todo_1", text: "Learn React Hooks", completed: true },
    { id: "todo_2", text: "Master State Management", completed: false },
    { id: "todo_3", text: "Deploy to Production", completed: false }
  ];

  return (
    <div className="todo-widget">
      <h3>Active Task List</h3>
      <ul className="todo-list">
        {/* Render list using stable unique ID for the key prop */}
        {todos
          .filter(todo => !todo.completed)
          .map(todo => (
            <li key={todo.id} className="todo-item">
              <span>📌 {todo.text}</span>
              <button onClick={() => alert(`Completed: ${todo.text}`)}>Done</button>
            </li>
          ))}
      </ul>
    </div>
  );
}
```
