# 24. REACT 19: THE 'USE' API & ASYNC SUSPENSE

| API Feature | Syntax Example | Description |
| --- | --- | --- |
| `use(Promise)` | `const data = use(fetchPromise);` | Unwraps promises directly in render; integrates seamlessly with `<Suspense>` |
| `use(Context)` | `const theme = use(ThemeContext);` | Can be called conditionally inside `if` statements and loops (unlike `useContext`) |
| Suspense Integration | Automatic suspension | React suspends component render until promise resolves |

**Example:**
```jsx
import React, { use, Suspense } from "react";

// Promise created outside or passed as prop
const messagePromise = new Promise((resolve) => {
  setTimeout(() => resolve("Hello from React 19 use() API!"), 1500);
});

// Component unwraps promise directly with use()
function MessageCard({ promise }) {
  const message = use(promise); // Suspends until resolved!
  return <div className="card">💬 {message}</div>;
}

export default function App() {
  return (
    <Suspense fallback={<p>⚡ Loading message via use()...</p>}>
      <MessageCard promise={messagePromise} />
    </Suspense>
  );
}
```
