# 16. COMPONENT COMPOSITION & SLOTS

| Composition Pattern | Syntax / Technique | Description |
| --- | --- | --- |
| Children Containment | `{children}` | Generic box wrappers that don't know children ahead of time |
| Named Slots via Props | `<Layout left={<Sidebar/>} right={<Main/>}/>` | Passes entire JSX elements as props for custom layout slots |
| Specialization | `function DangerButton(props)` returns `<Button {...props} />` | Creating specific variants of generic components |

**Example:**
```jsx
import React from "react";

// 1. Slot Pattern Layout Component
function SplitLayout({ topNav, sidebar, content }) {
  return (
    <div className="app-shell">
      <header>{topNav}</header>
      <div className="body-split">
        <aside>{sidebar}</aside>
        <main>{content}</main>
      </div>
    </div>
  );
}

// 2. Card Container with flexible header and body
function DialogBox({ title, icon, children, footerActions }) {
  return (
    <div className="modal-dialog">
      <header className="dialog-header">
        <span>{icon}</span>
        <h4>{title}</h4>
      </header>
      <div className="dialog-content">{children}</div>
      <footer className="dialog-footer">{footerActions}</footer>
    </div>
  );
}

export default function App() {
  return (
    <DialogBox 
      title="Confirm Delete" 
      icon="⚠️"
      footerActions={
        <>
          <button>Cancel</button>
          <button style={{ background: "red", color: "white" }}>Delete</button>
        </>
      }
    >
      <p>Are you sure you want to permanently delete this project?</p>
    </DialogBox>
  );
}
```
