# 4. NATIVE HTML PROPS & POLYMORPHIC COMPONENTS

| Type Helper | Syntax Example | Description |
| --- | --- | --- |
| `ComponentPropsWithoutRef<T>` | `React.ComponentPropsWithoutRef<'button'>` | Inherits ALL native HTML attributes (e.g. `disabled`, `type`, `aria-*`) without ref |
| `ComponentPropsWithRef<T>` | `React.ComponentPropsWithRef<'input'>` | Inherits native attributes PLUS ref |
| Omit Helper on Native Props | `Omit<ComponentPropsWithoutRef<'button'>, 'onClick'>` | Drops specific native props to override with custom signatures |
| Polymorphic `as` Prop | `as?: C` | Allows component to render dynamically as `a`, `button`, `div` while maintaining correct HTML attributes |

**Example:**
```tsx
import React from "react";

// 1. Extending native button attributes
interface CustomButtonProps extends React.ComponentPropsWithoutRef<"button"> {
  variant?: "primary" | "outline";
  isLoading?: boolean;
}

export function CustomButton({
  variant = "primary",
  isLoading = false,
  children,
  className = "",
  disabled,
  ...nativeButtonProps // Passes type="submit", onClick, aria-labels, etc.
}: CustomButtonProps) {
  return (
    <button
      className={`btn btn-${variant} ${className}`}
      disabled={disabled || isLoading}
      {...nativeButtonProps}
    >
      {isLoading ? "Processing..." : children}
    </button>
  );
}

// Usage inherits all native HTML button props automatically!
// <CustomButton type="submit" aria-label="Save" onClick={() => {}}>Save</CustomButton>
```
