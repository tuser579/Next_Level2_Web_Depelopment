# 7. LISTS

| Element | Description |
|---------|-------------|
| `<ul>` | Unordered list |
| `<ol>` | Ordered list |
| `<li>` | List item |
| `<dl>` | Description list |
| `<dt>` | Description term |
| `<dd>` | Description details |

**List Attributes:**
- `type` — `disc`, `circle`, `square` (for `<ul>`)
- `type` — `1`, `A`, `a`, `I`, `i` (for `<ol>`)
- `start` — Starting number (for `<ol>`)
- `reversed` — Reverse order (for `<ol>`)

**Example:**
```html
<!-- Unordered list -->
<ul type="disc">
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

<!-- Ordered list (starting at 3, reversed, type A) -->
<ol type="A" start="3" reversed>
  <li>Third item</li>
  <li>Second item</li>
  <li>First item</li>
</ol>

<!-- Description list -->
<dl>
  <dt>HTML</dt>
  <dd>HyperText Markup Language — the structure of web pages.</dd>
  <dt>CSS</dt>
  <dd>Cascading Style Sheets — the styling of web pages.</dd>
</dl>
```
