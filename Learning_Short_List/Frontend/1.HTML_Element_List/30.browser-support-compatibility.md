# 30. BROWSER SUPPORT & COMPATIBILITY

| Technique | Description |
|-----------|-------------|
| Conditional comments | Target IE browsers (legacy) |
| `@supports` | CSS feature detection |
| Modernizr | JavaScript feature detection library |
| Polyfills | Fill in missing browser features |
| Vendor prefixes | `-webkit-`, `-moz-`, `-ms-` |

**Example:**
```html
<!-- Legacy IE conditional comment -->
<!--[if IE]>
  <p>You are using Internet Explorer. Please upgrade to a modern browser.</p>
<![endif]-->

<!-- Feature detection with @supports (in CSS) -->
<style>
  /* Fallback for older browsers */
  .container { display: block; }

  /* Modern CSS Grid if supported */
  @supports (display: grid) {
    .container { display: grid; grid-template-columns: repeat(3, 1fr); }
  }

  /* Vendor prefixes example */
  .box {
    -webkit-transform: rotate(45deg);
       -moz-transform: rotate(45deg);
        -ms-transform: rotate(45deg);
            transform: rotate(45deg);
  }
</style>

<!-- Polyfill for older browser support -->
<script>
  // Manual feature detection
  if (!window.fetch) {
    const script = document.createElement("script");
    script.src = "https://cdn.jsdelivr.net/npm/whatwg-fetch@3/fetch.umd.js";
    document.head.appendChild(script);
  }

  // Check canvas support
  const canvas = document.createElement("canvas");
  if (!canvas.getContext) {
    console.warn("Canvas is not supported in this browser.");
  }
</script>

<!-- Fallback for browsers without JS -->
<noscript>
  <p>This website requires JavaScript to function properly.</p>
</noscript>
```
