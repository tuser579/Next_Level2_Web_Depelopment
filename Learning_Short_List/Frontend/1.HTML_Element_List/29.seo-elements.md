# 29. SEO ELEMENTS

| Element | Description |
|---------|-------------|
| `<title>` | Page title (shows in search results) |
| `<meta name="description">` | Page description snippet |
| `<meta name="keywords">` | Keywords (low impact now) |
| `<meta name="robots">` | Control indexing |
| `<link rel="canonical">` | Canonical URL to avoid duplicates |
| `<header>` | Semantic page header |
| `<nav>` | Navigation (important for crawlers) |
| `<main>` | Main content (signals primary content) |
| `<article>` | Self-contained content unit |
| `<footer>` | Page footer |
| `<h1>` to `<h6>` | Heading hierarchy |
| `alt` on `<img>` | Image SEO and accessibility |
| Schema.org markup | Structured data for rich snippets |

**Example:**
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Best HTML Guide 2025 | Learn HTML Fast</title>
  <meta name="description" content="A complete HTML reference guide with examples for every element." />
  <meta name="robots" content="index, follow" />
  <link rel="canonical" href="https://example.com/html-guide" />

  <!-- Open Graph for social sharing -->
  <meta property="og:title" content="Best HTML Guide 2025" />
  <meta property="og:description" content="Complete HTML reference with examples." />
  <meta property="og:image" content="https://example.com/html-guide-og.jpg" />

  <!-- JSON-LD Structured Data -->
  <script type="application/ld+json">
  {
    "@context": "https://schema.org",
    "@type": "Article",
    "headline": "Best HTML Guide 2025",
    "author": { "@type": "Person", "name": "John Doe" },
    "datePublished": "2025-08-28"
  }
  </script>
</head>
<body>
  <header>
    <nav aria-label="Main navigation">
      <a href="/">Home</a>
      <a href="/html">HTML</a>
      <a href="/css">CSS</a>
    </nav>
  </header>
  <main>
    <article>
      <h1>Best HTML Guide 2025</h1>
      <section>
        <h2>Introduction to HTML</h2>
        <p>HTML is the foundation of every web page...</p>
        <img src="html-diagram.jpg" alt="Diagram showing HTML document structure" />
      </section>
    </article>
  </main>
  <footer>
    <p>&copy; 2025 HTML Guide. All rights reserved.</p>
  </footer>
</body>
</html>
```
