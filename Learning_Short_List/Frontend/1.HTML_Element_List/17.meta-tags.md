# 17. META TAGS

**Example:**
```html
<head>
  <!-- Character set -->
  <meta charset="UTF-8" />

  <!-- Responsive viewport -->
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />

  <!-- SEO meta tags -->
  <meta name="description" content="A comprehensive HTML reference guide." />
  <meta name="keywords" content="HTML, CSS, JavaScript, Web Development" />
  <meta name="author" content="John Doe" />
  <meta name="robots" content="index, follow" />

  <!-- Auto refresh page every 30 seconds -->
  <meta http-equiv="refresh" content="30" />

  <!-- Open Graph (for social sharing) -->
  <meta property="og:title" content="HTML Reference Sheet" />
  <meta property="og:description" content="Complete guide to HTML elements." />
  <meta property="og:image" content="https://example.com/og-image.jpg" />
  <meta property="og:url" content="https://example.com/html-guide" />
  <meta property="og:type" content="website" />

  <!-- Twitter Card -->
  <meta name="twitter:card" content="summary_large_image" />
  <meta name="twitter:title" content="HTML Reference Sheet" />
  <meta name="twitter:description" content="Complete guide to HTML elements." />
  <meta name="twitter:image" content="https://example.com/og-image.jpg" />
</head>
```
