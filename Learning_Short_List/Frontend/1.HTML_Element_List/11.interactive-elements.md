# 11. INTERACTIVE ELEMENTS

| Element | Description |
|---------|-------------|
| `<details>` | Collapsible content |
| `<summary>` | Summary heading for `<details>` |
| `<dialog>` | Modal dialog |
| `<menu>` | Context menu list |

**Example:**
```html
<!-- Details / Summary (accordion) -->
<details>
  <summary>What is HTML?</summary>
  <p>HTML stands for HyperText Markup Language. It is the standard language for creating web pages.</p>
</details>

<!-- Dialog (modal) -->
<button onclick="document.getElementById('modal').showModal()">Open Modal</button>

<dialog id="modal">
  <h2>Modal Title</h2>
  <p>This is a modal dialog.</p>
  <form method="dialog">
    <button>Close</button>
  </form>
</dialog>

<!-- Menu -->
<menu>
  <li><button>Cut</button></li>
  <li><button>Copy</button></li>
  <li><button>Paste</button></li>
</menu>
```
