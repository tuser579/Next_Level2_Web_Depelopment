# 19. STORAGE & DATA

| Storage | Description |
|---------|-------------|
| `localStorage` | Persistent local storage (survives page close) |
| `sessionStorage` | Session storage (cleared on tab close) |
| `indexedDB` | Client-side indexed database |

**Storage Methods:**

| Method | Description |
|--------|-------------|
| `setItem(key, value)` | Store data |
| `getItem(key)` | Retrieve data |
| `removeItem(key)` | Remove one item |
| `clear()` | Remove all items |

**Example:**
```html
<script>
  // localStorage
  localStorage.setItem("username", "Alice");
  console.log(localStorage.getItem("username")); // Alice
  localStorage.removeItem("username");
  localStorage.clear();

  // sessionStorage (same API, cleared when tab closes)
  sessionStorage.setItem("cart", JSON.stringify(["item1", "item2"]));
  const cart = JSON.parse(sessionStorage.getItem("cart"));
  console.log(cart); // ["item1", "item2"]

  // IndexedDB (brief example)
  const request = indexedDB.open("MyDatabase", 1);
  request.onupgradeneeded = (e) => {
    const db = e.target.result;
    db.createObjectStore("users", { keyPath: "id" });
  };
  request.onsuccess = (e) => {
    const db = e.target.result;
    const tx = db.transaction("users", "readwrite");
    tx.objectStore("users").add({ id: 1, name: "Alice" });
    console.log("User added to IndexedDB");
  };
</script>
```
