# 12. SCRIPTING

| Element | Description |
|---------|-------------|
| `<script>` | JavaScript code or file |
| `<noscript>` | Fallback content when JS is disabled |
| `<template>` | Reusable HTML template (not rendered) |
| `<slot>` | Web component placeholder slot |

**Example:**
```html
<!-- Inline script -->
<script>
  console.log("Hello from inline script!");
</script>

<!-- External script (deferred) -->
<script src="app.js" defer></script>

<!-- Async script -->
<script src="analytics.js" async></script>

<!-- Noscript fallback -->
<noscript>
  <p>Please enable JavaScript to use this site.</p>
</noscript>

<!-- Template (used with JavaScript) -->
<template id="card-template">
  <div class="card">
    <h2 class="card-title"></h2>
    <p class="card-body"></p>
  </div>
</template>

<script>
  const template = document.getElementById("card-template");
  const clone = template.content.cloneNode(true);
  clone.querySelector(".card-title").textContent = "Dynamic Card";
  document.body.appendChild(clone);
</script>
```
