# 22. HTML5 NEW ELEMENTS

| Element | Description |
|---------|-------------|
| `<article>` | Independent article content |
| `<aside>` | Sidebar / related content |
| `<audio>` | Audio content |
| `<canvas>` | Drawing canvas |
| `<datalist>` | Suggestions for input |
| `<details>` | Expandable details |
| `<dialog>` | Dialog/modal |
| `<embed>` | Embedded content |
| `<figure>` | Figure / illustration |
| `<figcaption>` | Caption for figure |
| `<footer>` | Page or section footer |
| `<header>` | Page or section header |
| `<main>` | Main page content |
| `<mark>` | Highlighted/marked text |
| `<meter>` | Scalar measurement |
| `<nav>` | Navigation links |
| `<output>` | Result of a calculation |
| `<progress>` | Progress indicator |
| `<section>` | Thematic content section |
| `<source>` | Media source |
| `<summary>` | Summary for `<details>` |
| `<time>` | Date or time |
| `<video>` | Video content |
| `<wbr>` | Word break opportunity |

**Example:**
```html
<article>
  <header>
    <h2>HTML5 Is Great</h2>
    <time datetime="2025-08-28">August 28, 2025</time>
  </header>

  <section>
    <p>HTML5 introduced many <mark>powerful new elements</mark>.</p>
    <figure>
      <img src="html5-logo.png" alt="HTML5 Logo" />
      <figcaption>The official HTML5 logo.</figcaption>
    </figure>
  </section>

  <details>
    <summary>Read more about HTML5 history</summary>
    <p>HTML5 was officially recommended by W3C in October 2014.</p>
  </details>

  <meter value="0.75" min="0" max="1">75%</meter>
  <progress value="75" max="100">75%</progress>

  <p>This line can break he<wbr />re if needed.</p>
</article>
```
