# 1. DOCUMENT STRUCTURE

| Element | Description |
|---------|-------------|
| `<!DOCTYPE html>` | Declares document type (HTML5) |
| `<html>` | Root element |
| `<head>` | Metadata container |
| `<body>` | Visible content |

**Example:**
```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title>My Page</title>
  </head>
  <body>
    <h1>Hello, World!</h1>
  </body>
</html>
```
