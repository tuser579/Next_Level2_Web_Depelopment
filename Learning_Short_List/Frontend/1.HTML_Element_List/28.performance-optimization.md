# 28. PERFORMANCE OPTIMIZATION

| Technique | Description |
|-----------|-------------|
| `loading="lazy"` | Lazy load images/iframes |
| `<link rel="preload">` | Preload critical resources |
| `<link rel="prefetch">` | Prefetch future resources |
| `<script defer>` | Defer script execution |
| `<script async>` | Async script loading |
| Minification | Reduce HTML/CSS/JS file size |
| Image optimization | Use WebP, compress, resize |
| CDN | Serve assets from edge locations |
| Browser caching | Cache static resources |
| Compression | gzip / Brotli encoding |

**Example:**
```html
<head>
  <!-- Preload critical font -->
  <link rel="preload" href="fonts/inter.woff2" as="font" type="font/woff2" crossorigin />

  <!-- Preload hero image -->
  <link rel="preload" href="hero.jpg" as="image" />

  <!-- Prefetch next page -->
  <link rel="prefetch" href="/next-page.html" />

  <!-- Defer non-critical script -->
  <script src="analytics.js" defer></script>

  <!-- Async third-party script -->
  <script src="https://cdn.example.com/widget.js" async></script>
</head>
<body>
  <!-- Lazy load images below the fold -->
  <img src="photo1.jpg" alt="Photo 1" loading="lazy" width="800" height="600" />
  <img src="photo2.jpg" alt="Photo 2" loading="lazy" width="800" height="600" />

  <!-- Lazy load iframe -->
  <iframe src="map.html" loading="lazy" title="Map"></iframe>
</body>
```
