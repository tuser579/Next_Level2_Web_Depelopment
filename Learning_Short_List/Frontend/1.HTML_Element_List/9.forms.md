# 9. FORMS

| Element | Description |
|---------|-------------|
| `<form>` | Form container |
| `<input>` | Input field |
| `<textarea>` | Multi-line text |
| `<button>` | Button |
| `<select>` | Dropdown list |
| `<optgroup>` | Option group |
| `<option>` | Option item |
| `<label>` | Input label |
| `<fieldset>` | Form group |
| `<legend>` | Fieldset caption |
| `<datalist>` | Input suggestions |
| `<output>` | Calculation result |
| `<progress>` | Progress bar |
| `<meter>` | Measurement |

**Input Types:**

| Type | Description |
|------|-------------|
| `text` | Text input |
| `password` | Password |
| `email` | Email address |
| `number` | Number |
| `tel` | Phone number |
| `url` | URL |
| `search` | Search field |
| `date` | Date picker |
| `time` | Time picker |
| `datetime-local` | Date and time |
| `month` | Month picker |
| `week` | Week picker |
| `color` | Color picker |
| `file` | File upload |
| `checkbox` | Checkbox |
| `radio` | Radio button |
| `range` | Slider |
| `submit` | Submit button |
| `reset` | Reset button |
| `button` | Generic button |
| `hidden` | Hidden field |
| `image` | Image button |

**Form Attributes:**

| Attribute | Description |
|-----------|-------------|
| `action` | Submit URL |
| `method` | `GET`, `POST` |
| `enctype` | `multipart/form-data` |
| `autocomplete` | `on`, `off` |
| `novalidate` | Skip validation |
| `required` | Mandatory field |
| `placeholder` | Hint text |
| `pattern` | Regex pattern |
| `min` / `max` | Range limits |
| `step` | Increment value |
| `multiple` | Multiple values |
| `disabled` | Disable field |
| `readonly` | Read-only field |

**Example:**
```html
<form action="/submit" method="POST" enctype="multipart/form-data" autocomplete="on">
  <fieldset>
    <legend>Personal Information</legend>

    <label for="name">Full Name:</label>
    <input type="text" id="name" name="name" placeholder="John Doe" required />

    <label for="email">Email:</label>
    <input type="email" id="email" name="email" placeholder="john@example.com" required />

    <label for="password">Password:</label>
    <input type="password" id="password" name="password" minlength="8" required />

    <label for="dob">Date of Birth:</label>
    <input type="date" id="dob" name="dob" />

    <label for="phone">Phone:</label>
    <input type="tel" id="phone" name="phone" pattern="[0-9]{10}" placeholder="0123456789" />
  </fieldset>

  <fieldset>
    <legend>Preferences</legend>

    <label>Gender:</label>
    <input type="radio" id="male" name="gender" value="male" />
    <label for="male">Male</label>
    <input type="radio" id="female" name="gender" value="female" />
    <label for="female">Female</label>

    <label for="country">Country:</label>
    <select id="country" name="country">
      <optgroup label="Asia">
        <option value="bd">Bangladesh</option>
        <option value="in">India</option>
      </optgroup>
      <optgroup label="Europe">
        <option value="uk">United Kingdom</option>
      </optgroup>
    </select>

    <label for="skills">Skills:</label>
    <input list="skill-options" id="skills" name="skills" />
    <datalist id="skill-options">
      <option value="HTML" />
      <option value="CSS" />
      <option value="JavaScript" />
    </datalist>

    <label for="bio">Bio:</label>
    <textarea id="bio" name="bio" rows="4" cols="40" placeholder="Tell us about yourself..."></textarea>

    <label for="avatar">Upload Avatar:</label>
    <input type="file" id="avatar" name="avatar" accept="image/*" />

    <label>
      <input type="checkbox" name="agree" required /> I agree to the terms
    </label>
  </fieldset>

  <label for="satisfaction">Satisfaction:</label>
  <input type="range" id="satisfaction" name="satisfaction" min="0" max="10" step="1" />

  <label for="score">Score (0-100):</label>
  <meter id="score" value="70" min="0" max="100" low="30" high="80" optimum="90">70</meter>

  <progress value="40" max="100">40%</progress>

  <output name="result" for="satisfaction">5</output>

  <input type="hidden" name="token" value="abc123" />

  <button type="submit">Submit</button>
  <button type="reset">Reset</button>
</form>
```
