# 20. BROWSER APIs & FEATURES

| API | Description |
|-----|-------------|
| Geolocation API | Get user's location |
| Notification API | Send browser notifications |
| Web Workers | Background thread tasks |
| WebSocket | Real-time two-way communication |
| Fetch API | HTTP requests (modern AJAX) |
| History API | Browser history manipulation |
| Drag and Drop API | Drag-and-drop interactions |
| File API | Read local files |
| Canvas API | 2D/3D graphics |
| Web Audio API | Audio processing |
| WebRTC | Real-time peer-to-peer communication |
| Service Workers | Offline support and caching |

**Example:**
```html
<script>
  // Geolocation
  navigator.geolocation.getCurrentPosition(
    (pos) => console.log("Lat:", pos.coords.latitude, "Lng:", pos.coords.longitude),
    (err) => console.error("Error:", err.message)
  );

  // Notification
  Notification.requestPermission().then((perm) => {
    if (perm === "granted") {
      new Notification("Hello!", { body: "This is a browser notification." });
    }
  });

  // Fetch API
  fetch("https://api.example.com/data")
    .then((res) => res.json())
    .then((data) => console.log(data))
    .catch((err) => console.error(err));

  // History API
  history.pushState({ page: 2 }, "Page 2", "/page-2");

  // Web Worker
  const worker = new Worker("worker.js");
  worker.postMessage("start");
  worker.onmessage = (e) => console.log("Worker result:", e.data);

  // WebSocket
  const ws = new WebSocket("wss://example.com/socket");
  ws.onopen = () => ws.send("Hello Server!");
  ws.onmessage = (e) => console.log("Server:", e.data);
</script>
```
