# 13. EMBEDDED CONTENT

| Element | Description |
|---------|-------------|
| `<embed>` | External content (PDF, Flash) |
| `<object>` | Generic embedded object |
| `<param>` | Parameter for `<object>` |
| `<iframe>` | Inline frame |
| `<picture>` | Responsive picture container |
| `<source>` | Media source for `<picture>`, `<video>`, `<audio>` |
| `<track>` | Text track (subtitles, captions) |
| `<map>` | Image map |
| `<area>` | Clickable area inside an image map |

**Example:**
```html
<!-- Embed PDF -->
<embed src="document.pdf" type="application/pdf" width="600" height="400" />

<!-- Object with param -->
<object data="movie.swf" type="application/x-shockwave-flash" width="400" height="300">
  <param name="autoplay" value="true" />
  <p>Your browser does not support Flash.</p>
</object>

<!-- Iframe -->
<iframe src="https://www.wikipedia.org" width="800" height="500" title="Wikipedia"></iframe>

<!-- Image Map -->
<img src="world-map.jpg" alt="World Map" usemap="#worldmap" />
<map name="worldmap">
  <area shape="rect" coords="10,10,200,150" href="europe.html" alt="Europe" />
  <area shape="circle" coords="350,200,80" href="asia.html" alt="Asia" />
</map>

<!-- Track (subtitles) -->
<video controls>
  <source src="video.mp4" type="video/mp4" />
  <track src="subtitles_en.vtt" kind="subtitles" srclang="en" label="English" default />
</video>
```
