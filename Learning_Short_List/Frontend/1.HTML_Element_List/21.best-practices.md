# 21. BEST PRACTICES

### ✅ DO's
- Use semantic HTML elements (`<header>`, `<main>`, `<article>`, etc.)
- Always include `alt` text for images
- Use proper heading hierarchy (`<h1>` → `<h2>` → `<h3>`)
- Include `<meta name="viewport">` for responsive design
- Validate your HTML at [validator.w3.org](https://validator.w3.org/)
- Use descriptive link text (not "click here")
- Include `<label>` for every form input
- Structure content logically with semantic tags
- Use ARIA attributes when semantic HTML is insufficient
- Optimize images (compress, use `srcset`, `loading="lazy"`)

### ❌ DON'Ts
- Don't use deprecated tags (`<center>`, `<font>`, `<big>`, etc.)
- Don't use tables for page layout
- Don't skip heading levels (h1 → h3, skipping h2)
- Don't use excessive inline styles — use CSS classes
- Don't forget to close tags properly
- Don't use non-semantic `<div>` where semantic tags exist
- Don't ignore accessibility (contrast, keyboard nav, ARIA)
- Don't nest `<div>` excessively
- Don't forget `<!DOCTYPE html>` declaration
- Don't use deprecated attributes (`align`, `bgcolor`, `border` on elements)
