# 6. IMAGES & MEDIA

| Element | Description |
|---------|-------------|
| `<img>` | Image |
| `<figure>` | Figure container |
| `<figcaption>` | Figure caption |
| `<picture>` | Responsive image container |
| `<source>` | Media source |
| `<video>` | Video |
| `<audio>` | Audio |
| `<track>` | Text track (subtitles) |
| `<iframe>` | Inline frame |
| `<embed>` | Embedded content |
| `<object>` | Object container |
| `<canvas>` | Drawing canvas |
| `<svg>` | Scalable vector graphics |

**Example:**
```html
<!-- Image with alt text -->
<img src="photo.jpg" alt="A scenic mountain view" width="600" height="400" />

<!-- Figure with caption -->
<figure>
  <img src="chart.png" alt="Sales chart" />
  <figcaption>Figure 1: Monthly Sales 2025</figcaption>
</figure>

<!-- Responsive picture -->
<picture>
  <source srcset="large.jpg" media="(min-width: 800px)" />
  <source srcset="medium.jpg" media="(min-width: 400px)" />
  <img src="small.jpg" alt="Responsive image" />
</picture>

<!-- Video -->
<video controls width="640" poster="thumbnail.jpg">
  <source src="movie.mp4" type="video/mp4" />
  <track src="subtitles.vtt" kind="subtitles" srclang="en" label="English" />
  Your browser does not support video.
</video>

<!-- Audio -->
<audio controls>
  <source src="song.mp3" type="audio/mpeg" />
  Your browser does not support audio.
</audio>

<!-- Iframe (embed YouTube) -->
<iframe
  src="https://www.youtube.com/embed/dQw4w9WgXcQ"
  width="560" height="315"
  allowfullscreen
  title="YouTube video">
</iframe>

<!-- Inline SVG -->
<svg width="100" height="100" xmlns="http://www.w3.org/2000/svg">
  <circle cx="50" cy="50" r="40" fill="steelblue" />
</svg>
```
