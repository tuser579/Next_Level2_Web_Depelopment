# 4. TEXT FORMATTING

| Element | Description |
|---------|-------------|
| `<strong>` | Important text (bold) |
| `<b>` | Bold text |
| `<em>` | Emphasized text (italic) |
| `<i>` | Italic text |
| `<u>` | Underlined text |
| `<s>` | Strikethrough text |
| `<mark>` | Highlighted text |
| `<small>` | Smaller text |
| `<sub>` | Subscript |
| `<sup>` | Superscript |
| `<del>` | Deleted text |
| `<ins>` | Inserted text |
| `<code>` | Inline code snippet |
| `<kbd>` | Keyboard input |
| `<samp>` | Sample output |
| `<var>` | Variable |
| `<abbr>` | Abbreviation |
| `<cite>` | Citation |
| `<dfn>` | Definition |
| `<time>` | Date/time |

**Example:**
```html
<p>This is <strong>very important</strong> and <em>emphasized</em> text.</p>
<p>Price was <del>$50</del> now <ins>$30</ins>.</p>
<p>Water formula: H<sub>2</sub>O &nbsp; Area: m<sup>2</sup></p>
<p>Use <kbd>Ctrl + S</kbd> to save. Output: <samp>File saved.</samp></p>
<p>Variable: <var>x</var> = 10</p>
<p><mark>Highlighted</mark>, <small>smaller</small>, <u>underlined</u>, <s>struck</s></p>
<p><abbr title="HyperText Markup Language">HTML</abbr> is a markup language.</p>
<p><cite>MDN Web Docs</cite> — great reference.</p>
<p><dfn>Semantic</dfn> means meaningful structure.</p>
<p>Meeting at <time datetime="2025-09-01T10:00">Sep 1, 10:00 AM</time>.</p>
<p>Inline code: <code>console.log("Hello")</code></p>
```
