# 14. WEB COMPONENTS

| Element | Description |
|---------|-------------|
| `<template>` | Reusable HTML template |
| `<slot>` | Slot inside shadow DOM |
| Custom Elements | User-defined HTML elements |
| Shadow DOM | Encapsulated DOM tree |

**Example:**
```html
<!-- Define a custom element -->
<script>
  class MyCard extends HTMLElement {
    connectedCallback() {
      this.innerHTML = `
        <style>
          .card { border: 1px solid #ccc; padding: 16px; border-radius: 8px; }
        </style>
        <div class="card">
          <slot name="title"><h2>Default Title</h2></slot>
          <slot name="content"><p>Default content.</p></slot>
        </div>
      `;
    }
  }
  customElements.define("my-card", MyCard);
</script>

<!-- Use the custom element -->
<my-card>
  <h2 slot="title">Custom Card Title</h2>
  <p slot="content">This is the card content passed via slot.</p>
</my-card>
```
