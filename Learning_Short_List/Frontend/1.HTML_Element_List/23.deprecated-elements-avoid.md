# 23. DEPRECATED ELEMENTS (Avoid)

| Element | Replacement |
|---------|-------------|
| `<center>` | Use `text-align: center` in CSS |
| `<font>` | Use CSS `font-family`, `font-size`, `color` |
| `<big>` | Use CSS `font-size` |
| `<strike>` | Use `<s>` or `<del>` |
| `<tt>` | Use `<code>` or CSS `font-family: monospace` |
| `<frame>` | Use `<iframe>` |
| `<frameset>` | Use CSS layout |
| `<noframes>` | Remove entirely |
| `<applet>` | Use `<embed>` or `<object>` |
| `<basefont>` | Use CSS |
| `<dir>` | Use `<ul>` |
| `<acronym>` | Use `<abbr>` |

**Example (❌ deprecated vs. ✅ modern):**
```html
<!-- ❌ Deprecated -->
<center><font color="red" size="5">Old Style</font></center>
<strike>Old strikethrough</strike>
<acronym title="HyperText Markup Language">HTML</acronym>

<!-- ✅ Modern HTML + CSS -->
<p style="text-align: center; color: red; font-size: 1.5rem;">Modern Style</p>
<s>Modern strikethrough</s>
<abbr title="HyperText Markup Language">HTML</abbr>
```
