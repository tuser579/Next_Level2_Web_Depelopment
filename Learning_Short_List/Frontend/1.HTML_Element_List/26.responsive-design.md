# 26. RESPONSIVE DESIGN

| Technique | Description |
|-----------|-------------|
| `<meta name="viewport">` | Control layout on mobile |
| `<picture>` | Responsive image with art direction |
| `<source media="...">` | Media query for image sources |
| `<img srcset="...">` | Responsive image resolution switching |
| CSS Media Queries | Adapt layout to screen size |

**Example:**
```html
<!-- Viewport meta (REQUIRED for responsive design) -->
<meta name="viewport" content="width=device-width, initial-scale=1.0" />

<!-- Responsive image with srcset -->
<img
  src="image-400.jpg"
  srcset="image-400.jpg 400w, image-800.jpg 800w, image-1200.jpg 1200w"
  sizes="(max-width: 600px) 400px, (max-width: 1024px) 800px, 1200px"
  alt="Responsive image example"
/>

<!-- Art direction with picture -->
<picture>
  <source srcset="wide-banner.jpg" media="(min-width: 1024px)" />
  <source srcset="tablet-banner.jpg" media="(min-width: 600px)" />
  <img src="mobile-banner.jpg" alt="Banner" />
</picture>

<!-- Responsive iframe embed (16:9 ratio) -->
<div style="position: relative; padding-bottom: 56.25%; height: 0;">
  <iframe
    src="https://www.youtube.com/embed/dQw4w9WgXcQ"
    style="position: absolute; top: 0; left: 0; width: 100%; height: 100%;"
    allowfullscreen
    title="Responsive video embed">
  </iframe>
</div>
```
