# 18. CANVAS & SVG

| Element | Description |
|---------|-------------|
| `<canvas>` | Bitmap drawing canvas (via JavaScript) |
| `<svg>` | Scalable vector graphics |

**Canvas Methods:**

| Method | Description |
|--------|-------------|
| `getContext()` | Get drawing context |
| `fillRect()` | Draw filled rectangle |
| `strokeRect()` | Draw rectangle outline |
| `clearRect()` | Clear rectangle area |
| `beginPath()` | Start a new path |
| `moveTo()` | Move to a point |
| `lineTo()` | Draw line to a point |
| `arc()` | Draw arc or circle |
| `fill()` | Fill the current shape |
| `stroke()` | Stroke the current shape |
| `drawImage()` | Draw an image onto canvas |

**Example:**
```html
<!-- Canvas -->
<canvas id="myCanvas" width="400" height="200" style="border: 1px solid #ccc;"></canvas>
<script>
  const canvas = document.getElementById("myCanvas");
  const ctx = canvas.getContext("2d");

  // Draw filled rectangle
  ctx.fillStyle = "steelblue";
  ctx.fillRect(20, 20, 150, 100);

  // Draw circle
  ctx.beginPath();
  ctx.arc(300, 100, 60, 0, Math.PI * 2);
  ctx.fillStyle = "coral";
  ctx.fill();
  ctx.strokeStyle = "darkred";
  ctx.stroke();

  // Draw line
  ctx.beginPath();
  ctx.moveTo(20, 180);
  ctx.lineTo(380, 180);
  ctx.strokeStyle = "black";
  ctx.stroke();
</script>

<!-- Inline SVG -->
<svg width="200" height="100" xmlns="http://www.w3.org/2000/svg">
  <rect x="10" y="10" width="80" height="80" fill="teal" rx="10" />
  <circle cx="150" cy="50" r="40" fill="orange" stroke="brown" stroke-width="3" />
  <text x="10" y="95" font-size="12" fill="gray">SVG Example</text>
</svg>
```
