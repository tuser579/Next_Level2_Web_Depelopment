# 15. GLOBAL ATTRIBUTES

| Attribute | Description |
|-----------|-------------|
| `id` | Unique identifier |
| `class` | CSS class name(s) |
| `style` | Inline CSS styles |
| `title` | Tooltip text |
| `lang` | Language code |
| `dir` | Text direction (`ltr`, `rtl`) |
| `hidden` | Hide element |
| `tabindex` | Tab order |
| `accesskey` | Keyboard shortcut |
| `contenteditable` | Editable content |
| `draggable` | Enable drag and drop |
| `spellcheck` | Spell checking |
| `translate` | Translation hint |
| `data-*` | Custom data attributes |
| `role` | ARIA role |
| `aria-*` | Accessibility attributes |

**Example:**
```html
<!-- id, class, style, title -->
<p id="intro" class="highlight main-text" style="color: navy;" title="Introduction paragraph">
  Welcome to my site.
</p>

<!-- lang, dir -->
<p lang="ar" dir="rtl">مرحباً بالعالم</p>

<!-- hidden -->
<p hidden>This paragraph is hidden from view.</p>

<!-- tabindex -->
<div tabindex="0">Focusable div element</div>

<!-- accesskey -->
<a href="/home" accesskey="h">Home (Alt+H)</a>

<!-- contenteditable -->
<div contenteditable="true" spellcheck="true">
  Click here to edit this text directly in the browser.
</div>

<!-- draggable -->
<img src="icon.png" alt="Drag me" draggable="true" />

<!-- data-* custom attributes -->
<button data-user-id="42" data-action="delete" onclick="handleDelete(this)">Delete</button>
<script>
  function handleDelete(btn) {
    console.log("User ID:", btn.dataset.userId);
  }
</script>

<!-- translate -->
<p translate="no">Brand Name™</p>
```
