# 24. CHARACTER ENTITIES

| Entity | Character |
|--------|-----------|
| `&amp;` | & |
| `&lt;` | < |
| `&gt;` | > |
| `&quot;` | " |
| `&apos;` | ' |
| `&nbsp;` | Non-breaking space |
| `&copy;` | © |
| `&reg;` | ® |
| `&trade;` | ™ |
| `&euro;` | € |
| `&pound;` | £ |
| `&yen;` | ¥ |
| `&cent;` | ¢ |
| `&hellip;` | … |
| `&mdash;` | — |
| `&ndash;` | – |
| `&lsquo;` | ' |
| `&rsquo;` | ' |
| `&ldquo;` | " |
| `&rdquo;` | " |

**Example:**
```html
<p>Copyright &copy; 2025 &mdash; All Rights Reserved &reg;</p>
<p>Price: &euro;99.99 &nbsp;&nbsp; (approx. &pound;85 or &yen;14500)</p>
<p>Use &lt;p&gt; for paragraphs &amp; &lt;h1&gt; for headings.</p>
<p>She said &ldquo;Hello&rdquo; and smiled&hellip;</p>
<p>It&rsquo;s a &trade; product.</p>
```
