# 16. EVENT HANDLERS

| Event | Description |
|-------|-------------|
| `onclick` | Mouse click |
| `ondblclick` | Double click |
| `onmouseover` | Mouse over element |
| `onmouseout` | Mouse leaves element |
| `onmousedown` | Mouse button pressed |
| `onmouseup` | Mouse button released |
| `onmousemove` | Mouse moves |
| `onkeydown` | Key pressed down |
| `onkeyup` | Key released |
| `onkeypress` | Key pressed (deprecated) |
| `onfocus` | Element gains focus |
| `onblur` | Element loses focus |
| `onchange` | Value changed |
| `onsubmit` | Form submitted |
| `onreset` | Form reset |
| `onload` | Page/resource loaded |
| `onunload` | Page unloaded |
| `onerror` | Error occurred |
| `onscroll` | Page/element scrolled |
| `onresize` | Window resized |

**Example:**
```html
<!-- onclick / ondblclick -->
<button onclick="alert('Clicked!')" ondblclick="alert('Double clicked!')">Click Me</button>

<!-- onmouseover / onmouseout -->
<p onmouseover="this.style.color='red'" onmouseout="this.style.color='black'">Hover over me!</p>

<!-- onkeydown / onkeyup -->
<input type="text"
  onkeydown="console.log('Key down:', event.key)"
  onkeyup="console.log('Key up:', event.key)"
  placeholder="Type here" />

<!-- onfocus / onblur -->
<input type="text"
  onfocus="this.style.border='2px solid blue'"
  onblur="this.style.border=''"
  placeholder="Focus me" />

<!-- onchange -->
<select onchange="console.log('Selected:', this.value)">
  <option value="html">HTML</option>
  <option value="css">CSS</option>
  <option value="js">JavaScript</option>
</select>

<!-- onsubmit -->
<form onsubmit="event.preventDefault(); alert('Form submitted!')">
  <input type="text" name="name" required />
  <button type="submit">Submit</button>
</form>

<!-- onscroll -->
<div style="height:200px; overflow-y:scroll;" onscroll="console.log('Scrolling...')">
  <p style="height:500px;">Scroll inside me</p>
</div>

<!-- onload / onerror -->
<body onload="console.log('Page fully loaded!')">
  <img src="broken.jpg" alt="Image" onerror="this.src='fallback.jpg'" />
</body>
```
