# 25. HTML VALIDATION

**Required Attributes:**

| Element | Required Attribute |
|---------|-------------------|
| `<img>` | `alt` |
| `<a>` | `href` |
| `<video>`, `<audio>`, `<img>` | `src` |
| `<input>` | `type` |
| Form elements | `name` |

**Example:**
```html
<!-- ❌ Invalid: tags not closed properly -->
<p><b>Bold text</p></b>
<ul><p>Wrong child</p></ul>

<!-- ✅ Valid: correct nesting -->
<p><b>Bold text</b></p>
<ul>
  <li>Correct item</li>
  <li>Another item</li>
</ul>

<!-- ✅ Valid document structure -->
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title>Valid Page</title>
  </head>
  <body>
    <h1>Heading</h1>
    <img src="photo.jpg" alt="Description" />
    <a href="https://example.com">Link text</a>
  </body>
</html>
```
