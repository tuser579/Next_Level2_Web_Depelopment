# 29. POSTGRESQL INDEXES & PERFORMANCE

| Command / Option | Syntax Example | Description |
| --- | --- | --- |
| `CREATE INDEX` | `CREATE INDEX idx_cars_brand ON cars(brand);` | Creates B-Tree index for faster lookups |
| `CREATE UNIQUE INDEX`| `CREATE UNIQUE INDEX idx_uq_email ON users(email);` | Enforces uniqueness while indexing |
| Composite Index | `CREATE INDEX idx_cars_brand_year ON cars(brand, year);` | Multi-column index |
| `DROP INDEX` | `DROP INDEX IF EXISTS idx_cars_brand;` | Deletes an index |
| `EXPLAIN ANALYZE` | `EXPLAIN ANALYZE SELECT * FROM cars WHERE brand = 'Volvo';` | Shows query execution plan and runtime |

**Example:**
```sql
-- 1. Create B-Tree index on frequently filtered column
CREATE INDEX idx_customers_email ON customers(email);

-- 2. Multi-column index for combined filtering/sorting
CREATE INDEX idx_orders_customer_date ON orders(customer_id, order_date DESC);

-- 3. Analyze Query Execution Plan
EXPLAIN ANALYZE 
SELECT * FROM customers 
WHERE email = 'alex@example.com';

-- 4. Drop index if no longer needed
DROP INDEX IF EXISTS idx_customers_email;
```
