# 18. POSTGRESQL UNION & UNION ALL

| Operator | Syntax | Description |
| --- | --- | --- |
| `UNION` | `SELECT col FROM t1 UNION SELECT col FROM t2;` | Combines result sets and removes duplicate rows |
| `UNION ALL` | `SELECT col FROM t1 UNION ALL SELECT col FROM t2;` | Combines result sets and keeps all duplicates (faster) |
| `INTERSECT` | `SELECT col FROM t1 INTERSECT SELECT col FROM t2;` | Returns only rows present in both result sets |
| `EXCEPT` | `SELECT col FROM t1 EXCEPT SELECT col FROM t2;` | Returns rows in first query that are not in second |

**Example:**
```sql
-- 1. UNION: Unique list of cities from customers and suppliers
SELECT city FROM customers
UNION
SELECT city FROM suppliers
ORDER BY city;

-- 2. UNION ALL: Full list with duplicates included
SELECT city, 'Customer' AS source_type FROM customers
UNION ALL
SELECT city, 'Supplier' AS source_type FROM suppliers;

-- 3. INTERSECT: Cities where we have both customers AND suppliers
SELECT city FROM customers
INTERSECT
SELECT city FROM suppliers;

-- 4. EXCEPT: Cities where we have customers but NO suppliers
SELECT city FROM customers
EXCEPT
SELECT city FROM suppliers;
```
