# 23. POSTGRESQL NULL FUNCTIONS (COALESCE, NULLIF)

| Function | Syntax Example | Description |
| --- | --- | --- |
| `COALESCE()` | `COALESCE(val1, val2, fallback)` | Returns first non-NULL value in list |
| `NULLIF()` | `NULLIF(val1, val2)` | Returns NULL if `val1 = val2`; otherwise returns `val1` |
| `IS NULL` | `WHERE phone IS NULL` | Evaluates to true if value is NULL |
| `IS NOT NULL` | `WHERE phone IS NOT NULL` | Evaluates to true if value has data |

**Example:**
```sql
-- 1. COALESCE: Provide fallback for missing phone numbers or emails
SELECT 
    customer_name,
    COALESCE(phone, mobile, 'No Contact Provided') AS primary_contact
FROM customers;

-- 2. NULLIF: Avoid division by zero errors
SELECT 
    product_name,
    revenue,
    units_sold,
    revenue / NULLIF(units_sold, 0) AS unit_price_calc
FROM sales_records;

-- 3. COALESCE combined with aggregate count
SELECT 
    category,
    COALESCE(SUM(total_amount), 0) AS total_revenue
FROM orders
GROUP BY category;
```
