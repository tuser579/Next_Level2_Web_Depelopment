# 26. POSTGRESQL ARRAYS & ENUM TYPES

| Feature / Concept | Syntax Example | Description |
| --- | --- | --- |
| Array Column | `tags TEXT[]`, `scores INT[]` | Stores list of elements in a single column |
| Array Literal | `ARRAY['sql', 'postgres']` | Array constructor syntax |
| Array Indexing | `tags[1]` | 1-based indexing into array element |
| `ANY()` Operator | `'react' = ANY(tags)` | Tests if value exists in array |
| `unnest()` | `SELECT unnest(tags)` | Expands array into individual rows |
| `CREATE TYPE ... ENUM` | `CREATE TYPE status AS ENUM ('open', 'closed');` | User-defined static set of values |

**Example:**
```sql
-- 1. Create Custom Enum Type
CREATE TYPE task_priority AS ENUM ('low', 'medium', 'high', 'urgent');

-- 2. Table with Array and Enum
CREATE TABLE project_tasks (
    task_id SERIAL PRIMARY KEY,
    title VARCHAR(150) NOT NULL,
    priority task_priority DEFAULT 'medium',
    tags TEXT[] DEFAULT '{}'
);

-- 3. Insert records
INSERT INTO project_tasks (title, priority, tags)
VALUES 
  ('Fix login bug', 'urgent', ARRAY['auth', 'backend', 'bug']),
  ('Update documentation', 'low', ARRAY['docs', 'frontend']);

-- 4. Query using ANY() and 1-based indexing
SELECT title, priority, tags[1] AS primary_tag 
FROM project_tasks 
WHERE 'backend' = ANY(tags);

-- 5. Flatten array with unnest
SELECT title, unnest(tags) AS tag 
FROM project_tasks;
```
