# 7. POSTGRESQL INSERT INTO & RETURNING

| Statement / Clause | Syntax Example | Description |
| --- | --- | --- |
| `INSERT INTO` (All cols) | `INSERT INTO cars VALUES ('Volvo', 'XC90', 2022);` | Inserts values for all table columns |
| `INSERT INTO` (Specific cols)| `INSERT INTO cars (brand, model) VALUES ('Ford', 'Mustang');` | Inserts values into specified columns |
| Multiple Rows Insert | `INSERT INTO cars VALUES ('BMW', 'M3', 2021), ('Audi', 'RS6', 2023);` | Inserts multiple rows in a single query |
| `RETURNING` | `INSERT INTO cars (...) VALUES (...) RETURNING *;` | Returns inserted rows immediately |
| `ON CONFLICT` | `INSERT ... ON CONFLICT (id) DO NOTHING;` | Handles duplicate key violations gracefully |

**Example:**
```sql
CREATE TABLE IF NOT EXISTS cars (
    id INT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    brand VARCHAR(255),
    model VARCHAR(255),
    year INT
);

-- 1. Insert multiple rows with RETURNING clause
INSERT INTO cars (brand, model, year)
VALUES 
  ('Volvo', 'p1800', 1968),
  ('BMW', 'M1', 1978),
  ('Toyota', 'Celica', 1975)
RETURNING id, brand, model;

-- 2. Insert with ON CONFLICT (UPSERT)
INSERT INTO cars (id, brand, model, year)
OVERRIDING SYSTEM VALUE
VALUES (1, 'Volvo', 'p1800 Modified', 1970)
ON CONFLICT (id) 
DO UPDATE SET model = EXCLUDED.model, year = EXCLUDED.year
RETURNING *;
```
