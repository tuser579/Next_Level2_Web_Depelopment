# 15. POSTGRESQL IN & BETWEEN OPERATORS

| Operator | Syntax Example | Description |
| --- | --- | --- |
| `IN (...)` | `WHERE brand IN ('Volvo', 'BMW', 'Ford')` | Shorthand for multiple `OR` conditions |
| `NOT IN (...)` | `WHERE brand NOT IN ('Audi', 'Toyota')` | Excludes all listed values |
| `IN (SELECT ...)`| `WHERE user_id IN (SELECT id FROM vip_users)` | Matches results from subquery list |
| `BETWEEN` | `WHERE year BETWEEN 1970 AND 1980` | Range filter, inclusive of boundary values |
| `NOT BETWEEN` | `WHERE price NOT BETWEEN 10 AND 50` | Excludes values within range |
| Date `BETWEEN` | `WHERE order_date BETWEEN '2026-01-01' AND '2026-01-31'` | Filters records within date interval |

**Example:**
```sql
-- 1. Using IN with discrete list of strings
SELECT * FROM cars 
WHERE brand IN ('Volvo', 'Mercedes', 'Porsche');

-- 2. Range filtering using BETWEEN on numbers
SELECT * FROM cars 
WHERE year BETWEEN 1965 AND 1975;

-- 3. Filtering by Date Range
SELECT * FROM orders 
WHERE order_date BETWEEN '2026-01-01' AND '2026-12-31';

-- 4. Using IN with a subquery
SELECT * FROM customers 
WHERE customer_id IN (
    SELECT customer_id FROM orders WHERE total_amount > 500
);
```
