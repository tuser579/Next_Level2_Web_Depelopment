# 9. POSTGRESQL WHERE & LOGICAL OPERATORS

| Operator | Meaning | Example |
| --- | --- | --- |
| `=` | Equal to | `WHERE brand = 'Volvo'` |
| `<>` or `!=` | Not equal to | `WHERE brand <> 'Ford'` |
| `>`, `<` | Greater than, Less than | `WHERE year > 2015` |
| `>=`, `<=` | Greater or equal, Less or equal | `WHERE year <= 2020` |
| `AND` | True if all conditions are true | `WHERE brand = 'Volvo' AND year > 1970` |
| `OR` | True if any condition is true | `WHERE brand = 'Volvo' OR brand = 'Ford'` |
| `NOT` | Reverses condition boolean value | `WHERE NOT brand = 'BMW'` |
| `IS NULL` / `IS NOT NULL` | Null check | `WHERE model IS NOT NULL` |

**Example:**
```sql
-- 1. Simple equality filter
SELECT * FROM cars 
WHERE brand = 'Volvo';

-- 2. Combining conditions with AND / OR
SELECT * FROM cars 
WHERE (brand = 'Volvo' OR brand = 'BMW') 
  AND year >= 1975;

-- 3. Filtering using NOT and inequality
SELECT * FROM cars 
WHERE brand != 'Ford' 
  AND year IS NOT NULL;
```
