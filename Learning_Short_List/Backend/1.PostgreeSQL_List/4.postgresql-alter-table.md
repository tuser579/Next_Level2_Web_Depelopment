# 4. POSTGRESQL ALTER TABLE (ADD, DROP, ALTER COLUMN)

| Action | Syntax Example | Description |
| --- | --- | --- |
| `ADD COLUMN` | `ALTER TABLE cars ADD color VARCHAR(50);` | Adds a new column to existing table |
| `DROP COLUMN` | `ALTER TABLE cars DROP COLUMN color;` | Removes a column from the table |
| `ALTER COLUMN TYPE` | `ALTER TABLE cars ALTER COLUMN year TYPE VARCHAR(4);` | Changes the data type of a column |
| `RENAME COLUMN` | `ALTER TABLE cars RENAME COLUMN brand TO make;` | Renames a table column |
| `RENAME TO` | `ALTER TABLE cars RENAME TO vehicles;` | Renames the table itself |
| `SET NOT NULL` | `ALTER TABLE cars ALTER COLUMN model SET NOT NULL;` | Adds NOT NULL constraint to column |
| `DROP NOT NULL` | `ALTER TABLE cars ALTER COLUMN model DROP NOT NULL;` | Removes NOT NULL constraint |

**Example:**
```sql
-- 1. Create base table
CREATE TABLE IF NOT EXISTS cars (
    brand VARCHAR(255),
    model VARCHAR(255),
    year INT
);

-- 2. Add 'color' column
ALTER TABLE cars ADD COLUMN color VARCHAR(50);

-- 3. Change 'year' data type
ALTER TABLE cars ALTER COLUMN year TYPE SMALLINT;

-- 4. Rename column 'brand' to 'make'
ALTER TABLE cars RENAME COLUMN brand TO make;

-- 5. Drop 'color' column
ALTER TABLE cars DROP COLUMN color;
```
