# 28. POSTGRESQL VIEWS & MATERIALIZED VIEWS

| Command | Syntax Example | Description |
| --- | --- | --- |
| `CREATE VIEW` | `CREATE VIEW v_active_cars AS SELECT ...;` | Creates virtual table based on query |
| `CREATE OR REPLACE VIEW`| `CREATE OR REPLACE VIEW v_name AS ...;` | Updates existing view |
| `DROP VIEW` | `DROP VIEW IF EXISTS v_active_cars;` | Deletes view definition |
| `CREATE MATERIALIZED VIEW`| `CREATE MATERIALIZED VIEW mv_sales AS SELECT ...;` | Stores physical result snapshot on disk |
| `REFRESH MATERIALIZED VIEW`| `REFRESH MATERIALIZED VIEW mv_sales;` | Updates data snapshot of materialized view |

**Example:**
```sql
-- 1. Standard View for Simplified Queries
CREATE OR REPLACE VIEW view_expensive_products AS
SELECT 
    product_name,
    category,
    price
FROM products
WHERE price > 100.00;

-- Query the view just like a table
SELECT * FROM view_expensive_products;

-- 2. Materialized View for Heavy Analytical Reports
CREATE MATERIALIZED VIEW mat_view_category_summary AS
SELECT 
    category,
    COUNT(*) AS total_items,
    AVG(price) AS average_price
FROM products
GROUP BY category
WITH DATA;

-- Refresh Materialized View
REFRESH MATERIALIZED VIEW mat_view_category_summary;
```
