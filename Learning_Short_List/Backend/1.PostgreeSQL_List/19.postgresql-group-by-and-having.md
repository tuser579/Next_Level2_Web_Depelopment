# 19. POSTGRESQL GROUP BY & HAVING

| Clause | Syntax Example | Description |
| --- | --- | --- |
| `GROUP BY` | `GROUP BY category` | Groups rows that have same values into summary rows |
| `HAVING` | `HAVING COUNT(*) > 5` | Filters groups based on aggregate conditions (used instead of WHERE) |
| `WHERE` vs `HAVING` | `WHERE price > 10 GROUP BY cat HAVING COUNT(*) > 2` | `WHERE` filters rows before grouping; `HAVING` filters groups after |

**Example:**
```sql
-- 1. Count customers per country
SELECT 
    country, 
    COUNT(customer_id) AS total_customers
FROM customers
GROUP BY country
ORDER BY total_customers DESC;

-- 2. Filter aggregated groups with HAVING
SELECT 
    country, 
    COUNT(customer_id) AS total_customers
FROM customers
GROUP BY country
HAVING COUNT(customer_id) >= 5
ORDER BY total_customers DESC;

-- 3. Complex grouping with WHERE and HAVING combined
SELECT 
    category,
    COUNT(*) AS total_items,
    AVG(price) AS average_price
FROM products
WHERE in_stock = true
GROUP BY category
HAVING AVG(price) > 50.00;
```
