# 8. POSTGRESQL SELECT & SELECT DISTINCT

| Clause / Keyword | Syntax Example | Description |
| --- | --- | --- |
| `SELECT *` | `SELECT * FROM cars;` | Returns all columns from table |
| `SELECT` specific columns | `SELECT brand, year FROM cars;` | Returns only specified columns |
| `SELECT DISTINCT` | `SELECT DISTINCT brand FROM cars;` | Returns unique values, eliminating duplicate rows |
| `COUNT(DISTINCT)` | `SELECT COUNT(DISTINCT brand) FROM cars;` | Counts the number of distinct values |

**Example:**
```sql
-- 1. Select all columns
SELECT * FROM cars;

-- 2. Select specific columns
SELECT brand, model FROM cars;

-- 3. Select distinct brands only
SELECT DISTINCT brand FROM cars;

-- 4. Count distinct brands
SELECT COUNT(DISTINCT brand) AS unique_brands_count 
FROM cars;
```
