# 27. POSTGRESQL JSON & JSONB OPERATIONS

| Operator / Function | Syntax Example | Description |
| --- | --- | --- |
| `->` | `info -> 'age'` | Extracts JSON object field as JSON |
| `->>` | `info ->> 'age'` | Extracts JSON object field as `text` |
| `#>` / `#>>` | `info #>> '{address, city}'` | Extracts nested field at path as JSON / text |
| `@>` | `data @> '{"role": "admin"}'` | Containment test (does left contain right?) |
| `?` | `data ? 'email'` | Existence test (does key exist in JSON?) |
| `jsonb_set()` | `jsonb_set(data, '{theme}', '"dark"')` | Modifies or sets value at specified path |

**Example:**
```sql
CREATE TABLE user_profiles (
    id SERIAL PRIMARY KEY,
    username VARCHAR(50) NOT NULL,
    profile_data JSONB NOT NULL DEFAULT '{}'
);

-- 1. Insert JSONB document
INSERT INTO user_profiles (username, profile_data)
VALUES ('alice', '{"theme": "dark", "notifications": true, "skills": ["sql", "postgres"], "address": {"city": "Boston"}}');

-- 2. Extract values
SELECT 
    username,
    profile_data ->> 'theme' AS preferred_theme,
    profile_data #>> '{address, city}' AS user_city
FROM user_profiles
WHERE profile_data @> '{"notifications": true}';

-- 3. Update JSONB value
UPDATE user_profiles
SET profile_data = jsonb_set(profile_data, '{theme}', '"light"')
WHERE username = 'alice';
```
