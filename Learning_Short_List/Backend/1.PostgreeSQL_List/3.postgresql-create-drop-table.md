# 3. POSTGRESQL CREATE & DROP TABLE

| Statement / Clause | Syntax Example | Description |
| --- | --- | --- |
| `CREATE TABLE` | `CREATE TABLE table_name (col1 type, col2 type);` | Creates a new relational table |
| `IF NOT EXISTS` | `CREATE TABLE IF NOT EXISTS cars (...);` | Prevents error if table already exists |
| `DROP TABLE` | `DROP TABLE cars;` | Deletes table schema and all its records |
| `DROP TABLE IF EXISTS` | `DROP TABLE IF EXISTS cars CASCADE;` | Safely removes table and dependent objects |
| `TRUNCATE TABLE` | `TRUNCATE TABLE cars;` | Quickly empties all records from table |
| `RESTART IDENTITY` | `TRUNCATE TABLE cars RESTART IDENTITY;` | Resets auto-increment counters back to 1 |

**Example:**
```sql
-- 1. Create a cars table
CREATE TABLE IF NOT EXISTS cars (
    brand VARCHAR(255),
    model VARCHAR(255),
    year INT
);

-- 2. View table structure
-- In psql: \d cars

-- 3. Empty all rows
TRUNCATE TABLE cars;

-- 4. Delete the table
-- DROP TABLE IF EXISTS cars;
```
