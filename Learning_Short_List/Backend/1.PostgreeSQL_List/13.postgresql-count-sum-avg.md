# 13. POSTGRESQL COUNT, SUM & AVG FUNCTIONS

| Function | Syntax Example | Description |
| --- | --- | --- |
| `COUNT(*)` | `SELECT COUNT(*) FROM orders;` | Returns total number of rows matching query |
| `COUNT(col)` | `SELECT COUNT(customer_id) FROM orders;` | Counts non-NULL values in specific column |
| `COUNT(DISTINCT)`| `SELECT COUNT(DISTINCT customer_id) FROM orders;` | Counts unique non-NULL values |
| `SUM()` | `SELECT SUM(total_amount) FROM orders;` | Computes the total sum of numeric column |
| `AVG()` | `SELECT AVG(price) FROM products;` | Calculates the arithmetic mean of numeric column |
| `ROUND()` | `SELECT ROUND(AVG(price), 2) FROM products;` | Rounds numeric calculation to specified decimal places |

**Example:**
```sql
-- 1. General order metrics
SELECT 
    COUNT(*) AS total_orders_placed,
    COUNT(DISTINCT customer_id) AS unique_customers_count,
    SUM(total_amount) AS total_revenue,
    ROUND(AVG(total_amount), 2) AS average_order_value
FROM orders;

-- 2. Aggregations grouped by category
SELECT 
    category,
    COUNT(*) AS product_count,
    ROUND(AVG(price), 2) AS avg_product_price,
    SUM(stock_quantity) AS total_units_in_stock
FROM products
GROUP BY category;
```
