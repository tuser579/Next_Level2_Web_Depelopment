# 11. POSTGRESQL UPDATE & DELETE

| Statement / Clause | Syntax Example | Description |
| --- | --- | --- |
| `UPDATE ... SET` | `UPDATE cars SET color = 'red' WHERE brand = 'Volvo';` | Modifies existing records |
| `UPDATE` multiple cols | `UPDATE cars SET color = 'red', year = 1970 WHERE id = 1;` | Updates several columns at once |
| `DELETE FROM` | `DELETE FROM cars WHERE brand = 'Ford';` | Removes rows matching condition |
| `DELETE` all rows | `DELETE FROM cars;` | Removes all rows from table |
| `RETURNING` | `UPDATE cars SET year = 2024 WHERE id = 1 RETURNING *;` | Returns modified or deleted rows |

**Example:**
```sql
-- 1. Update single record with RETURNING
UPDATE cars
SET color = 'Midnight Blue', year = 1972
WHERE id = 1
RETURNING *;

-- 2. Update with mathematical modification
UPDATE products
SET price = price * 1.05
WHERE category = 'Accessories';

-- 3. Delete specific records
DELETE FROM cars
WHERE year < 1970
RETURNING id, brand, model;
```
