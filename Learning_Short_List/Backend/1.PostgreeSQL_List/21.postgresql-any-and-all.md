# 21. POSTGRESQL ANY & ALL OPERATORS

| Operator | Syntax Example | Description |
| --- | --- | --- |
| `= ANY()` | `WHERE col = ANY(ARRAY['a', 'b'])` | True if value matches any item in array or subquery |
| `> ANY()` | `WHERE price > ANY (SELECT price FROM ...)` | True if value is greater than the smallest subquery value |
| `> ALL()` | `WHERE price > ALL (SELECT price FROM ...)` | True if value is greater than every value in subquery |
| `< ALL()` | `WHERE price < ALL (SELECT price FROM ...)` | True if value is smaller than the smallest value |

**Example:**
```sql
-- 1. Using ANY with Array literals
SELECT * FROM cars 
WHERE brand = ANY(ARRAY['Volvo', 'BMW']);

-- 2. Products priced higher than ANY (at least one) product in 'Accessories'
SELECT product_name, price 
FROM products
WHERE price > ANY (
    SELECT price FROM products WHERE category = 'Accessories'
);

-- 3. Products priced higher than ALL products in 'Accessories'
SELECT product_name, price 
FROM products
WHERE price > ALL (
    SELECT price FROM products WHERE category = 'Accessories'
);
```
