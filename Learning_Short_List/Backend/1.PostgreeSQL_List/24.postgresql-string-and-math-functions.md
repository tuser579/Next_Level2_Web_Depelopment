# 24. POSTGRESQL STRING & MATH FUNCTIONS

| Function Category | Function Syntax | Description |
| --- | --- | --- |
| String Concatenation | `CONCAT(a, ' ', b)` or `a \|\| b` | Combines multiple strings |
| Character Length | `LENGTH(str)` or `CHAR_LENGTH(str)`| Returns number of characters |
| Case Transformation | `UPPER(str)`, `LOWER(str)`, `INITCAP(str)` | Converts to uppercase, lowercase, title case |
| Substring & Trim | `SUBSTRING(str FROM 1 FOR 4)`, `TRIM(str)` | Extracts part of text or trims leading/trailing spaces |
| Replacement | `REPLACE(str, 'from', 'to')` | Replaces occurrences of substring |
| Rounding & Abs | `ROUND(num, 2)`, `ABS(num)` | Rounds to decimals or returns absolute value |
| Ceiling & Floor | `CEIL(num)`, `FLOOR(num)` | Smallest integer `>= num` / Largest integer `<= num` |
| Power & Modulo | `POWER(a, b)`, `MOD(a, b)` | Exponentiation and remainder |

**Example:**
```sql
-- 1. String Functions Demonstration
SELECT 
    UPPER(brand) AS brand_upper,
    CONCAT(brand, ' - ', model) AS car_title,
    LENGTH(model) AS model_name_length,
    REPLACE(brand, 'BMW', 'Bayerische Motoren Werke') AS expanded_brand
FROM cars;

-- 2. Math Functions Demonstration
SELECT 
    ROUND(45.6789, 2) AS rounded_val,     -- 45.68
    CEIL(45.1) AS ceiling_val,            -- 46
    FLOOR(45.9) AS floor_val,             -- 45
    POWER(2, 8) AS byte_combinations,     -- 256
    MOD(10, 3) AS remainder_val;          -- 1
```
