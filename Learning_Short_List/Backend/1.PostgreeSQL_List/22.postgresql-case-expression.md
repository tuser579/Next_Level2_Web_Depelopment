# 22. POSTGRESQL CASE CONDITIONAL EXPRESSION

| Syntax Form | Pattern Example | Description |
| --- | --- | --- |
| Searched `CASE` | `CASE WHEN condition THEN result ELSE fallback END` | Evaluates boolean expressions in sequence |
| Simple `CASE` | `CASE col WHEN val1 THEN res1 ELSE res2 END` | Compares expression to specific values |
| In `SELECT` | `SELECT name, CASE WHEN ... END AS label` | Creates conditional columns |
| In `ORDER BY` | `ORDER BY CASE WHEN ... END` | Custom conditional sort order |

**Example:**
```sql
-- 1. Categorize products by price range
SELECT 
    product_name,
    price,
    CASE 
        WHEN price < 50 THEN 'Budget'
        WHEN price BETWEEN 50 AND 200 THEN 'Mid-Range'
        WHEN price > 200 THEN 'Premium'
        ELSE 'Unpriced'
    END AS price_tier
FROM products;

-- 2. Custom conditional sorting (Prioritize 'In Stock' items first)
SELECT product_name, in_stock, price
FROM products
ORDER BY 
    CASE 
        WHEN in_stock = true THEN 1 
        ELSE 2 
    END,
    price DESC;
```
