# 2. POSTGRESQL CREATE & DROP DATABASE

| Statement / Clause | Syntax Example | Description |
| --- | --- | --- |
| `CREATE DATABASE` | `CREATE DATABASE my_db;` | Creates a new PostgreSQL database |
| `DROP DATABASE` | `DROP DATABASE my_db;` | Permanently deletes a database |
| `IF NOT EXISTS` | `CREATE DATABASE IF NOT EXISTS my_db;` | Note: PostgreSQL does not support `IF NOT EXISTS` directly in `CREATE DATABASE`, handled via shell/script |
| `IF EXISTS` | `DROP DATABASE IF EXISTS my_db;` | Drops the database only if it exists without throwing error |
| `WITH OWNER` | `CREATE DATABASE store_db WITH OWNER = postgres;` | Specifies the role that owns the database |
| `ENCODING` | `CREATE DATABASE store_db WITH ENCODING = 'UTF8';` | Sets character encoding for database |

**Example:**
```sql
-- 1. Create a new database
CREATE DATABASE testdb
  WITH OWNER = postgres
  ENCODING = 'UTF8';

-- 2. Switch to testdb in psql
\c testdb;

-- 3. Drop database safely (make sure you are connected to a different DB first)
-- \c postgres;
-- DROP DATABASE IF EXISTS testdb;
```
