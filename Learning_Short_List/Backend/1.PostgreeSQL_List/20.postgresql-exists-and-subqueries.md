# 20. POSTGRESQL EXISTS & SUBQUERIES

| Operator / Subquery | Syntax Example | Description |
| --- | --- | --- |
| `EXISTS` | `WHERE EXISTS (SELECT 1 FROM ...)` | Tests for existence of rows returned by subquery (returns true/false) |
| `NOT EXISTS` | `WHERE NOT EXISTS (SELECT 1 FROM ...)`| True if subquery returns no rows |
| Scalar Subquery | `SELECT name, (SELECT AVG(price) FROM products) ...` | Returns a single value |
| Subquery in `FROM` | `SELECT * FROM (SELECT id, brand FROM cars) AS c` | Inline derived table |

**Example:**
```sql
-- 1. Customers who have placed at least one order (EXISTS)
SELECT customer_name, email 
FROM customers c
WHERE EXISTS (
    SELECT 1 
    FROM orders o 
    WHERE o.customer_id = c.customer_id
);

-- 2. Customers with NO orders placed (NOT EXISTS)
SELECT customer_name, email 
FROM customers c
WHERE NOT EXISTS (
    SELECT 1 
    FROM orders o 
    WHERE o.customer_id = c.customer_id
);

-- 3. Products priced higher than the overall average price (Scalar Subquery)
SELECT product_name, price 
FROM products
WHERE price > (SELECT AVG(price) FROM products);
```
