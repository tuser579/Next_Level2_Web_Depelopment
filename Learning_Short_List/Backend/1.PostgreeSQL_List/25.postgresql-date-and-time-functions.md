# 25. POSTGRESQL DATE & TIME FUNCTIONS

| Function / Expression | Syntax Example | Description |
| --- | --- | --- |
| Current Timestamp | `NOW()` or `CURRENT_TIMESTAMP` | Returns current date and time with timezone |
| Current Date / Time | `CURRENT_DATE`, `CURRENT_TIME` | Current calendar date / time |
| `EXTRACT()` | `EXTRACT(YEAR FROM created_at)` | Extracts specific field (year, month, day, hour) |
| `DATE_TRUNC()` | `DATE_TRUNC('month', NOW())` | Truncates timestamp to specified precision level |
| `AGE()` | `AGE(timestamp1, timestamp2)` | Calculates interval difference between two dates |
| Date Arithmetic | `NOW() + INTERVAL '7 days'` | Adds or subtracts time intervals |

**Example:**
```sql
-- 1. Current Date & Time values
SELECT 
    CURRENT_DATE AS today,
    CURRENT_TIME AS local_time,
    NOW() AS current_time_utc;

-- 2. Date Subfield Extraction
SELECT 
    order_date,
    EXTRACT(YEAR FROM order_date) AS order_year,
    EXTRACT(MONTH FROM order_date) AS order_month,
    EXTRACT(DOW FROM order_date) AS day_of_week
FROM orders;

-- 3. Date truncation for monthly aggregation
SELECT 
    DATE_TRUNC('month', order_date) AS sales_month,
    SUM(total_amount) AS monthly_revenue
FROM orders
GROUP BY sales_month
ORDER BY sales_month;

-- 4. Age calculation
SELECT 
    customer_name,
    AGE(birth_date) AS exact_age
FROM customers;
```
