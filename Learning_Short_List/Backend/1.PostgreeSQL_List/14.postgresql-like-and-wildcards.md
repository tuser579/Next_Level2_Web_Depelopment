# 14. POSTGRESQL LIKE, ILIKE & WILDCARDS

| Pattern / Wildcard | Description | Example |
| --- | --- | --- |
| `%` Wildcard | Matches zero, one, or multiple characters | `'A%'` (Starts with A), `'%tech%'` (Contains tech) |
| `_` Wildcard | Matches exactly one single character | `'H_t'` (Matches 'Hot', 'Hat', 'Hit') |
| `LIKE` | Case-sensitive pattern matching | `WHERE model LIKE 'M%'` |
| `ILIKE` | Case-insensitive pattern matching (PostgreSQL specific) | `WHERE model ILIKE 'm%'` (Matches 'M3', 'm5') |
| `NOT LIKE` / `NOT ILIKE`| Inverts the pattern match | `WHERE email NOT ILIKE '%@gmail.com'` |

**Example:**
```sql
-- 1. Starts with 'Vol' (case-sensitive)
SELECT * FROM cars 
WHERE brand LIKE 'Vol%';

-- 2. Contains 'pro' (case-insensitive with ILIKE)
SELECT * FROM products 
WHERE product_name ILIKE '%pro%';

-- 3. Exact length wildcard (starts with 'B', followed by exactly two characters)
SELECT * FROM cars 
WHERE brand LIKE 'B__';

-- 4. Exclude specific domain emails
SELECT * FROM users 
WHERE email NOT ILIKE '%@spam.com';
```
