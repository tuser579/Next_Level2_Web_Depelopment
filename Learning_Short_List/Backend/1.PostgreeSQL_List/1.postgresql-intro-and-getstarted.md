# 1. POSTGRESQL INTRO & GETTING STARTED

| Tool / Concept | Syntax / Command | Description |
| --- | --- | --- |
| PostgreSQL | RDBMS | Open-source, powerful, object-relational database management system |
| `psql` CLI | `psql -U username -d dbname` | Interactive command-line terminal client for PostgreSQL |
| pgAdmin | GUI Tool | Popular open-source web/desktop administration tool for PostgreSQL |
| Connect to DB | `\c <dbname>` | Connects/switches to a specified database in psql |
| List Databases | `\l` | Lists all databases on the server |
| List Tables | `\dt` | Displays all user tables in the current database |
| Describe Table | `\d <tablename>` | Shows structure, columns, data types, and indexes of a table |
| Quit psql | `\q` | Exits the psql interactive console |

**Example:**
```sql
-- 1. Check current PostgreSQL server version
SELECT version();

-- 2. Check current connected database and user session
SELECT current_database(), current_user;

-- 3. Basic query demonstration
SELECT 'Welcome to PostgreSQL!' AS greeting;
```
