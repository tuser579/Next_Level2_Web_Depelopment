# 12. POSTGRESQL MIN & MAX FUNCTIONS

| Aggregate Function | Syntax Example | Description |
| --- | --- | --- |
| `MIN()` | `SELECT MIN(year) FROM cars;` | Returns the smallest value in the selected column |
| `MAX()` | `SELECT MAX(price) FROM products;` | Returns the largest value in the selected column |
| With `WHERE` | `SELECT MIN(price) FROM products WHERE in_stock = true;` | Returns minimum value within filtered subset |
| With `GROUP BY` | `SELECT category, MIN(price), MAX(price) FROM products GROUP BY category;` | Finds min and max values per category group |

**Example:**
```sql
-- 1. Find oldest and newest car model year
SELECT 
    MIN(year) AS oldest_car_year,
    MAX(year) AS newest_car_year
FROM cars;

-- 2. Find lowest and highest price in each category
SELECT 
    category,
    MIN(price) AS lowest_price,
    MAX(price) AS highest_price
FROM products
GROUP BY category;
```
