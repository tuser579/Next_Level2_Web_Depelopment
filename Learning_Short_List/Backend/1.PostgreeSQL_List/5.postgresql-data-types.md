# 5. POSTGRESQL DATA TYPES

| Data Type | Category | Syntax / Storage | Description |
| --- | --- | --- | --- |
| `INTEGER` / `INT` | Numeric | 4 bytes | Standard integer range (-2B to +2B) |
| `BIGINT` | Numeric | 8 bytes | Large integer range |
| `NUMERIC(p, s)` | Numeric | Variable | Exact numeric with precision `p` and scale `s` |
| `VARCHAR(n)` | Character | Up to `n` characters | Variable-length character string |
| `CHAR(n)` | Character | Fixed `n` characters | Fixed-length, space-padded string |
| `TEXT` | Character | Unlimited (~1GB) | Unlimited variable-length text |
| `BOOLEAN` | Logical | 1 byte | `TRUE`, `FALSE`, or `NULL` |
| `DATE` | Date/Time | 4 bytes | Calendar date (`YYYY-MM-DD`) |
| `TIME` | Date/Time | 8 bytes | Time of day (`HH:MM:SS`) |
| `TIMESTAMP` | Date/Time | 8 bytes | Date and time (`YYYY-MM-DD HH:MM:SS`) |
| `TIMESTAMPTZ` | Date/Time | 8 bytes | Date, time with timezone support |

**Example:**
```sql
CREATE TABLE products (
    product_id INT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    product_name VARCHAR(150) NOT NULL,
    description TEXT,
    price NUMERIC(8, 2) NOT NULL,
    in_stock BOOLEAN DEFAULT true,
    release_date DATE,
    created_at TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP
);

-- Insert sample product record
INSERT INTO products (product_name, description, price, in_stock, release_date)
VALUES ('Smart Watch', 'Fitness tracking smartwatch', 199.99, true, '2026-05-15');
```
