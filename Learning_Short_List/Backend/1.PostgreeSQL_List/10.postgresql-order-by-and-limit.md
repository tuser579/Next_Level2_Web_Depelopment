# 10. POSTGRESQL ORDER BY, LIMIT & OFFSET

| Clause | Syntax Example | Description |
| --- | --- | --- |
| `ORDER BY` (ASC) | `ORDER BY year ASC;` | Sorts results ascending (default) |
| `ORDER BY` (DESC) | `ORDER BY year DESC;` | Sorts results descending |
| Multi-column Sort | `ORDER BY brand ASC, year DESC;` | Sorts by first column, then second |
| `NULLS FIRST / LAST` | `ORDER BY year DESC NULLS LAST;` | Explicit control of NULL positioning |
| `LIMIT` | `LIMIT 5;` | Restricts number of returned rows |
| `OFFSET` | `OFFSET 10;` | Skips specified number of rows before returning rows |
| `FETCH FIRST` | `FETCH FIRST 5 ROWS ONLY;` | ANSI SQL standard alternative to LIMIT |

**Example:**
```sql
-- 1. Sort cars by brand ascending and year descending
SELECT * FROM cars
ORDER BY brand ASC, year DESC;

-- 2. Pagination: Page 2 (Skip first 10 rows, fetch next 5)
SELECT * FROM cars
ORDER BY id ASC
LIMIT 5 OFFSET 10;

-- 3. SQL Standard FETCH FIRST syntax
SELECT * FROM cars
ORDER BY year DESC NULLS LAST
FETCH FIRST 3 ROWS ONLY;
```
