# 30. POSTGRESQL TRANSACTIONS, PROCEDURES & TRIGGERS

| Feature / Command | Syntax Example | Description |
| --- | --- | --- |
| `BEGIN` / `COMMIT` / `ROLLBACK` | `BEGIN; ... COMMIT;` | Manages atomic transaction boundaries |
| `SAVEPOINT` | `SAVEPOINT sp1;` | Partial rollback point within transaction |
| `CREATE PROCEDURE` | `CREATE PROCEDURE sp_name() LANGUAGE plpgsql ...` | Routine capable of handling transactions |
| `CREATE FUNCTION` | `CREATE FUNCTION fn_name() RETURNS ...` | Returns calculated value or result set |
| `CREATE TRIGGER` | `CREATE TRIGGER trg AFTER UPDATE ON table ...` | Executes trigger function on table events |

**Example:**
```sql
-- 1. Atomic Transaction with ROLLBACK protection
BEGIN;
UPDATE accounts SET balance = balance - 100.00 WHERE id = 1;
UPDATE accounts SET balance = balance + 100.00 WHERE id = 2;
COMMIT;

-- 2. Stored Procedure in PL/pgSQL
CREATE OR REPLACE PROCEDURE sp_discount_old_products()
LANGUAGE plpgsql AS $$
BEGIN
    UPDATE products 
    SET price = price * 0.90 
    WHERE release_date < '2025-01-01';
    COMMIT;
END;
$$;

-- Execute procedure:
-- CALL sp_discount_old_products();

-- 3. Trigger Function & Trigger definition
CREATE OR REPLACE FUNCTION fn_set_timestamp()
RETURNS TRIGGER AS $$
BEGIN
    NEW.updated_at = CURRENT_TIMESTAMP;
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trg_products_updated_at
BEFORE UPDATE ON products
FOR EACH ROW
EXECUTE FUNCTION fn_set_timestamp();
```
