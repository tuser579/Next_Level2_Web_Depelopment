# 16. POSTGRESQL ALIASES (AS)

| Feature | Syntax Example | Description |
| --- | --- | --- |
| Column Alias | `SELECT brand AS car_brand FROM cars;` | Renames result set column for output display |
| Column Alias with Spaces | `SELECT price AS "Retail Price" FROM products;` | Uses double quotes for aliases with spaces/case |
| Table Alias | `SELECT c.brand FROM cars AS c;` | Gives short temporary nickname to table in query |
| Concatenated Alias | `SELECT first_name \|\| ' ' \|\| last_name AS full_name ...` | Names an expression or concatenation |

**Example:**
```sql
-- 1. Column aliases for cleaner reporting
SELECT 
    product_name AS item_title,
    price AS original_price,
    ROUND(price * 0.90, 2) AS discounted_price
FROM products;

-- 2. Table aliases simplifying JOIN queries
SELECT 
    c.customer_name,
    o.order_id,
    o.total_amount
FROM customers AS c
JOIN orders AS o ON c.customer_id = o.customer_id;
```
